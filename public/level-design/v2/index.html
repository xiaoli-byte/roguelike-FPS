推荐路线是一个回环：正殿 → 链桥 → 悬炉 → 东风道 → 正殿。也可以从悬炉原路走链桥回殿，近但拿不到风道私藏，而且是从北门进殿，正对炉门守军；走风道是从东北角进殿，先到东侧检修台的高处。

行进节奏

  1. 南耳室：安全缓冲，望见正殿两台巨型风箱
  2. 鼓风正殿（一）：第一战，熔炉铁牛在风箱道里推进，吸气把人沿风箱道往它那边拉
  3. 链桥与悬炉锻台：第二战，锻台吊在熔渊上，四面无墙；毕方立在四根吊链柱顶，马面狱卒甩钩把人拖出铁砧
  4. 东风道：隔着熔渊回望悬炉，风道里有炉工的私藏
  5. 鼓风正殿（二）：最终战，风箱鼓起，炉门喷出的火落在风箱道上，祸斗吃火变强，傩巫金面加速，神火飞鸦从殿顶俯冲；胜利后从炉门离开
