## 2. 已能确定的视觉方向

1. **碎片构成的刀身应成为第一识别点。** 合拢时仍能读出密集裂纹，展开后保持片状金属的实体感。
2. **蓝紫色能量应成为主色。** 官方联动说明支持蓝／紫发光；本项目可选紫色为主、蓝色为辅，但具体色值是游戏美术选择。
3. **黑色长柄与小型护手应形成干净轮廓。** 依据实际观察的官方周边图，现有金色兽首与红流苏不是这次参考图的主要造型特征。
4. **动作要有清楚的方向与节奏。** 官方制作解析强调关键姿态和可理解的动作。华丽演出应让玩家看清刀、碎片、目标三者的关系。

推导出的制作原则：先把闭合刀身、裂纹、刃片轮廓做好，再增加能量连接、碎刃轨迹、分层弧光及爆发。仅把红色改为紫色，无法解决结构和动作辨识的问题。

据此修正前面的美术建议：

- **裂缝与能量分开设计。** 图1、图2里的裂缝首先读作深色分片边界；白亮刃口和外围紫光承担主要发光。不应默认让每一条裂缝都成为等亮度霓虹线。
- **片面保留银白与淡紫。** 刀背较暗、刃口较亮，紫光集中在外缘和爆发区；避免整把刀被均匀紫光覆盖，丢失裂缝和实体面。
- **刀根纹样和裂纹使用不同尺度。** 图3刀根的蓝色曲线纹样明显大于刀身碎片边界，需要独立建模／贴图表达。现有随机斜刻痕不能直接作为替代。
- **重做细长轻弯的轮廓。** 不能由图1、图2的透视夸张直接推导武器实际长度、宽度或攻击范围；完整轮廓主要参考图3，第一人称再以持握和视野检视。
- **刃口散片时保留主轮廓。** 图1可用于定义“边缘正在碎裂”的关键姿态：刀背仍连贯，下沿局部解体，大小不同的碎片环绕下沿分布。运动方向、速度与回收路径仍属于待核对／游戏改编部分。
- **护手、握把、柄尾回归参考图。** 以小型深色护手、黑色缠柄、蓝色刀根和柄尾纹样取代现有金色兽首、宝珠及红流苏的主体造型。

建议先做两个可对照的关键姿态：图2所示的闭合刀身、图1所示的刃口散片。两者使用同一套片面和分片边界，保证视觉上是同一把刀在变化。静帧只支持状态对照，尚不能证明其时间顺序。

### 2.2 用户明确的碎片运动方向

用户于2026-10-05明确：**碎片运动从刀尖到刀柄。** 这是此次重做的直接动画约束，优先于先前未核实的运动猜测。

- 以刀身长度方向组织运动，碎片沿刀尖→刀根→刀柄方向传递。
- 动画必须能读出这个方向；单纯由刀尖开始依次亮起／裂解，不能替代碎片自身向刀柄运动。
- 随机抖动、侧向散开和自旋只作为次级表现，不能盖过主运动方向。
- 这一说明确认了运动方向，未指定速度、加速度、具体曲线或回收／重组是否采用反向运动；这些仍属于后续演出设计，不自行写成原作已确认事实。

### 必须处理的技术约束

- 18柄弹药与18组可动刃片、排序、悬浮阵重排、召回动画有关联。视觉碎片增加时，应使用18个逻辑组，每组含多个不规则小片，或者同步重新定义全部映射；不能直接改一个数量常量。
- `animateBlade` 的可见片数由剩余弹药计算，然后再应用形态插值。远程打空后切近战的完整刀身表现需要专门检查；代码存在闭合刀身跟着弹匣缺片的可能，本轮尚未做运行复现。
- 现有对象池：512枚飞行刃、24组刃印、32组贯穿爆发。24个目标同时发动高画质贯穿时，理论请求超过512枚飞行刃，循环覆盖是潜在上限；增加单目标数量前需验证多目标降级策略。
- 刃光、环和风线写入共享RibbonBatch。增加轨迹条数也会消耗全局容量，需与枪火、敌人特效同场验证。
- 暂停时必须只绘制而不推进动画；换关、死亡、中止技能和切枪的清理行为需要保留。
- 项目已有高／中／低画质缩放与性能采样协议，采用相同视口、实际渲染分辨率和负载对比；旧场景约60FPS的记录不能直接证明新魔刀的性能。

## 4. 游戏演出建议（历史调研方案；当前落地见第7节）

建议定位：**黑色缠柄、蓝色刀根纹样、银白碎片刀身与深色裂缝、白亮刃口和紫色辉光；碎刃能够沿清楚的轨迹离开、形成刃群并归位。** “华丽”来自形态变化和节奏层次。造型与光色优先依据用户提供的三张参考图。

| 情境 | 建议演出 | 需要看清的内容 |
| --- | --- | --- |
| 近战待机 | 刀身合拢，深色裂缝分隔银白片面；刀根蓝纹与刃口弱辉光呼吸 | 完整长刀轮廓和实体分片 |
| 横斩／回斩 | 淡紫弧面、白亮刃口与紫色外晕；下沿角状实体薄片由刀尖向刀柄运动，刀背保留轮廓；两段挥砍方向清楚 | 碎片向刀柄流动，刀路与碎片属于同一动作 |
| 第三段下劈 | 刃片短暂拉开缝隙，出刀时聚合；主斜劈光＋短暂裂纹冲击；命中时保持原有顿帧 | 重击比前两段更有力度，裂解不导致攻击距离误读 |
| 变形 | 刀根纹样与刃口先亮，片组由刀尖向刀根解开；碎片分层绕行，形成不遮挡准星的紧凑刃群 | 原有不规则片面在离刃后仍可辨 |
| 远程射击 | 每次三组刃片收束成三束飞刃；实体片＋细亮芯＋紫色尾迹 | 弹药减少与离手动作一致 |
| 召回 | 分批沿弯曲轨迹归位；接近时减速、转正、微闪；完成时一次清楚的聚合反馈 | 回来的碎片进入刀／刃群，不只是消失在手边 |
| 技能突进 | 起手能量聚合，突进两侧碎刃流与短残影；镜头中心保持通透 | 路径、结束位置与被命中的目标 |
| 技能等待 | 刃印由稀疏碎片围绕目标形成，间隔缩小，亮度逐步升高 | 目标即将被贯穿，等待阶段有可辨的蓄势 |
| 贯穿爆发 | 周围刃群先构成可辨结构，再向中心同时收束；短亮闪、交错切痕、碎屑外散，最后迅速退光 | 命中时刻明确；多目标时不会覆盖整个画面 |

主题色建议保留在刀根纹样、刃口辉光和主要刀路，深色裂缝保留对比。火／电／腐蚀等元素可用次级粒子、命中外环或局部边缘表达。这是本次改编建议，不代表原作元素机制。

具体形态变化应适配现有0.25秒切换、三段连击和技能时间窗口；不为容纳慢镜头擅自延长攻击前摇或延迟伤害。

## 6. 2026-10-05第一版制作记录（已由第7节修正）
