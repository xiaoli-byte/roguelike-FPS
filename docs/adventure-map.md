> 下文保留原 StageDesign 地图及其历史验证记录。2026-10-04 用户认可十五关白盒后，[新布局与场景美术（LD-02 / ART-01）](level-design/README.md) 已成为正常游戏默认地图。当前流程按房区触发遭遇，不再依赖旧地图的祭坛波次；`/whitebox-lab.html?theme=desert&stage=0&look=art` 可对照技术白盒。新场景使用本机 Hunyuan 成品及新增栈桥，保持已验证通路和碰撞；`?layout=legacy` 保留旧地图回看入口。以下旧尺寸、流程与性能数据不代表新场景。

每轮包含三章、每章五个关卡位置，共十五关。普通战斗关和精英关保留 84×84 米的半开放区域，使用各自的道路、连通口、岩脊和建筑配置；三章首领另有独立场地。第 2–4 个位置仍可选择战斗、精英、商店或宝藏分支。

道路设计延续此前参考《雨中冒险 2》的中央空地、多条避敌路线和分层探索思路：[Seekers of the Storm Dev Diary #2](https://store.steampowered.com/news/posts/?appids=632360&enddate=1716224663&feed=steam_community_announcements)。实际数值蓝图集中在 `src/world/StageDesign.ts`，检视页、传送门和 HUD 读取同一份名称与路线提示。

## 游玩流程

1. 入场后自由探索。主路和侧路分别设置局部守卫，进入可见的触发区域才开战。尚未踏入的支路不会向当前战斗不断加入敌人。
2. 三个可选地点分别提供金币、武器和秘卷宝箱；其中一处有物资守卫，清除后才能领取。每个地点本关只生成一次奖励。
3. 同时只进行一场局部遭遇。解决当前守卫后，可继续探索，也可靠近金色灵火祭坛按 **F** 开始试炼。
4. 完成祭坛波次后开启章节出口。未交战的沿途守卫撤离；仍需亲自走到补给点收取遗漏物资。无需清理所有支路才能通关。

左上角行旅图显示本关名称、路线提示、道路、玩家朝向和目标距离。局部战斗时指向当前遭遇；补给标记在附近或已探访后显示；清场后指向实际开启的出口。商店和宝藏分支不生成战斗守卫，首领维持首领击破后的结算流程。

怪物按武器分工：近战从前路压上，突袭单位延后从侧路出现，弩手和飞灯占远程点，精准射手和炮手使用更远阵位，巫祝靠近前排提供支援。精英替换编队中的普通单位。具体编队及验证见 [遭遇设计](encounter-design.md)。

## 场景和通行

岩脊、天然边界使用本机 Hunyuan3D 已生成的沙岩和玄武岩；霜山复用覆雪松树并给岩石添加积雪材质。没有生成新的程序化艺术网格。地面材质随路线过渡，一处 1.2 米低看台由实际可攀登台阶连接。

岩石按 24 米区域使用共享网格实例合批，高／中画质近处使用 LOD1，远处使用 LOD2，低画质持续使用 LOD2；实例按实际源网格顶点拟合碰撞包络。光源数量沿用固定两盏。生成种子、90° 整体旋转、支路和岩石碰撞始终同步。道路材质权重已预烘焙，太阳阴影缓存并以约 30 Hz 更新，详见 [性能记录](performance.md)。

祭坛敌人只从距离祭坛 12–23 米的可走地面出现，刷出时距离玩家至少 12 米。局部遭遇使用各自的安全阵位，距离玩家至少 10 米。刷新前验证落地位置及完整可达路径，并保留至少 0.8 秒实际显示的地面预警；冲进预警点后会换位并重新预警，暂时没有安全点时延后刷新。

## 本轮验证（2026-10-04）

完整 `npm test` **138/138 通过**，`npm run build` 通过。新增关卡检查包含 189 份正常生成地图与 90 份未经修复／重试的原始地图，逐米采样主路、横巷、门洞和高台通道，检查真实 NavGrid 与 CollisionWorld 的完整路径、玩家身体及遭遇阵位净空。12 种主路签名在旋转、平移和镜像后仍互不相同；随机布置不修改共享蓝图。

真实地图、编队和刷新调度的 63 组固定站位模拟全部刷齐，包含 9 只精英盾卫。独立流程测试覆盖守卫仅触发一次、隔墙不触发、单场遭遇互锁、补给仅奖励一次、取消预警和清关结算。

种子 20261004 的 12 个探索图实际合计 196 面墙，每图两座石门；所有实际墙包络与崖岩相交为零。墙和门合计上限为每图 18 或 22 个模块。前景岩块约 54–61 块，沿用实例合批、三级 LOD 与固定两盏点光源；没有增加美术模型文件。蓝图中的墙段是候选，只有通过净空检查的模块才落地。

十五关全景与三章地面镜头已在浏览器检查，原始截图、测试日志、构建日志和性能记录位于 `art/reviews/stage-design-20261004/`。

实际 Game 中走完熔炉环路的侧路巡逻、物资守卫、补给解锁、四波祭坛和出口开启；未触发前哨随清场结束，通关计数仅增加一次。另检查炎脊斗场首领登场，以及玄岩三庭的商店覆盖类型没有守卫、没有战斗提示。该实机检视页全程无 console error / warn，结束后已关闭，保留暂停的十五关场景检视页。
