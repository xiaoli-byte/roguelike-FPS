# 地域建筑与地表细化（2026-10-04）

本页保留第一轮地标与性能记录。之后按《枪火重生》方向重做六件主要环境资产，最新实际发布规格、失败重试、画面对比及验证见 [scene-stylization.md](scene-stylization.md)；原阶段文件与本页旧数据继续保留。

三章增加独立建筑地标：沙寺的残垣壁龛、霜山的覆雪山道祭亭、熔火的黑曜铸造祭炉。每个半开放区域在三个支路补给点和祭坛附近各设置一座，原有碑、罐、灯龛和小祭炉作为陪衬。建筑正面朝向对应发现点，入口、主要通路与战斗区域继续留空。

艺术网格全部来自本机 ComfyUI/Hunyuan3D，未使用程序化建筑模型。概念参考使用 **Codex 内置 image_gen**，完整最终提示词、原始路径与生成器在 `art/pipeline/landmark_concepts.json`。未经改写的概念原图副本、配准四视图、输入与生成图谱哈希保存在各资产 `art/source/props/<ID>/asset.json` 和阶段目录中。参考阶段只创建尺寸与正交相机 JSON，`reference_mode=bounds_only`、`geometry_created=false`。

所有建筑沿用 5000 / 1600 / 500 面预算、1024² BaseColor/Normal/ORM 和每件 900 KiB 上限。Hunyuan 负责形体；Blender 负责减面、UV 和 CPU 烘焙。运行时联合测量实际全部 LOD 顶点，先将轴心居中并落地，再等比缩入各建筑预留的完整矩形碰撞体。场景建筑高画质覆盖发布距离，在 20 / 42 米切换（独立道具检视使用清单中的 18 / 42 米）；低画质使用中远景两级，在 30 米切到最远级；切换带 10% 迟滞。重复建筑共享几何、贴图和场景材质，静态矩阵冻结，没有增加灯光。

建筑占地在岩壁生成之前预留；现有 48 块边界岩壁局部向外让位，三条内部山脊保持连续。360 个地标布局覆盖三章、普通/精英区域与 60 个种子，验证完整占地、朝向、道路宽度、交互圈、出生点、奖励、出口、台阶和导航。不依赖事后删除建筑修复布局。资源尚未加载时不生成替代建筑，后台预加载完成后补入真实网格；已销毁场景不会被异步加载复活。

地表复用已有 ImageGen 石板原图和一次 R8 道路蒙版采样。主路保留石板，路外混合较平整的积沙、积雪或灰烬，继续保留顶点色大尺度明暗变化。覆盖处降低石缝法线与熔火裂缝透出、提高粗糙度；未增加纹理采样或 GPU 道路循环。建筑脚下继续使用共享实例的接触阴影与贴地风化层。

祭坛标牌缩为 4.8×1.2 米，水平观看距离 3.4–6 米平滑淡出，近处由实际 F 交互提示接管。探索、战斗、清场各有对应文字与金/红/绿边框，文字纹理仅在阶段变化时重绘。

`/details-lab.html` 可单独检查三件新建筑的正面、两侧、背面与旋转视角，也能检查三章主景、支路和区域全景。`/adventure-lab.html?theme=inferno&debug=1&perf=1` 用真实游戏记录性能；最终截图与测量保存在 `art/reviews/landmarks-20261004/`。

## 新资产接入后的性能复核

继续使用真实 Game、固定种子 20261004、high 画质、1280×720 CSS 视口和 DPR 1.5（实际 1920×1080）。每项先预热 30 帧，再记录 240 帧；生成任务和构建进程均已结束，所有记录隐藏帧和 GPU disjoint 为 0。

| 探索入口 | RAF FPS | GPU 平均 ms | 平均调用 | 平均三角形 |
| --- | ---: | ---: | ---: | ---: |
| 沙寺 | 60.0 | 4.62 | 89.5 | 151,461 |
| 霜山 | 60.0 | 4.71 | 98.0 | 158,044 |
| 熔火 | 60.0 | 4.27 | 91.5 | 157,985 |

多开 3D 页面时保留了最初熔火探索 **48.3 FPS** 的失败采样；仅临时移除自有场景预览即可恢复约 60 FPS，用户原有两个标签未改动。场景播放预览随后限制为 30 Hz，恢复自有页面后得到以上三章探索结果。持续战斗仍测到 **52.0 FPS**，临时移除同一预览的对照为 **60.0 FPS**。两段战斗的 GPU 平均分别为 6.74 / 6.51 ms，但技能和粒子时序不同，不能把它们当成严格相同负载的百分比比较。

最终进一步将暂停预览改为操作后按需重绘：控件修改、镜头切换、窗口尺寸变化和 WebGL 恢复均触发更新；武器与怪物的内插有 600 ms 收敛窗口，再停止更新与绘制。启动时等待真实地表原图，避免暂停画面保留临时材质。播放中的场景保持 30 Hz，播放中的武器、怪物与真实游戏维持正常 RAF。

恢复自有暂停检视页后，最终祭坛 Q / E 技能战斗采样为 **60.0 FPS**，RAF P95 **16.8 ms**，GPU 平均 / P95 **6.41 / 7.68 ms**，CPU 更新平均 **0.75 ms**、提交平均 **2.41 ms**，平均 **122.4 calls / 193,831 triangles**。对应 `inferno-combat-final.json` 与截图；首次技能战斗的 54.4 FPS 记录仍以 `inferno-combat-first-wave.json` 保留，30 Hz 预览时的 52.0 FPS 以 `inferno-combat-viewer-30hz.json` 保留。按需重绘改动后的全量 98 项测试与生产构建再次通过。

原始 JSON、低帧对照及截图全部保留在 `art/reviews/landmarks-20261004/`，没有删除低帧记录。测量仅代表本机上述视角、分辨率和敌人负载。
