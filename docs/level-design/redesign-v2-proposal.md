# 关卡与场景重做方案（V2 提案，2026-10-06）

## 1. 现状诊断（15 张 LD-03 平面图实测）

| 指标 | 现状 | 问题 |
| --- | --- | --- |
| 房间面积 | 多数 500–1000 m²（约 25×30 m） | 6 只以上敌人加冲刺、二段跳时空间局促 |
| 通道宽度 | 5–8 m | 窄而长，像走廊迷宫 |
| 主路长度 / 转弯 | 85–425 m，最多 15 个转折 | 方向感差，频繁回头找路 |
| 掩体 | 每图 2–7 块，高度单一 | 战斗缺少层次 |
| 高差 | 平面格式不支持 | 没有高台、坡道、俯射位，二段跳无用武之地 |
| 美术 | 同一墙段沿房间边界重复拼接 | 视觉单调，地标弱，像迷宫 |
| 每图硬编码 | 77 处（场景布局 42、场景视图 18、遭遇 17） | 改图要同时改多张旁表，难以迭代 |

## 2. 目标结构（参照《枪火重生》的关卡节奏）

- **线性主线 + 少量支路**：每关 3–4 个大型战斗场地串联，场地之间用短而宽的过渡段连接；支路只是一两个可选的小平台或侧室，用来放宝箱，不形成回环迷宫。
- **场地尺寸**：战斗场地 40–60 m 见方（1600–3600 m²），过渡段宽 10–14 m、长 15–30 m。
- **高差**：每个战斗场地至少两层高度。高台 2.5–4 m，配坡道或台阶；二段跳能直接上高台，形成俯射与绕后路线。
- **视线与导航**：入口处能看到下一场地的地标（塔、拱门、巨像、熔炉）；出口有明显的光源和颜色引导，不依赖 HUD 箭头。
- **掩体**：每个场地 8–12 处，分为低掩体（1.2 m）、高掩体（2.6 m）和可绕柱，中远距离交替。
- **节奏**：入场缓冲 → 战斗 → 短暂探索（宝箱、商人）→ 下一场。首领关为一个准备区加一个大型圆形或扇形场地。

## 3. 技术方案

1. **新的关卡数据格式**：以「场地 + 过渡段」为单位描述，每个场地包含地面多边形、高台（多边形 + 高度）、坡道、掩体、出生点、地标位置。由同一份数据生成碰撞、导航（含坡道）、白盒和美术摆放，不再按房间边界自动拼墙。
2. **去掉每图硬编码旁表**：遭遇编组、美术主题、地标都写进关卡数据。
3. **美术**：外围用大块山体 / 城墙 / 建筑立面封边，中间用少量高辨识度地标。建筑模块与地标改用 Tripo 生成，经现有管线（校验、LOD、Draco、清单）发布；Hunyuan 现有资产保留为岩石、植被等填充物。
4. **迁移**：先做沙寺第 1 关的完整垂直切片（白盒 + 美术 + 遭遇），确认手感后再批量推进其余 14 关。旧图纸与 `?layout=legacy` 保留用于对照。

## 4. 怪物重做

- 用 Tripo 重新生成 8 种普通怪与 3 个首领，使用 Tripo 自动绑定（Mixamo 骨骼）。
- 运行时把 Mixamo 骨骼映射到现有人形关节名；持枪、施法动作改为基于手部挂点与武器握点的约束，而不是复制武器朝向（避免手腕折叠）。
- 骷髅弩手、迫击炮手、萨满的持械与施法动作逐个对照验收。
