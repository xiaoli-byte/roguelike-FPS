# 2-4 北冥冰台 · 鲲鹏（M24，2026-10-22）

第二章的首领场。瑶池冰湖（2-3）往北，翻过一道雪岭就是北冥：一圈环形冰台围着中央破开的冰窟，冰窟里是北冥的冰海。鲲在冰窟里醒来，从各个方向探头扑咬；打到一半鲲沉入冰窟，冰海炸开，化成巨鹏升空，在环台上空盘旋俯冲。

## 2. 冰窟与水面遮罩

- **地形洞**：`Sample.hole` 在冰窟半径（随方位 ± 0.6 m 起伏）以内为 1，碰撞和渲染都开口；洞里的高度压到 −3，洞边那一圈地块从冰沿卷下去。
- **水体**：一块 32 × 32 m、深 6.06 m 的 L8 `WaterVolume`，顶面就是水面（环台地面 +0.06，同 Three.js 的海面高度）。四角伸到冰沿下面，冰沿比水面高，所以只在冰窟里看得见水。
  - 深水（脚下 ≥ 1.3 m）按坠落处理：扣 `drownBurst`（10%）、托回安全落脚点、1 s 无敌；深水区不记安全落脚点。
  - 水底 −7 m 一块不渲染的碰撞块兜底（托回失败时人不会一直往下掉）。
  - 导航：冰窟上空铺一排 `NavMeshModifierVolume`（Not Walkable，1 m 宽的条带拼成圆）。不依赖「地形洞会不会被烘焙器扣掉」。
- **冰窟标记** `IceHole`（`G/Bosses/KunPeng/IceHole.cs`）：放在冰窟圆心（物体高度 = 环台地面），声明半径 15、外缘 44、水面 +0.06。鲲鹏按它找冰窟（Three.js 是从导航网格反推的，这里改成显式标记），找不到时退回场地中心的虚拟冰窟。
  - 冰窟边缘的 20 段挂在标记的 `rimRoot` 下：鲲的吞吸气流、鹏的狂风是从冰窟里越过冰沿吹出来的，首领的「掩体挡住」判定不把边缘段当掩体。
- **水面遮罩**：`IceHole` 运行时在水面下 0.15 m 铺一张不透明的深海圆盘（没有碰撞、不投影）。冰窟里水面以下的东西——鲲的平切口、洞壁——全被它挡住。
  - 鲲的模型只做了露出水面的前半身，模型原点就是平切口。BS3 让切口最高点始终压在水面下 0.3 m（抬身、前扑时整只往下沉）。
  - 场景里没有水体时（测试场的虚拟冰窟），标记自己补一张水面片。

## 4. 节奏

1. 出生在雪岭营地：买药、强化。营地四周是雪岭，看不到冰台。
2. 出营地东门进冰崖通道，转一次弯爬上来。登台口先看到冰窟里翻涌的冰海和两座祭台。
3. 一阶段 · 鲲：在冰窟里慢慢绕到玩家那一侧探头。
   - 吞吸：扇形里的人被拉向冰沿，冰柱 / 矮墙挡气流，冰沿四段冰面上脚下打滑；
   - 猛砸：前身砸上环台、掀冰浪；
   - 潜袭：从玩家那一侧破冰而出；
   - 吐冰：远了就吐冰弹。
   - 要绕着冰窟找它探头的位置；额头鲛珠是弱点，猛砸趴台时离地最近。
4. 50%：鲲沉入冰窟，冰海炸开（整圈冰浪），冰雾里化鹏升空。
5. 二阶段 · 鹏：在环台上空盘旋。
   - 扇翼狂风：把人吹向外缘冻风带，冰柱背后不受风；
   - 俯冲掠台：沿环台切线，撞上冰柱 / 祭台撞晕；
   - 羽刃雨；
   - 落台歇翼：主要输出窗口。
6. 击败 → 溃散 → 结算（回满、首领宝箱）→ 南缘冰门前立出口，进第三章。

## 6. 风险 / 待编辑器确认

- 这张图在 worktree 里写成，没在编辑器里生成过。第一次 `bridge.sh level 2-4` 后要看报告和截图确认：
  - 冰窟洞边那圈地块卷进水里的样子；
  - 冰沿与水面方块四角的遮挡（冰沿只比水面高 0.19 m，洞边的起伏不能把方块角露出来）；
  - 冰窟边缘段的贴合（段心 r 16.4、底面压进冰沿 0.2 m）；
  - 冰崖通道两侧的切壁；
  - 南缘门洞平台和冰门的贴合。
- 冰窟边缘、冰柱、崖壁片（ART5）和霜山商摊（ART7）、冰门、鲸骨灯、船桅、毡帐都是正式件，全部经 `PlaceOrBox` 摆：缺 Prefab 时放白盒，报告按 Warn 列出。
