## 1. 母题与节奏

- **母题：逆流而上的梯坊**。熔铜从王座流下来，一级级跌到出生点；玩家每上一级台地，王座就近一级、熔铜就高一级。全图只有王座是暖光中心，其余分区保持冷暗（11-01 的氛围原则保留）。
- **三件新东西**：① 梯坊——每一级之间是 4 m 的陡坎，坡道就是路线，陡坎边就是俯射位；② 熔流闸——③ 的两口浇包，打掉吊钩熔铜就顺槽冲过来，第一次「用熔岩打一片」；③ 一座殿打两次（保留）——拉开风闸，殿里换一番光景。
- **章节位置**（ch3-v2 3.3 登场表）：3-3 教熔铜匠（① 第一波，单只）和变脸傩巫（② 第一波）；祸斗在 ③ 第一次做精英（迅捷），铁牛在 ④ 做精英（坚盾）；首领熔心魔将。火鼍不在 3-3 出（3-1、3-4 的怪）。

### 2.2 熔铜（`Falls`、`Pools`、`Spill`）

- **流路**：熔岩柱 → 神范熔池 → 十字浅渠（南北渠南流进横渠、东西渠西流进主渠）→ 横渠东段西流、主渠南流 → 主渠口 (100, 110) → 熔铜瀑：D1 瀑口 (100, 107.5) 0 → −4，T2 段（B2 瀑上桥）→ D2 (102, 76.5) −4 → −8 → 瀑池 (102, 66) → T1 段（B1 瀑下桥）→ D3 (106, 42.5) −8 → −12 → 熔铜潭 (124, 26)。
- **截面**：同原来的铸坊渠（8 m 宽、约 54° 斜壁、熔岩面低于台面 1 m）——只能走桥；瀑口那 2.5 m 渠底陡落 4 m，没有熔岩判定，画一片沿抛物线落下的熔瀑（`Molten Cascades`，材质同王座熔岩柱的调法；「兽首熔流口」锦上添花件到货前就靠它）。
- **① 溢流槽**：瀑池往西分出一股（5 m 宽），穿过岩丘流进 ① 东北角的废铜池（r 3.5）——① 的击退熔岩岸。**炉前熔池**（殿西头大炉前，r 3.5，浅）——殿里的击退熔岩岸。
- **涨落**：主渠、横渠东段、熔铜瀑三级、瀑池、熔铜潭都写好自动涨落（风闸拉开后打开，只在渠里涨 0.6 m）；**领主战漫溢只碰神范台**（十字浅渠 8 段 + 熔池 = 9 片，`FoundryChannels.surge`），熔铜瀑段和神范台段分开（自查逐片核对坐标）。

## 11. 设计上的取舍（不问用户，按推荐定）

1. **东引坡拆成两段**：5.3 节写「③ → 东引坡（沿东壁）→ 东中台 → B2」，但沿东壁上去再走回 B2 要多 90 m。主线改走 ③ 西北角的「吊坊西北坡」（③ → 东中台 → B2 约 80 m），沿东壁的东引坡改成支线（东中台 → 横渠南岸 → B6）。
