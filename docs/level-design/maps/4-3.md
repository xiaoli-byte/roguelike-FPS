# 4-3 彩林海子（L4_3_Cailin）

川西深秋的高山海子：近景一汪镜面静水，中景满谷金黄的落叶松夹着墨绿云杉，右岸一整面花岗岩大山，远处 V 形谷口里是积雪的尖峰，湖面倒映雪山、金林和天上的云。

用户 2026-11-06 发来一张川西秋景照片（雪峰 + 金色落叶松 + 镜面湖），要「给游戏建一个这种场景」；2026-11-07 看了成品后选「加成第四章新关」。照片只当气氛和构图参考，地形、树、远山都是程序化重做的，风格按全项目的风格化光照走。

## 1. 定位

- 第四章「雪域天路」第三关：4-2 大渡河·铁索桥峡谷 → **4-3 彩林海子** → 4-4 神山海子·雷泽雷神（RunPlan，难度 3.72）。叙事上是过了峡谷、走进神山脚下的秋林谷地，谷口那三座雪峰就是神山一带。
- 占了原计划「雪域宫堡」的位置（宫堡只有一行设计，第二期还没开工），宫堡怎么安排见第 5 节。
- 现状：第四章只建好了 4-1 和 4-3，整局路线是 … 3-4 → 4-1 → 4-3，4-3 暂时是终点（打开出口就是胜利结算）；4-2、4-4 建好后自动接上。
- 生成：`Spiritfire ▸ Levels ▸ Build 4-3 彩林海子`，或 `bash scripts/unity/bridge.sh level 4-3`。代码 `unity/Assets/Pipeline/Editor/Levels/Level_4_3*.cs`，验收报告和截图在 `unity/Assets/Art/_Review/level_4-3_*`。

## 3. 玩法（同 4-1 的开放图规则，没有领主）

五处据点任意顺序，各一座灵火坛（守卫肃清后才点得着，点亮回满血 + 复活点）；**点亮任意三处灵火，谷口经幡门里的出口升起**。谷口还有一拨守卫，是出口前的考试。代码 `Level_4_3.Play.cs`。

- 推荐主线（验收的路点）：出生（南岸）→ ③ 西岸 → ② 北岸 → ① 东岸车路 → ④ 玛尼石滩 → ⑥ 谷口经幡门；⑤ 在出生点身后，是回头可选的一处。
- 据点、灵火坛、经幡门周围不种树（据点 0.6 倍半径以内是空地，往外渐渐回到林子），湖岸和林子里的仗靠倒木、大石和树干打。
- 编制写在 `BalanceModel.Stages` 的 4-3 行（`BalanceModelTests` 逐关对照场景）。

### 3.1 守鼓人鼓楼（2026-11-07 用户定：原 4-3 雪域宫堡的剧情落在这里）

- 位置：谷口西侧山腰的一块台地（台心 (−268, 505)，台面半径 13 m，比谷底高十几米），一条约 20° 的直坡道从谷底 (−212, 468) 上去，坡脚两根矮杆横拉一道经幡、坡边三堆玛尼石标出上山的路。离出口经幡门约 150 m，不在主线上，是谷口的一处可选支路。
- 造型（白盒，只借宫堡的形态，不做寺院）：石台基 → 收分的白墙主楼（正面门、两层梯形黑窗）→ 赭红边玛墙带 + 黑檐线 → 小一圈的上层 → 金顶、宝顶，主楼四角金饰；楼顶拉经幡到台地边。正面朝东南。坡下留了一片高山草甸（不种树），沿谷底往出口走时隔着草甸就能看见山腰金林里的白墙红边金顶（验收视线「谷口草甸 → 守鼓人鼓楼」）；从出生点隔湖是看不见的——北岸的林子挡住了，出生点的画面留给湖和雪峰。
- 门前：一副**空鼓架**（鼓早被夔带走了，横梁上挂着断皮绳和一片撕下来的鼓皮，地上几片鼓框碎木）；石案上摊着**修鼓旧簿**。
- 剧情投放：修鼓旧簿是一份 `LoreNote`（新组件 `Game/Scripts/World/LoreNote.cs`，剧情草案第 6 节「遗物」的第一份）。走近看着它，提示卡里直接显示正文：
  > 庚子秋，鼓面又裂一道。皮向外翻，铜钉向外崩——非外力所击，是自内而裂。补以新筋，不出三月复裂。鼓中夜夜作雷声。——守鼓人记

  第一次阅读：大横幅「鼓自内裂 · 守鼓人鼓楼 · 修鼓旧簿」，鼯的一句：「鼓不是被敲破的……是里面的东西想出来。」（`LoreNote.AnyRead` 留给以后的图鉴 / 残简收集。）
- 没有放灵石窖藏：试过檐下放一个香火箱（CachePOI，灵石），4-4 补给营前攒下的灵石超出经济设计的区间（BalanceModelTests：能买下整店的 89%，上限 85%），去掉了；鼓楼的回报是剧情。
- 资产 id：`SM_Tripo_LarchDrumTower` / `LarchDrumFrame` / `LarchLedgerTable`，正式件到了自动换上。
- 场景件都是白盒，资产 id 沿用第四章的 `SM_Tripo_Plateau*`（玛尼墙、玛尼堆、黑帐篷、经幡杆、大石、灵火坛石柱），另加 `SM_Tripo_LarchFallenLog` / `LarchLogPile` / `LarchHunterRack`，正式件到了自动换上。

## 4. 开放区域与树

- 谷底（湖岸、林下、北边谷地一直到谷口）、东岸车路都能走；两岸陡坡和大崖是天然边界。软边界：谷底两侧各让出 70 m 林坡、高出谷底 90 m 以上不算界内，南北到地形边缘内约 150 m（`Playable`），风雪白化推回，没有空气墙。
- 树：程序化风格化针叶树（`Spiritfire/Foliage`：顶点色固有色 + 球形法线 + 风摆 + 逆光透光，和 StylizedLit 同一套光照），两级 LOD，种成地形树（带树干碰撞）。落叶松 4 种（金黄 / 琥珀橙 / 浅黄 / 转色中），云杉 3 种（墨绿 / 蓝绿 / 橄榄绿）。谷底约 7 m 一棵，山坡密；落叶松比例谷底约 80%，往上降到 22%。约 4.4 万棵，林下地被约 26 万丛（只铺游玩区，视距 120 m）。
