# 彩林海子（LX_LarchLake）

川西深秋的高山海子：近景一汪镜面静水，中景满谷金黄的落叶松夹着墨绿云杉，右岸一整面花岗岩大山，远处 V 形谷口里是积雪的尖峰，湖面倒映雪山、金林和天上的云。

用户 2026-11-06 发来一张川西秋景照片（雪峰 + 金色落叶松 + 镜面湖），要「给游戏建一个这种场景」。照片只当气氛和构图参考，地形、树、远山都是程序化重做的，风格按全项目的风格化光照走。

## 1. 定位

- 第四章「雪域天路」的气质（川西高原），但**还没有排进整局路线**：RunPlan 里没有它，直接打开场景按 Play 开调试局（`LevelBootstrap.stageTitle = 彩林海子`）。
- 放进哪一关（新增一关 / 做成 4-3 前后的过渡图 / 当主菜单远景）等用户定；玩法（遇敌、灵火、出口）到那时再按开放图规则加。
- 生成：`Spiritfire ▸ Levels ▸ Build 彩林海子`，或 `bash scripts/unity/bridge.sh level larch`。截图和验收报告在 `unity/Assets/Art/_Review/level_larch_*`。

## 3. 开放区域

- 谷底（湖岸、林下、北边谷地一直到谷口垭口前）、东岸车路都能走；两岸陡坡和大崖是天然边界。
- 软边界：谷底两侧各让出 70 m 林坡、高出谷底 90 m 以上不算界内，南北到地形边缘内约 150 m（`Playable`），风雪白化推回，没有空气墙。
- 验收：出生点 → 东岸车路 / 北岸林地 / 西岸霜滩 / 北边谷地在导航网格上连通（`CheckWalk`）。

## 4. 树

程序化风格化针叶树（`Spiritfire/Foliage`：顶点色固有色 + 球形法线 + 风摆 + 逆光透光，和 StylizedLit 同一套光照），两级 LOD，种成地形树（带树干碰撞）：

- 落叶松 4 种：金黄 / 琥珀橙 / 浅黄 / 转色中（还带绿意）——细高，层间露出深色树干；
- 云杉 3 种：墨绿 / 蓝绿 / 橄榄绿——塔形、枝层密。
- 谷底稀（约 7 m 一棵，人走得开）、山坡密；落叶松比例谷底约 80%，往上降到 22%，按噪声成片出现云杉林斑；东岸崖面按噪声留一条条树带。
- 现在一共约 4.4 万棵（落叶松 2.8 万、云杉 1.6 万），林下地被约 26 万丛（Terrain 细节，只铺游玩区，视距 120 m）。

审核截图：`docs/art/review/larch-lake/`（出生点低机位、第一人称、西岸、东岸车路、林下、俯瞰）。

## 5. 还没做

- 玩法：遇敌、灵火坛、出口；排进哪一关。
- 正式资产：湖边玛尼堆、经幡、木栈道这类第四章标识物（现在只有地形、树、地被）。
- 画质分档：平面反射在低画质下关掉（`PlanarReflection.Enabled`），还没接进 QualityProfile；4.4 万棵树 + 倒影再画一遍的帧耗时还没测（`playtest perf` 一类的套件还没覆盖这张图）。
- 平面反射的实现细节：嵌套渲染（`RenderSingleCamera`）期间临时停掉贴花和 SSAO 两个渲染特性——不停的话贴花 Pass 取不到颜色目标、空引用，整张倒影作废。
- 东岸大山的崖面还偏浅灰、平；照片里是深一些的花岗岩带暗色竖纹，可以再压暗或加一层崖面细节。
