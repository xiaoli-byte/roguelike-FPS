## 1. 题材与定位

祝融火狱外围的一片开阔火山灰原。东北方向远处一座冒烟的大火山（全图地标），一条主熔岩河从火山方向流下、斜穿灰原，在中部分出一条东去的支流——
**两条熔岩河把灰原切成西、东北、东南三块陆地**，只有天然玄武岩堤能过（碰熔岩的只有石头，没有木桥木船）。

和本章另外三张图拉开：3-1 是熔湖里的堤和墩（处处是熔岩、路线被堤限定），3-2 是竖井，3-3 是工坊大殿；3-A 主打**大片可走的灰原 + 熔岩河分出的多条路线**：
六道玄武岩堤把三块陆地连成环，先去哪块、从哪道堤过都由玩家定。

## 2. 尺度与高度

- 关卡坐标 = 世界 XZ（米，x 向东、z 向北），熔岩面 y = 0；灰原面约 +2.6（±1 起伏），河床 −1.2，堤面 +2.8。
- 游玩区约 275 × 240 m（x −138…140、z −122…120），外圈是 20–26 m 的火山口崖（地形），崖外东北是远景大火山（峰顶约 +78，冒烟）。
- 地形 400 × 400 m（2 × 2 块），外缘 30 m 落回远景地面。

## 4. 怪摆在哪（三类地方）

用户 11-08：「射得爽 = 武器牛逼，怪少了不爽」「要考虑哪些地方能够安排怪物，哪些作为据点刷多轮怪物，哪些地方作为怪物入场点」。
编组全部取 `InfernoSquads`（G01–G12），自查每波 ≤ 3 种、远程 ≤ 3、同时在场 ≤ 10。

### 4.1 驻守点（开局就站在场上）

路遇小队（`AsRoadside`，不计目标、不落宝箱），第一波条目和站位都是埋伏（Ambush）：玩家先看见一队守卫站在那儿，走近 / 开枪整组苏醒；第二波从熔岩爬上岸。

| 驻守点 | 位置 | 第一波（站着的） | 第二波 |
|---|---|---|---|
| 南堤头守卫 | D1 西头 (−14, −43) | 马面 + 祸斗 ×2 + 炭童 ×3 | 熔流伏兵（炭童 ×4 爬出、毕方栖柱） |
| 北堤头守卫 | D2 西头 (4, 63) | 炮仗傀儡 ×2 + 祸斗 + 炭童 ×4 | 熔流伏兵 |
| 东堤头守卫 | D3 南头 (74, −4) | 马面 + 祸斗 ×2 + 炭童 ×3 | 熔流伏兵 |
| 火坛前守卫 | D5 南头 (118, 6)，两座火坛前 | 马面 + 祸斗 + 炭童 ×4 | 岸边伏鼍（火鼍 + 炭童 ×3 爬出） |

另有路遇 a「灰坡余烬」（眺台坡脚的渣堆，炭童余烬起身）当出生后的第一战。驻守点都不在出生点的视线里。

### 4.2 据点（多轮）

四个必清据点各 3 波，波次从场地自己的站位进场，合乎地形：

- ① 玄武柱林：毕方栖在柱顶（埋伏）、炭童从渣堆余烬起身 → 祸斗从三条 lane 的增援门冲进来 → 马面从柱台沿跃下。
- ② 火口丘：炮仗傀儡一窝埋在火口北缘 → 铁牛从锥脚东西两头的增援门走出、马面埋在南缘 → 神火鸦群飞临锥脚栖柱；火口和锥脚的间歇熔泉只在交战时喷。
- ③ 祝融残殿：傩巫在神像前跳傩（埋伏）、祸斗 / 炭童走增援门 → 毕方栖在残柱顶 → 精英马面从殿台沿跃下、飞鸦飞临。
- ④ 熔渠铸坊：火鼍 / 炭童从熔渠爬上岸、马面埋在东北岸 → 铜匠埋在范列后、炮仗埋在铸床上、炭童余烬起身 → 祸斗走增援门（炉塔后、两岸外侧）。

必清合计约 72 只（3-1 约 46），精英：主走法 2 只，都在终局据点。可选的烬穴守军约 11 只。

## 5. 布局变体

- **main 自灰坡入**：西南眺台出生 → 东北角祭坛。① 开场（给武器），③ 终局（两只精英，给保底精良武器）。
- **reverse 自火山口入**：东北角祭坛前出生 → 西南眺台上的新祭坛（NavMesh 烘焙后摆，只在逆行里在场）。③ 换成开场编制、给武器，① 换成终局编制（两只精英）、给保底精良武器。

## 6. 地标视线

出生 → 大火山烟柱；① 柱台 → 祝融像；D2 北堤 → 祝融像；③ 殿台 → 出口祭坛；② 火口丘缘 → 大火山。

## 7. 边界

没有空气墙：火山口崖（地形，崖面 > 70°）围住游玩区，软边界（落灰推回、白化）只兜底；熔岩在游玩区里，掉进去由 L7 托回。熔岩河从崖脚下穿出去。
