# 首领登场演出（电影运镜 → 第一人称开打）

2026-10-23。用户原话：「BOSS 还需要有出场演出，以及电影级运镜过渡到玩家的屏幕第一视角然后开始战斗」。

适用：Unity 版四个首领——旱魃（1-4 鸣沙山月牙泉）、鲲鹏（2-4 北冥冰台）、熔心魔将（3-3 铸范大坊 · 神范台）、火麒麟（3-4 祝融炉心）。
没有专属演出的首领（代理首领、参考首领、以后的新首领）自动用通用演出。

## 1. 目标

- **利落**：单场 6–10 s（实际 6.5–7.9 s）。射得爽优先，演出只交代「谁、在哪、多凶」，不讲故事。
- **连续**：最后一镜连续落回玩家眼睛，位置、朝向、视角插值到 Eye，最后一帧误差为零，不硬切。落地时玩家视线已经对准首领。
- **可跳过**：第一次看要先看满 1.5 s 才能跳；看过之后一开始就能按住交互键跳过。跳过同样平滑落回第一人称。
- **安全**：演出期间首领和小怪不攻击、不可选中，玩家不受伤。时间缩放只走 TimeScaleArbiter。演出被打断时（玩家阵亡、场景卸载、首领丢失、超时）一切复原。

## 2. 结构

代码在 `unity/Assets/Game/Scripts/Bosses/Intro/`：

| 文件 | 作用 |
|---|---|
| `BossIntroScript.cs` | 数据：`BossIntroScript`（[Defs] 注册，id = BossDef.id）、`IntroShot`（一个镜头）、`IntroPoint`（锚点 + 偏移）、`IntroCue`（时间轴事件）、通用演出 `DefaultBossIntro` |
| `BossIntroDirector.cs` | 导演（MonoBehaviour，挂在 BossEncounter 物体上）：接管 / 镜头 / 事件 / 跳过 / 交接 / 复原 |
| `BossIntroContext.cs` | 脚本看到的上下文：锚点解析、决斗坐标系、首领体型，以及给事件用的动作（播动作、慢动作、名字卡、模型临时位移 / 缩放 / 发光） |
| `IntroMath.cs` | 纯数学（EditMode 测试直接测）：缓动、姿态混合、环绕插值、交接误差、决斗坐标系、视线转向、单镜求值 |
| `CinematicOverlay.cs` | UI Toolkit 的 Overlay 层：上下黑边、电影式名字卡（底下垫一团径向淡墨，亮背景上也读得清）、「按住 F 跳过」。同层的全屏闪光每次播放都会 BringToFront，这一层每帧再提到最前，黑边不被闪光染色 |
| `BossIntroLog.cs` | 存档段 `cinematics`：看过哪些首领的演出（跟当前档） |
| `BossIntroDevCommands.cs` | 调试命令 `boss_intro_reset`（忘掉看过）、`boss_intro_policy`（开关轮换） |

每个首领的镜头脚本放在各自目录：`Hanba/HanbaIntro.cs`、`KunPeng/KunPengIntro.cs`、`Warlord/WarlordIntro.cs`、`Qilin/QilinIntro.cs`。

不用 Timeline / Cinemachine：worktree 里不能生成 `.playable` 资产，而且镜位要跟着场地锚点和首领实时位置走。镜头表写成代码，和 HanbaCinematics 的做法一致（D20 允许代码驱动）。

### 2.1 共享文件里的钩子（都是一两行）

| 文件 | 改动 |
|---|---|
| `Encounters/BossEncounter.cs` | `Begin()` 里 `BossIntroDirector.Play(this)`。有演出时不画预警圈、不弹提示；`Warning` 阶段按 `intro.SpawnDue` 刷首领，演出没了退回 `warnSeconds` 计时；有演出时不补横幅 |
| `Bosses/BossBrain.cs` | 生成时 `Directs(this)` 为真就不打登场横幅（名字卡由演出打）；`StepIntro` 里 `HoldsIntro(this, overtime)` 为真时，登场动作播完也继续待在登场里（不可选中、不出招），保险上限 25 s |
| `Enemies/EnemyAI.cs` | 「玩家阵亡 → 待机」的分支加上 `BossIntroDirector.HoldsEnemy(this)`：演出期间所有敌人待机，正在登场的首领除外 |
| `UI/GameUI.cs` + `UI/Hud.cs` + `UI/Toolkit/UIToasts.cs` | `GameUI.HudHidden`：HUD 层的目标不透明度多一个条件；提示条（toast）层同样整层淡出（出 0.15 s、进 0.45 s），计时照走 |
| `Bosses/Qilin/QilinCauldron.cs` | `Rattle(amount)`：把吊鼎现有的摆动幅度抬到 amount 倍，之后照常回落 |
| 五个首领套件 | 开头一行 `BossIntroDirector.Policy = BossIntroPolicy.Never`（测试开关） |

CameraFeel、WeaponController、PlayerMotor 都没改：
- **镜头**：导演的执行顺序是 −35，CameraFeel 是 −40，所以导演的 LateUpdate 在 CameraFeel 之后直接覆盖主相机（Head）的世界位姿和 FOV。
- **武器**：收枪 / 抬枪动的是枪模叠加相机（只渲染 FirstPerson 层）：上仰 55°、抬高 0.22 m 后停用，枪自然沉出画面；抬枪反过来。这样碎刃、技能手这些第一人称层的东西也一起处理，不用找每把枪的 rig。
- **输入**：导演每帧（−35，在 PlayerMotor / WeaponController / HeroSkills / Interactor / PetOwner 之前）把 `motor.inputEnabled` 关掉，同时加一个 `MotorLock.All` 修饰器。暂停后 GameSession 重新打开输入，下一帧也会被关回去。

## 3. 时间轴

```
0 ─ BossEncounter.Begin：接管（锁输入、无敌、小怪待机且不可选中、HUD 和提示条淡出 0.15 s、收枪 0.25 s、黑边 0.5 s 拉出）
│   第一镜 blendIn：从玩家第一人称的画面平滑拔起（玩家看不见的时候，视线已经转向首领出生点）
├ spawnAt ─ SpawnDue → BossEncounter 刷首领；首领自己的登场（BossIntroDef：动作、吼声、HanbaBrain/KunPengBrain/... 的 IntroTick）从这一刻起跑
├ 镜头表逐镜播；事件按时刻触发（重复事件在 [at, until) 里每 every 秒一次）
├ ShotsSeconds ─ 落地：landSeconds 秒，smootherstep 把姿态从最后一镜的终点（仍实时跟着锚点）插值到 Eye + CameraFeel.Fov
│     回程远时按路程拉长（IntroMath.LandStretch：25 m 内不变，最多 ×1.45；3-3 的 55 m 回程约 1.9 s）
│     回程走摇臂弧：中段抬起路程的 8%（最多 4 m），lift × 4w(1 − w)，起点 / 终点都是 0；开始时沿途 9 点查碰撞，挡着就换不抬 / 抬两倍
│     手持晃动 / 震屏的权重 = 1 − 落地权重；视线平滑跟着首领身体
│     55% 收黑边 · 50% 收名字卡 · 60% HUD 淡入（0.45 s）· 72% 抬枪（0.4 s，ease-out）
└ 落地 100%：这一帧写进去的就是 Eye（Blend 在 w = 1 时原样返回目标）→ 记交接误差 → Head 归零交还 CameraFeel
    → 解锁输入、0.5 s 无敌余量、放开小怪、撤慢动作、清震屏、记「看过」、脚本 onEnd
    → 下一帧首领 IntroDone，喘 BossIntroDef.firstRest 秒后出第一招
    → 收尾：抬枪 / 黑边动画播完后导演自毁
```

所有镜头运动按游戏时间走：慢动作时镜头一起放慢，暂停时演出停住。UI 动画和「按住跳过」按真实时间走。

## 4. 镜头表

### 4.1 坐标

`IntroPoint(anchor, x, y, z)` 的偏移在**决斗坐标系**里：

- **+Z**：演出开始那一刻，从玩家指向首领出生点（水平）。
- **+X**：玩家的右手。
- **+Y**：上。

所以「首领正前方 8 m、偏右 3 m、离地 1.5 m」就写 `At(Boss, 3, 1.5, -8)`。`Sized(...)` 会把偏移乘首领体型系数（身高 / 4 m，夹在 0.6–3.5），特写会按体型自动拉远拉近。

### 4.2 锚点

内置锚点（实时）：

| 锚点 | 位置 |
|---|---|
| `spawn` | 首领出生点（地面） |
| `center` | 场地中心 |
| `boss` | 首领根节点 |
| `body` | 首领胶囊中心 |
| `head` | 首领头骨 |
| `model` | 模型视觉中心：模型根节点 + 半个身高。魔将从空中砸落、麒麟跃出熔池时胶囊不动、模型在动，跟拍用这个 |
| `player` | 玩家脚底 |
| `eye` | 玩家眼睛 |

首领生成之前，首领类锚点都退回出生点附近。

脚本自己的锚点：鲲鹏有 `hole`（冰窟圆心、水面高度）和 `breach`（鲲升起的位置）；火麒麟有 `pool`（熔池圆心）和 `cauldron`（吊鼎）。

### 4.3 单镜

`IntroShot.Make(name, seconds)` 后面可以接这些设置：

| 设置 | 作用 |
|---|---|
| `Move(a, b)` | 机位从 a 走到 b。默认直线，`.Orbit()` 时绕看点环绕：水平角度插值，距离和高度线性插值，不穿过看点 |
| `Look(a, b)` | 看点从 a 走到 b |
| `Fov(a, b)` | 竖直视角 |
| `Roll(a, b)` | 横滚 |
| `Ease(e)` | Linear / In / Out / InOut / Smoother |
| `BlendIn(s)` | 开头 s 秒从上一镜的终点（第一镜 = 第一人称）平滑接过来；0 = 硬切 |
| `Handheld(k)` | 手持晃动 0–1：位移 3.5 cm、转角约 0.5°，0.55 Hz Perlin |
| `NoClearance()` | 关掉避让 |

避让默认开着：从看点往机位打一个半径 0.3 m 的球，被世界几何挡住就把机位收到挡板前。收得快、放得慢，不会来回跳；机位离地不足 0.45 m 时会抬起来。

### 4.4 事件

`IntroCue` 有这些种类：

| 事件 | 作用 |
|---|---|
| `Act(at, anim, seconds)` | 首领播一个动作 |
| `Sfx(at, id, anchor, vol, pitch)` | 在锚点上放音效 |
| `Shake(at, strength, seconds)` | 震屏 |
| `SlowMo(at, scale, realSeconds)` | 慢动作，经 TimeScaleArbiter，优先级 = 顿帧 + 60 |
| `NameCard(at, seconds)` | 电影式名字卡：左下、黑边之上，依次是场地小字、首领名（标题字体，鎏金）、金线、称号 |
| `Flash(at, color, seconds)` | 闪屏 |
| `Call(at, label, ctx => …, essential)` | 任意代码 |
| `Every(from, until, every, label, ctx => …)` | 重复事件 |

`essential = true` 的事件在跳过时也会补放，留给改场地状态的那种；其余事件跳过就作废。

脚本还有三个钩子：`onBegin`、`onTick(ctx, dt)`（每帧，Update 里）、`onEnd`。onEnd 在正常结束、跳过、打断时都会调一次。

`ctx.OffsetModel / ScaleModel` 给首领模型加的是**这一帧**的临时位移 / 缩放。导演在 LateUpdate 加上，下一帧 Update 一开头（首领自己写模型根节点之前）撤掉。所以首领每帧重写也好、不写也好，都不会累积。

### 4.5 自检

`BossIntroScript.Validate()` 检查这些（EditMode 测试逐个跑）：

- 有镜头，每镜时长为正。
- 每个点都有锚点，锚点有定义。
- 视角在 10–120°。
- 生成时刻在镜头表里。
- 落地 0.6–3 s，跳过落地 0.3–2 s。
- 整段 4–11 s；四个专属演出另外要求 6–10 s。
- 事件时刻在演出内。
- 有名字卡。

## 6. 跳过

- 按住交互键（键鼠 F、手柄 Y）0.6 s 跳过。提示在右下黑边里，按住时下面的细条会填满。
- 第一次看要先看满 1.5 s（真实时间，不含暂停）。之前按住无效，提示也不显示。
- 看没看过记在存档段 `cinematics`（`BossIntroLog`，跟当前档；调试局记在调试档）。正常看完或跳过都会记；打断不记。
- 跳过之后：
  - 后面的镜头和非必需事件作废，必需事件立刻补放。
  - 首领如果还没生成，立刻生成。
  - 从当前画面用 0.7 s 落回第一人称，同样是 smootherstep，最后一帧零误差。
  - 名字卡还没打的话，交还后补一张普通横幅。
- 跳得早时，首领自己的登场动作（魔将砸落、麒麟跃出、鲲升起）会在第一人称里播完。这期间它不可选中、不出招，玩家已经能动，和以前没有演出时一样。

## 7. 安全与复原

| 情况 | 处理 |
|---|---|
| 首领 | 登场里本来就不可选中、霸体。登场动作播完后由 `HoldsIntro` 继续留在登场里，直到镜头交还。保险上限：超过 BossIntroDef.seconds 25 s 后不再等 |
| 小怪 | `EnemyAI` 走「待机」分支：打断招式、停下、熄灭前摇光，交还后从初始状态重新开始。可选中的小怪设为不可选中，交还时复原——每帧（Update 和 LateUpdate）都扫一遍，开演时还在出生 / 钻地、演出里才变回可选中的小怪也收进来 |
| 玩家 | 每帧续 0.3 s 无敌，交还时再给 0.5 s 余量 |
| 时间 | 演出慢动作经 TimeScaleArbiter 申请，按真实秒数撤销，交还 / 打断时一定撤销 |
| 玩家阵亡 | 立刻复原（镜头交还 CameraFeel、枪模复位、黑边拿掉、HUD 回来），输入保持关闭，交给 PlayerVitals / GameSession |
| 场景卸载（导演在首领关物体上，跟着销毁） | OnDisable 里同样复原。输入按开演前的状态恢复：换场景中（base = Transition）不碰，有模态时不开 |
| 首领丢失（生成失败 / 被删 / 演出里死了） | 直接走 0.7 s 落地 |
| 超时（比计划多 8 s） | 打断 |
| 新的演出顶掉旧的 | 旧的打断 |
