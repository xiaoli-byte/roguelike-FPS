色彩：
- 自然：青绿草甸（带黄、紫、粉野花）、灰褐岩坡、雪线以上纯白积雪、冰川的青白、圣湖的绿松石色、深蓝高原天空、大朵白云投下的移动云影。
- 人造物：白墙、赭红墙带、黑色梯形窗套、彩色窗楣布、木构赭红；只有宗教建筑用金（白塔塔刹、拉则顶）。经幡是五色：蓝、白、红、绿、黄。
- 灵火：据点的灵火坛未点亮时是暗的余烬，点亮后是青金色火焰（「灵火破晓」）。
- 腐化（敌人和首领设计时再定）：要能和青绿 / 白 / 蓝的底色一眼分开。

宗教元素的处理：白塔、经幡、玛尼石、转经筒只做场景和地标，**不做成可破坏物、不做成敌人来源、不放在射击靶位上**。玛尼石上的刻文用抽象纹样，不写真实经文。灵火坛是游戏自己的设定物，不借用真实宗教器物。

## 2. 4-1 折多垭口·天路草甸（开放盆地）

> 道班外就是一整片高原盆地：冰川河从北面的冰舌流下来，穿过草甸流出西南的峡谷。
> 碉楼寨、白塔、牧民营地、圣湖、冰川口和经幡山头散在盆地各处，先去哪里由玩家决定；
> 点亮其中 3 处的灵火，东北的垭口出口就会打开。

### 2.1 开放的规则

1. **看得见就去得了**：盆地内除了湖的深水区、陡于 40° 的崖壁，都能走到。整张图只有一种限制：爬到四周雪山的高处会进入风雪区，被风推回盆地（软边界，有画面和文字预警）。盆地内没有空气墙。
2. **地标当引力**：每个据点都有一个从远处就能认出的地标（碉楼、白塔、黑帐篷群、湖面、冰舌、经幡山头的拉则和桑烟）。贡嘎是全图的方向参照，北偏东，盆地大部分地方都看得见。
3. **三角法则**：据点之间放起伏的小丘，走近的时候小丘先挡住、再露出下一个目标（例如出生点附近的小丘挡住白塔，翻过去才露出白塔和河谷）。
4. **多条路通向任何地方**：天路（车路，最好走，最长）、牧道（细土路，连据点）、河谷、山脊高路（冰川口 → 垭口，要二段跳）、直接翻草坡。
5. **兴趣点密度**：据点之间每走 40–60 m 就有一个能看到的小兴趣点（玛尼堆、残碉、温泉、塔林、牦牛群、修行洞），让跑图不空。

### 2.3 路线

| 路线 | 走法 | 特点 |
|---|---|---|
| 天路 | 出生 → 盆地南缘 → 牧民营地 → 东坡盘山四折 → 垭口 | 车路，6 m 宽，坡度 ≤ 10%，最好走也最长；盘山段靠山一侧有挡土墙 |
| 牧道 | 白塔 ↔ 碉楼寨（过木桥）、碉楼寨 ↔ 圣湖、圣湖 ↔ 冰川口、白塔 ↔ 经幡山头、经幡山头 ↔ 冰川口、营地 ↔ 经幡山头 | 2.4 m 土路，提示方向但不强制 |
| 河谷 | 沿冰川河从出生点一路往上游走到冰川口 | 河谷低于草甸 4–5 m，河可以涉水 |
| 山脊高路 | 冰川口 → 北侧山脊 → 垭口 | 视野最好，几处要二段跳 |
| 翻草坡 | 任意方向 | 盆地内草坡都 ≤ 40°，直线去任何看得见的地方 |

### 2.4 动态环境（建议，待定）

**高原雷暴**（经幡山头或垭口）：乌云压过来，地面先出现雷击预警圈，落雷对玩家和敌人都造成雷殛；站在拉则旁会被引雷。和 1-1 沙暴（压视线）不重复，也和雷殛元素、鼯（雷）对得上。检视页已有天气演示（第三轮）；夔只在雷暴时现身，所以雷暴同时是夔的出场条件。

### 2.5 风的引导（飞廉）

飞廉是风神，整片盆地的风都被它吸向冰川口：**越靠近飞廉，风的痕迹越明显**，玩家不看地图也能顺着风找到它。风场在 `src/world/plateau/wind.ts`：基础风向（偏东）+ 指向巢穴的吸引，强度从巢穴外 300 m 的 0 平滑升到 30 m 内的 1。

| 离飞廉 | 风强 | 看得到什么 |
|---|---|---|
| 300 m 外（出生点、碉楼寨、牧民营地） | 0 | 经幡、桑烟、草浪都按基础风向轻轻飘；冰川口上空的风涡柱从盆地大部分地方都看得见 |
| 300–150 m（白塔溪谷、经幡山头、圣湖东岸） | 0–0.5 | 经幡、桑烟、草浪开始偏向冰川口，经幡飘得更急；草浪成片朝冰川口推过去 |
| 150–60 m（冰川口下方的冰湖、冰碛垄） | 0.5–0.9 | 空中出现顺风飞的白色风痕；地面刮出顺风的雪 / 碎石条纹，草被刮秃 |
| 60 m 内（冰舌顶上的擂台） | 0.9–1 | 冰面立起一排排顺风的风蚀冰脊，尖头都指向飞廉；风涡柱就在头顶 |

平面图打开遇敌区时，白箭头画出风向，越靠近飞廉越长越亮。

## 3. 网页检视页

- 打开：`npm run dev` 之后访问 `/plateau-lab.html`（launch.json 的 `dev` 配置是 5199 端口），或在白盒检视页 `/whitebox-lab.html` 的「章节」下拉里选「川藏高原」。
- 操作：点击画面锁定鼠标；WASD 移动，空格跳（可勾选二段跳），Shift 冲刺，G 切换飞行（飞行时空格升、C 降、Shift 加速），M 切换平面图，Esc 解锁鼠标。右侧面板可以一键跳到各据点和机位。
- 自动验收（面板里显示）：
  - 开放度：盆地可走面积占比、从出生点能走到的面积占比、每个据点和垭口是否走得到；
  - 地标视线：出生点能看到哪些地标、每个据点能看到经幡山头；
  - 据点之间的距离与跑图时间；天路最大坡度；帧率和绘制批次。
