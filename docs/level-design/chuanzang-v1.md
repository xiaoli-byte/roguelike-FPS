### 2.1 开放的规则

1. **看得见就去得了**：盆地内除了湖的深水区、陡于 40° 的崖壁，都能走到。整张图只有一种限制：爬到四周雪山的高处会进入风雪区，被风推回盆地（软边界，有画面和文字预警）。盆地内没有空气墙。
2. **地标当引力**：每个据点都有一个从远处就能认出的地标（碉楼、白塔、黑帐篷群、湖面、冰舌、经幡山头的拉则和桑烟）。贡嘎是全图的方向参照，北偏东，盆地大部分地方都看得见。
3. **三角法则**：据点之间放起伏的小丘，走近的时候小丘先挡住、再露出下一个目标（例如出生点附近的小丘挡住白塔，翻过去才露出白塔和河谷）。
4. **多条路通向任何地方**：天路（车路，最好走，最长）、牧道（细土路，连据点）、河谷、山脊高路（冰川口 → 垭口，要二段跳）、直接翻草坡。
5. **兴趣点密度**：据点之间每走 40–60 m 就有一个能看到的小兴趣点（玛尼堆、残碉、温泉、塔林、牦牛群、修行洞），让跑图不空。

### 2.4 动态环境（建议，待定）

**高原雷暴**（经幡山头或垭口）：乌云压过来，地面先出现雷击预警圈，落雷对玩家和敌人都造成雷殛；站在拉则旁会被引雷。和 1-1 沙暴（压视线）不重复，也和雷殛元素、鼯（雷）对得上。检视页已有天气演示（第三轮）；夔只在雷暴时现身，所以雷暴同时是夔的出场条件。

### 2.5 风的引导（飞廉）

飞廉是风神，整片盆地的风都被它吸向冰川口：**越靠近飞廉，风的痕迹越明显**，玩家不看地图也能顺着风找到它。风场在 `src/world/plateau/wind.ts`：基础风向（偏东）+ 指向巢穴的吸引，强度从巢穴外 300 m 的 0 平滑升到 30 m 内的 1。

| 离飞廉 | 风强 | 看得到什么 |
|---|---|---|
| 300 m 外（出生点、碉楼寨、牧民营地） | 0 | 经幡、桑烟、草浪都按基础风向轻轻飘；冰川口上空的风涡柱从盆地大部分地方都看得见 |
| 300–150 m（白塔溪谷、经幡山头、圣湖东岸） | 0–0.5 | 经幡、桑烟、草浪开始偏向冰川口，经幡飘得更急；草浪成片朝冰川口推过去 |
| 150–60 m（冰川口下方的冰湖、冰碛垄） | 0.5–0.9 | 空中出现顺风飞的白色风痕；地面刮出顺风的雪 / 碎石条纹，草被刮秃 |
| 60 m 内（冰舌顶上的擂台） | 0.9–1 | 冰面立起一排排顺风的风蚀冰脊，尖头都指向飞廉；风涡柱就在头顶 |

平面图打开遇敌区时，白箭头画出风向，越靠近飞廉越长越亮。

### 3.1 开放的规则

1. **看得见就去得了**：除了河道深水和陡于 40° 的崖壁，都能走到。四周靠地形：坡顶往外是越来越陡的山，爬高了起大风，被吹回峡谷（软边界，同 4-1 的风雪）；上下游的地图边缘河谷收窄成深水石槽。没有空气墙。
2. **垂直分层**：每块岸地都分层，每一层至少两条路上下。

   | 层 | 相对河面 | 有什么 |
   |---|---|---|
   | L0 河面 | 0–3 m | 下游河滩（涉水）、河心跳石、江嘴尖的卵石滩、磨坊 |
   | L1 中层台地 | 15–22 m | 两座桥头、江嘴下层岩台、两条溜索的落点、栈道下段、伸臂木桥 |
   | L2 高台 | 44–56 m | 甲居寨坡、江嘴碉楼、绝壁驿站、藤索吊桥 |
   | L3 坡顶 | 70–85 m | 出生点（西岸）、出口古驿道（东岸） |

3. **地标当引力**：江嘴碉楼立在两条河中间的台地上，三块岸地都看得见，是全图的方向参照（同 4-1 的经幡山头）；铁索桥从西岸大部分地方都看得见；甲居寨坡的白房子、东岸绝壁上的栈道和驿站从对岸都看得清。
4. **每两块岸地之间至少两种过法**（见 3.3），高、中、低三层都有过河点。任何一个过河点断掉（落石、涨水、雷电），所有据点仍然走得到——自动验收会逐个断开检查。
5. **掉进急流不会死**：被冲到下游河滩，河滩两岸都有路回到上面。

### 3.5 领主 · 大鹗（③ 江嘴）

西山经·钟山：钟山之子鼓与钦䲹杀葆江于昆仑之阳，帝戮之钟山之东的瑶崖，钦䲹化为大鹗，「其状如雕而黑文白首，赤喙而虎爪」。雷暴把它从瑶崖上惊醒，它把巢搬到了江嘴的绝壁上。

- 体型：体长约 5 m，翼展约 16 m；白首、黑纹翅、赤喙，腿是虎腿虎爪；弱点（紫红雷光）在胸口和翼根。
- 擂台：汇口上空，半径约 90 m，铁索桥、江嘴、东岸栈道都在擂台里——从任何岸地、任何高度都能打它。
- 它做什么：高空盘旋 → 俯冲抓人（地上先出影子）；落在铁索桥上用虎爪撕桥板、抓着铁链摇桥；回巢；停在碉楼顶上俯瞰；玩家坐溜索时追着扑。

| 环境 | 玩家怎么用 | 效果 |
|---|---|---|
| 桥头雷桩 | 雷暴时雷桩会攒电；打响雷桩，把电送进铁链 | 抓着铁链的大鹗被电晕、掉向河面，几秒后再飞起来；桥上的玩家也会被电，要先下桥 |
| 溜索锚桩 | 打断锚桩，钢索弹起 | 抽中正从索下掠过的大鹗，缠住一侧翅膀坠河；这条溜索之后要等重新架好 |
| 鹗巢危岩 | 巢上方的危岩用木楔撑着，打掉木楔 | 落石砸中巢里的大鹗（大输出窗口），也把巢砸塌一半 |
| 碉楼烽火 | 点燃江嘴碉楼（和寨坡碉楼）顶上的烽火 | 浓烟遮住它的视线，它在烟里乱飞，打不中人 |

### 3.6 动态环境

| 环境 | 规则 | 改变哪些路 |
|---|---|---|
| 雷暴 + 铁索导电 | 复用 4-1 的高原雷暴；铁索桥、溜索钢索、碉楼都是导体，落点 8 m 内有导体就劈导体。劈中铁索桥时整座桥带电约 4 秒（铁链发紫红光），桥上的人被电 | 雷暴时走铁索桥要看准空档，或者改走溜索 / 河滩 |
| 峡谷风 | 风顺着峡谷往上游吹（谷风），每隔 20–30 秒起一阵 5 秒的强阵风，峡谷越窄越强；经幡和草先被吹起来 | 顺风坐溜索更快、逆风更慢；起跳时被吹偏；桥上会被推 |
| 落石 | 绝壁下方的落石区定时落石，地上先出 1.5 秒的预警影子；栈道 A 有两段可以被砸断 | 栈道断了改走骡道；鹗巢危岩是领主战的机关 |
| 涨水 | 上游放水，水面 8 秒内涨 1.8 m，持续约 20 秒再退 | 河滩涉水、河心跳石、栈道 A 下段的卵石滩被淹；站在跳石上会被冲走 |

### 3.8 彩蛋 · 灵宠飞渡

带着会飞的灵宠（[pet-system.md](../pet-system.md) 里的精卫、重明鸟、应龙）走到峡谷高处的**风马旗台**，按 **F**：
灵宠飞到面前、灵火一闪变大，俯冲下来；燎双手抓住它的爪子被带离地面，镜头拉到第三人称，在峡谷上空滑翔。

| 项 | 规则 |
|---|---|
| 起飞台 | 三处风马旗台（高高的风马旗杆 + 玛尼堆，从对岸也看得见）：西岸坡顶（出生点旁）、江嘴碉楼旁、古驿道山口。平面图上是青色菱形 |
| 条件 | 随身灵宠里有会飞的（精卫、重明鸟、应龙）；没有就提示「要有会飞的灵宠才能飞渡」。地面灵宠不行 |
| 平时跟随 | 灵宠有自己的位置，在燎的侧前方约 31° 、3–4 m 远（个子越大越远、画面窄或个子大时往里收，保证整只在画面里），比眼睛略高，跟着低头抬头上下挪一点。视角小幅转动时它留在原地，像真东西一样在画面里滑过去，再慢慢靠回侧前方；跑出画面边缘 0.25 秒（猛甩视角时等视角停下）或挡到准星正前方，才绕个弧飞回最近那一侧——要换到另一侧时从身后绕，不横穿视线；持续转视角时按转速提前量追，不会一直落在画面外。走路时按跟随位自己的速度加提前量并排往前飞，不拖在后面；贴着坡走、那一侧是山壁就换到另一侧。运动有加速度上限（60 m/s²），起步、急停、掉头都是弧线；离眼睛至少约 2 m、离地至少约 1 m（照当前速度往前看 0.4 秒，要擦到坡就提前抬高），不进房子。飞得快朝飞的方向、转弯往里侧倾，悬停时身子直一些、快扇翅膀，平飞时一阵扇一阵滑，下滑时收翅；隔几秒回头看燎一眼 |
| 演出 | ① 起势 1.2 秒：镜头从眼睛沿弧线先后退、再绕到身侧（不会穿过燎的身体），灵宠从侧前方飞回来、绕着燎螺旋上升，一路洒灵火火星 → ② 化形 1.3 秒：灵宠悬在前上方，灵火从四周收进它身上，被灵火光罩包住、带回弹地变大（3.6–4.6 m 高），炸开的那一下有闪光、地面冲击环、扬尘和四散的羽毛 / 鳞光 → ③ 擒起 1.1 秒：灵宠绕到身后、俯冲过头顶，燎起跳把双手举成 V 字，爪子正好落到手上，人被提起来，镜头转到身后偏右 → ④ 滑翔（翅尖拖出风痕，越快视野越宽） → ⑤ 落地 2.2 秒：灵宠猛扇翅膀刹住、把人放到地上（扬尘 + 冲击环），再飞高、缩回原样（一圈光点）飞回侧前方的跟随位，镜头沿弧线回到眼睛 |
| 镜头与穿模 | 镜头离燎的头不到 1.4 m 时不画燎的模型；镜头和燎之间被崖挡住时往前推；滑翔离地 8 m 内自动拉平减速，前方有坡就抬高越过；落地前先刹住再放人，不会一头扎进地里 |
| 滑翔 | 鼠标或 A / D 转向，W 俯冲（更快、掉得更快），S 拉平（更慢、掉得慢）；峡谷阵风往上托（峡谷风 3.6 的另一个用处）；飞出坡顶会被风吹回峡谷；空格中途松手，自己掉下去 |
| 三只的区别 | 精卫最小、掉得最快（约 13 m/s，下沉 1.9 m/s）；重明鸟中等（约 14 m/s，1.6 m/s）；应龙是神兽，最快最稳（约 16.5 m/s，1.1 m/s），抓的是前爪 |
| 用途 | 彩蛋和捷径：从西岸坡顶一口气飞到东岸约 20 秒，比走铁索桥 + 栈道快；不能往上爬，只能从高往低，所以不会替代骡道和桥 |

网页检视页里用面板「随身灵宠」模拟玩家带着哪只（网页版没有灵宠系统，模型是 Unity 那套发布到 `public/assets/characters/` 的骨骼模型，动作全部程序化）。
