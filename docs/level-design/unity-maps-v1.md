# Unity 正式关卡与第一章 Boss 设计（v1 草案，2026-10-17）

Three.js 版验证了玩法与题材；Unity 是正式开发，这份设计不以 V2 平面图为蓝本，而是对它做取舍：
保留「线性主线 + 大场地 + 两层以上高差 + 地标导航」这些被验证有效的规则，丢掉「平地 + 城墙围合的切角八边形庭院」——
第一章五张图都是这一个模板，正是「刻出来的」观感的来源。

## 0. 设计原则

1. **地形先于建筑**：场地的边界、高差与掩体首先由地形本身给出（沙丘脊、雅丹岩身、河床陡坎、冰崖），建筑是嵌在地形里的点缀与地标，不再拿墙围出房间。
2. **每张图一个空间母题**，同章内不重复：开阔（远景、长视线）→ 收紧（走廊、伏击）→ 城市（屋顶层、街巷），节奏随章节推进。
3. **地标导航**：每个场地入口都能看到下一个目标（烽燧、巨像、寺塔、冰瀑），出口用光与色引导，不靠 HUD 箭头。
4. **三层高度**：地面层、掩体 / 台阶层（1.2–2.6 m）、俯射层（2.5–4 m，坡道可达，二段跳只是捷径）；至少一条「高路」能绕到敌人背后。
5. **动态环境服务于战斗**：沙暴压缩视线、流沙改变走位、冰面打滑——每张图最多一个，且有明确的预警。

|---|---|---|

| 移速 | 约 7.5 m/s | 过渡段 15–30 m（2–4 秒）；场地 40–60 m |

## 1. 第一章 · 赤沙古道（三张图 + Boss）

章节叙事：商队沿古道穿过戈壁 → 风蚀雅丹里迷失 → 抵达被沙吞没的丝路古城 → 城下干涸的月牙泉，旱魃在那里沉睡。
色彩：赭红砂岩、黑戈壁、旧金；敦煌壁画色（石绿、朱砂、青金）只用在人造物上；腐化之火 = 白金日光 + 热浪扭曲。

## 2. 第二章 · 冰瀑栈道（首张正式地图）

## 3. 第一章 Boss · 旱魃

**定位**：第一章腐化的源头。传说她所到之处赤地千里。她用日火灼烧敦煌飞天（邪飞天），把古城的人、兽、石像变成沙魇。

**外形**：悬浮的干瘦女神，高约 4.5 m（身体）+ 背后日轮直径 6 m。剪影要点是 **细长的肢体 + 巨大的白金日轮 + 拖地的焦黄残衣**。皮肤像龟裂的旱地，裂缝里透出白金色的光。
配色：焦黄、炭黑、白金日光，只在裂缝和日轮处发光。读图距离 40 m 以上要一眼认出。

**场地**：干涸月牙泉。
- 地下巨穴约 80 × 70 m，月牙形泉床下沉 1.5 m，泉床内侧是一块高 3 m 的岩岛。
- 月牙阁在泉的凸侧，高 6 m 二层台。
- 顶部裂缝的日光柱会随阶段移动。

**核心机制：日晒与荫蔽**
- 「烈日」期间，暴露在日光柱和日轮直射下的玩家会持续叠加「灼烧」。
- 躲进岩岛、月牙阁或沙丘的影子里可以消除。
- 影子由真实光照决定：Unity 的阴影贴图，加一次射线判定。旱魃移动日轮，影子会转向，安全区随之变化。这是 Three.js 版做不到、Unity 能做好的玩法。

| 阶段 | 生命 | 场地变化 | 招式 |
|---|---|---|---|
| 一 · 烈日 | 100–60% | 泉床还剩一圈浅水（踩水减灼烧） | **日轮扫射**：日轮聚焦成光束，沿地面扫过，躲进影子。**旱风**：扇形热浪推开玩家并扬沙。**沙魇**：召唤 3–4 个沙魇（第一章杂兵的沙化版）。 |
| 二 · 焦土 | 60–30% | 她把剩下的泉水吸干，泉床龟裂，裂缝间歇喷出热气（地面预警） | 新增 **焦裂**：手掌按地，裂缝沿直线蔓延后爆开。**飞天之殇**：召唤一名被腐化的邪飞天，给她加护盾，打碎琵琶即可解除。 |
| 三 · 赤地千里 | 30–0% | 日轮升到穴顶裂缝里，整个泉床成为日晒区，只剩月牙阁和岩岛有影子 | **日蚀**：日轮短暂熄灭（3 秒），旱魃的心口露出最后一滴泉水，那是弱点，伤害 ×3，这是输出窗口。之后日轮爆发强光，覆盖全场。 |

- **弱点**：心口的「泉珠」，只在日蚀和施法后摇时暴露。其余时间靠日轮挡在身前，从侧后方能打到身体。
- **动作**：悬浮漂移、日轮旋转、残衣与长发是弹簧骨。Three.js 版没有她，动作要原创：
  - 资产走管线：概念 → 3D → 绑骨。骨架用语义人形加长发、残衣链。
  - 基础姿态和招式由 Blender 脚本化关键帧，加运行时程序层（悬浮、日轮、弹簧骨）组合；需要的话补少量手工关键帧。

## 4. 技术方案

| 模块 | 做法 |
|---|---|
| 地形 | Unity Terrain（多块拼接）。高度场生成器：戈壁平原（低频起伏 + 干河床）、沙丘场（新月形沙丘，迎风缓背风陡）、雅丹场（沿主风向拉长、顶平侧陡的脊）、峡谷（V 形谷 + 阶地）。古道 / 栈道按样条压平。所有参数写在场景数据里，可重复生成；生成后美术在编辑器里继续雕刻、绘制 |
| 地形着色 | 自写 URP 地形着色器 `Spiritfire/StylizedTerrain`：与 StylizedLit 同一套分段光照、冷暗部、边缘光；4–8 层贴图按坡度、高度自动混合（沙 / 砾 / 岩 / 龟裂土；雪 / 冰 / 岩 / 冻土），手绘笔触的宏观色斑压掉平铺感 |
| 散布 | 按规则在地形上散布砾石、骆驼刺、经幡、碎冰等（坡度、高度、离路远近、密度图），用 GPU instancing |
| 动态环境 | 沙暴：体积雾 + 粒子 + 风场，驱动弹簧骨和散布物摇摆。流沙：地表下陷 + 拖拽力场。冰面：物理材质与角色控制器的摩擦参数 |
| 关卡数据 | 每张图一个 `LevelSpec` 资产：场地、高台、掩体、出生点、遭遇、地标、视线检查点。场景由它生成并能重新生成；手工微调用覆盖层保存，不会被冲掉 |
| 验收 | 自动检查：场地尺寸、高差可达（坡道 + 单跳；二段跳 / 冲刺只算捷径）、掩体数、地标从入口可见（射线）、主线可走（NavMesh 连通）、性能（三角面、绘制批次） |
