# 第四章 · 雪域天路 战斗设计 v1（怪物动作、领主演出、战斗）（2026-10-22）

> 范围：8 只雷魅（啸獭、天狗、獓狠 + 雷牦、举父、蛮蛮、连鼓灵、帝江、穷奇）、4-1 三领主（夔、飞廉、化蛇）、4-2 领主大鹗、4-4 终局雷泽雷神。
> 先在网页可玩版里实现和迭代（`src/world/plateau/play/`、`src/world/gorge/`、`src/world/haizi/`），之后烘焙进 Unity。
> 怪物定稿与建模见 [enemy-roster-v2.md](../art/enemy-roster-v2.md)「第四章」；地图见 [chuanzang-v1.md](chuanzang-v1.md)。

## 0. 原则

1. **射得爽**：后坐轻、反馈足。每一枪有命中闪白和数字，弱点有金色数字和放大的准星，击杀有专属的死法；硬直、眩晕、破防都是「奖励玩家」的时刻，不是惩罚。
2. **前摇读得出**：每个招式的预警由四层叠起来，越危险叠得越多：
   - **姿态**：招式独有的剪影（人立、伏低、举石、仰头、张翼），远处只看轮廓也认得出；
   - **发光**：弱点 / 雷纹在前摇里从暗到亮；
   - **地面预警**：落点圈、扫线、冲撞线，填满的那一刻正好出手；
   - **出手闪光**：真正出手前 0.25 秒，弱点上闪一下白星（只给「挨了会很疼」的招）。
3. **有节奏、有破绽**：每招都是「前摇 → 出手 → 收招」三段。收招是固定的破绽：怪停下、弱点朝外或放低。群怪靠**出手令牌**轮流出手，不会一起扑脸。
4. **开阔地远近夹击**：近战压迫（啸獭、天狗、帝江、獓狠）+ 远程（举父、蛮蛮）+ 辅助（连鼓灵）+ 游猎（穷奇）；掩体靠地形，不靠房间。
5. **本章的组合母题：雷魅带电，燎点火就炸**。雷魅在特定状态下「带电」（等同身上有雷殛），燎的火一碰就是焚雷；导体能引雷、风能借火、水能导电——环境和元素都能拿来反打。

### 0.1 招式时间轴（和 Unity BossMove 一致）

所有怪和领主的招式都写成同一种数据（`play/moves.ts` 的 `MoveDef`）：

| 字段 | 含义 |
|---|---|
| `id` | 招式 id = 动画状态名（烘焙片段、`<资产>.events.json` 都按它） |
| `windup` / `active` / `recover` | 前摇 / 出手 / 收招时长（秒）；前摇时长 = 地面预警填满的时长 |
| `cooldown` / `weight` / `minPhase` | 调度：冷却、抽招权重、最早哪个阶段可用 |
| `stunnable` | 出招中能否被硬直打断（默认能；领主的大招是霸体） |
| `events` | 招式内的时间点：`warn`（出预警）、`glint`（出手闪光）、`hit`（伤害判定）、`release`（放出投射物）、`land`（落地）、`end`（收招结束） |

网页可玩版按这张表驱动 AI 和动作；`play.dev.moveTable()`（试玩脚本的 `export` 场景把三张图的合起来）按 events.json 的格式（`{ clips: { <状态>: [{ at: 0–1, name }] } }`）导出全部出手时间点，生成的一份在 [`docs/art/ch4-move-events.json`](../art/ch4-move-events.json)。以后烘焙进 Unity 时，状态名、出手时刻都照抄这份。

## 1. 通用系统

### 1.1 受击的四层

| 层 | 触发 | 表现 | 对 AI |
|---|---|---|---|
| 受击 | 每一枪 | 命中处闪白；按命中方向的小抖动（头被打往后仰、侧面被打往另一边歪）；轻的怪打一枪顿一下 | 不打断（啸獭、帝江这种轻怪顿 0.12 秒） |
| 硬直 | 2 秒内累计的「韧性伤害」超过韧性值（弱点 ×2、爆炸 ×3） | 0.4–0.9 秒的踉跄：四足往侧面滑、双足后退一步、飞的在空中翻一下 | 打断当前招式（霸体招除外）、清掉预警 |
| 眩晕 | 封脉反应、各怪的专属反制（举父手中炸石、獓狠雷球引爆、穷奇滑翔被打下来、领主破防） | 头上一圈紫白火花；四足趴下抽搐、双足跪地、飞的掉到地上扑腾 | 停 1.5–4 秒；受到伤害 +25% |
| 死亡 | 血量归零 | 按死因分四种：**普通**（按体型倒地）、**弱点击杀**（头 / 弱点一甩、更快倒下、白闪）、**爆炸击杀**（被掀飞、在空中打转再落地）、**带电死亡**（倒下时把电放给 8 m 内最多 2 个同伴） | 尸体 3 秒后沉下去消失 |

### 1.2 带电与元素反应

元素和反应沿用正式游戏（[arsenal-expansion.md](../arsenal-expansion.md) 第 2 节，`src/combat/Reactions.ts`）：灼烧、雷殛、蚀化，两两成反应。网页版做简化实现（`play/elements.ts`），名字和效果对得上：

| 反应 | 组成 | 效果（网页版） |
|---|---|---|
| **焚雷** | 灼烧 + 雷殛 | 3 m 爆炸（周围吃 60%），雷弧跳到 8 m 内最多 4 个敌人并给它们挂灼烧；击退 |
| **熔金** | 灼烧 + 蚀化 | 对护甲 / 蓑毛中心 ×2；留 2.5 m 熔池 3 秒 |
| **封脉** | 雷殛 + 蚀化 | 眩晕 0.7 秒、减速 40%；首领吃「脉滞」受伤 +12% 4 秒，并打断非霸体的前摇 |

**带电**（本章规则）：下面这些状态的雷魅身上算有雷殛，燎的火一碰就是焚雷：

| 怪 | 什么时候带电 |
|---|---|
| 啸獭 | 在电网里（3 只以上相距 4 m 内） |
| 天狗 | 衔雷之后 8 秒（3 m 内落过雷） |
| 獓狠 | 角间雷球攒了电（≥ 1 份） |
| 举父 | 手里举着雷石的时候（雷暴里一直是雷石） |
| 蛮蛮 | 成对飞、电弧连着的时候 |
| 连鼓灵 | 雷心一直带电 |
| 帝江 | 胀大的时候 |
| 穷奇 | 吞雷之后 15 秒 |
| 夔 | 一直带电（雷兽） |
| 飞廉 | 风雷珠攒满时 |
| 化蛇 | 泡在通电的湖水里（雷泽雷神的二阶段、玩家的雷殛打在水里） |
| 雷泽雷神 | 拍腹前摇时腹鼓带电 |

**电会传**：带电的怪死掉时，把电放给 8 m 内最多 2 个同伴（它们也带电 6 秒）——一窝啸獭点着一只，焚雷 → 电传过去 → 下一个焚雷，能一路炸穿。

**本章的元素克制**：化蛇在水里时灼烧时长减半（湿身），雷殛 +50%（导电）；但玩家自己站在 6 m 内的水里，打出的雷殛会电到自己（5 点）。飞廉的龙卷风柱被火打中变成**火龙卷**（见 4.2）。

### 1.3 导体与引雷

- 导体：经幡杆、拉则、碉楼（4-1）；铁索桥、溜索钢索、雷桩、碉楼（4-2）；导雷石柱（4-4）。
- 落雷（天狗雷标、夔捶胸、雷暴、雷神拍腹）落点 5 m 内有导体，雷被导体引走；导体底下 2 m 溅电（12 点）。**站在导体旁 2–5 m 能躲雷**。
- 导体被劈中后带电 10 秒（发紫光）：带电的经幡杆旁 4 m 内落地的夔会被杆子回劈（硬直 + 200 伤害）；带电的导雷石柱可以被玩家引爆打雷神（4.5）。

### 1.4 出手令牌（群怪的节奏）

一片遇敌共用一组令牌：**近战扑击 2 个**（天狗扑咬同时只有 1 只）、**远程 2 个**（举父远投、蛮蛮扫线、天狗雷吠）。拿不到令牌的怪继续走位、绕圈、找掩体，不出手。玩家正被硬直 / 击飞时令牌冻结 0.6 秒（不连段到死）。

### 1.5 预警的颜色语言

| 颜色 | 意思 |
|---|---|
| 紫红 | 雷（落雷、电弧、电场） |
| 橙 | 落点（投石、大跳、扑击落点、冲撞线） |
| 青白 | 风（狂风锥、龙卷、风刃） |
| 蓝 | 水（水弹、浪、涨水线） |
| 白星 | 出手闪光：0.25 秒后就打 |

## 3. 八只雷魅

**分工总表**

| 分工 | 怪 | 节奏 | 玩家优先级 |
|---|---|---|---|
| 近战压迫·群 | 啸獭 | 一窝冲上来，单只脆；电网封地 | 先点哨兵，再用火炸电网 |
| 近战压迫·包抄 | 天狗 | 12–18 m 绕到身后；一只雷吠、一只扑，轮流来 | 背靠地形；打断雷吠 |
| 近战压迫·冲脸 | 帝江 | 鼓点越来越快地蹦过来，贴身胀爆 | 在它们挤在一起时打爆一只 |
| 近战压迫·坦克 | 獓狠（+ 雷牦） | 慢走、长距离直线踩踏、贴脸挑 | 先烧毛；侧移出冲撞线 |
| 远程·炮击 | 举父 | 先抢高，再抛物线远投 | 打它手里的石头 |
| 远程·扫线 | 蛮蛮 | 盘旋 → 低空电弧横扫 | 跳过 / 冲刺穿过；打下一只 |
| 辅助 | 连鼓灵 | 躲在后面敲鼓给同伴上护盾 / 加速 | 最先打，先打红鼓 |
| 游猎·精英 | 穷奇 | 全图巡视；上脊 → 滑翔扑杀 → 旋斩 | 看地上的影子横移；滑翔时打翼根 |

下面每张招式表：**前摇**写它怎么让你读出来，**判定**写打到你的范围和伤害，**破绽**写收招时你能干什么。时长写成「前摇 / 出手 / 收招」秒。

### 3.1 啸獭（群怪·哨兵）

血 40，移速 6.5，韧性 18，弱点：头 ×2、尾尖静电球 ×2.5（侧面、背后才打得到）。每窝 5–8 只，1 只哨兵，窝边 3–5 个洞口。

| 招式 | 时长 | 前摇 | 判定 | 破绽 |
|---|---|---|---|---|
| `scream` 尖啸（哨兵） | 1.2 / 0.3 / 0.6 | 直立、仰头、两爪抱胸，嘴边紫光从暗到亮，头顶出「！」 | 出手：一圈声波，60 m 内别的兽群醒来朝玩家集结 | 前摇里打死或打出硬直：只叫醒自己这窝 |
| `bite` 扑咬 | 0.35 / 0.2 / 0.6 | 伏低、炸毛（毛尖火花） | 往前扑 2.2 m，1.6 m 内 6 伤害 | 扑完坐起来抖毛 0.6 秒 |
| `burrow` 钻洞 | 0.25 / 1.2 / 0.4 | 半秒内挨两枪或被贴到 3 m：一头扎进洞 | 地下无敌，土包沿地面移到 6–10 m 外另一个洞口 | 钻出来「探头」0.4 秒不动；冷却 6 秒 |
| 电网（被动） | — | 3 只以上相距 4 m 内，两两连紫红电弧 | 碰到电弧每 0.4 秒 4 伤害 | 打掉中间那只断网；网里的都带电 → 燎的火一碰焚雷，电传过去连环炸 |

- 节奏：一窝最多 3 只同时扑；其余在 4–8 m 绕着蹦，等令牌。
- 受击：耳朵贴后、头一缩；硬直是往后滚一圈。
- 死亡：普通——翻肚子、四爪抽两下；爆头——原地转半圈倒下；爆炸——被抛成一道弧。

### 3.2 天狗（群怪·包抄）

血 80，移速 9.5，韧性 30，弱点：白首额心的雷纹 ×2。三四只一群。

| 招式 | 时长 | 前摇 | 判定 | 破绽 |
|---|---|---|---|---|
| `circle` 绕圈 | — | 在 12–18 m 外跑，按「左后、右后、左侧、右侧」四个位置分配 | — | — |
| `howl` 雷吠 | 1.0 / 0.6 / 0.8 | 停下、坐低、仰头长吠，额心雷纹亮起；玩家脚下出现跟着走的紫红雷标 | 前摇里雷标跟人 1.5 秒；出手时定格 0.6 秒后落雷 3 m、15 伤害 | 雷吠的那只站着不动 1.8 秒；打出硬直或封脉，雷标取消；站到导体旁 2–5 m，雷被引走 |
| `pounce` 扑咬 | 0.3 / 0.4 / 0.7 | 只从玩家视野外（> 50°）发动：伏低、低吼，地上出一条 3 m 的橙色扑线 | 扑 4 m，9 伤害（衔雷后 14 + 雷殛） | 落地滑一下、低头 0.7 秒 |
| 衔雷（被动） | — | 3 m 内落雷（自己的雷吠、雷暴、夔）：毛上闪电 | 带电 8 秒 | 带电时被火打 = 焚雷 |

- 节奏：一群里同时只有 1 只雷吠、1 只扑；其余绕圈。雷吠 → 玩家横移 → 侧后方那只扑，两招一前一后正好逼走位。
- 受击：一声呜咽侧歪；硬直是往侧面滑 0.4 秒。眩晕：侧躺抽搐。
- 死亡：跑动中被打死会带着冲劲往前翻滚；站着被打死侧倒。

### 3.3 獓狠（坦克）+ 雷牦

獓狠：血 900，走 3.5 m/s、踩踏 13 m/s，韧性 220（子弹几乎打不出硬直），不吃击退。弱点：四角之间的雷球 ×2.5（正面）、烧出来的雷筋 ×1.25。雷牦：血 260，复用獓狠模型（×0.72），没有雷球和蓑毛。

**蓑毛**：全身分 6 片（胸、背、臀、左右肩、左右后腿），没烧的那片只吃 20% 伤害；灼烧落在那片上 1.5 秒后烧光，露出发光的雷筋，之后吃 125%。燎的 E / Q、炎心、焚雷、熔金都能烧（熔铸让熔金烧得快一倍）。头和雷球没有毛。

| 招式 | 时长 | 前摇 | 判定 | 破绽 |
|---|---|---|---|---|

## 4. 领主

**领主通用**：

### 5.2 难度曲线（开放顺序下）

4-1 的据点任意顺序，难度不能按地图位置排，按**已经打了多少**动态排：

- **领主梯度**：第 *n* 个打的领主（*n* = 0, 1, 2）血量 ×(1 + 0.15 *n*)，收招 ×(1 − 0.1 *n*)，*n* = 2 时每个阶段多一招变体（夔的雷掌接小跳、飞廉冲撞接风刃、化蛇扑岸接翼拍浪）。
- **玩家梯度**：每点亮一处灵火 +1 张秘卷；打败领主再 +20% 伤害、+25 血上限。领主梯度比玩家梯度略缓：先打普通据点、攒两三张秘卷再打领主的玩家会更轻松，直接冲领主的玩家要靠走位。
- **一场领主战内部**：一阶段教招（招式少、前摇长、一次一个威胁）；二阶段加场地机制（经幡杆、龙卷、涨水、撕桥、雷泽）；三阶段压缩（收招变短、连段），但同时给最大的反打窗口（破鼓、珠碎、噎住、坠江、神颓）。
- **整章**：4-1 三领主（12k / 11k / 10.5k，单一机制为主）→ 4-2 大鹗（16k，四个环境机关）→ 4-4 雷泽雷神（30k，所有母题合一：雷与鼓、导体、水、身段平台）。

## 7. 需要美术的

**模型（大的缺口）**
- **大鹗**（4-2）：网页版是白盒（`gorge/dae.ts` 程序化拼的鸟身、双翼、虎爪），要走概念 → 四视图 → Tripo → 骨骼（翼骨三节、爪、头颈）。
- **雷泽雷神**（4-4，全游戏最大）：网页版是白盒（`haizi/leize.ts` 程序化管状龙身 + 方块人身 + 金神面 + 腹鼓）。按 enemy-roster-v2 的定稿「学烛阴」：头、上身和双爪进 Tripo，长身程序化沿样条生成鳞片带；神面、腹鼓要单独可发光的材质槽。
- 4-4 神山（冈仁波齐式的山尖）现在用程序化远山（`plateau/backdrop` 的 `buildMountains`）拼出来，终局背景要一个正式的远景模型或绘景。

**手工关键帧**（现在全是程序化姿势函数，烘焙进 Unity 时用 `bake-native-anims.mjs` + `docs/art/ch4-move-events.json` 的时间点，但下面这些要手修）
- 夔：单足蹦跳的蓄力和落地缓冲、双拳拄地荡身（拄拳）、捶胸、破鼓跪地、倒回残鼓。
- 飞廉：人立长嘶、侧跃、回旋冲撞的身体倾斜、侧倒（珠碎）。
- 化蛇：水中游动的波形、翼拍浪、潜游突袭出水、噎住翻肚子。
- 雷魅：天狗扑咬、獓狠冲撞起步、举父举石 / 投石、穷奇滑翔展翼和落地扑杀、蛮蛮成对扫线、连鼓灵骨槌击鼓。
- 四种死法（普通 / 弱点 / 爆炸 / 带电）现在是程序化倒地，烘焙后做成每种怪各一套死亡片段。

**特效贴图 / 着色器**
- 雷：落雷、电弧、带电噼啪、雷球、雷晶充电，现在是锯齿线 + 加色光晕，要正式的闪电贴图序列和辉光。
- 风：狂风锥、风刃、龙卷（含火龙卷），现在是半透明几何体。
- 水：水弹、浪、涨水线、湖面漩涡、通电湖水（现在整片湖染成紫红，太艳，要做成电流焦散 + 局部辉光）。
- 地面预警：落点圈、扫线、冲撞线、扇形，现在是着色器色块，要统一的预警贴花（四种颜色语言见 1.5）。
- 獓狠蓑毛分区燃烧（现在只是分区变色），化蛇湿身。
- Tripo 出来的模型材质金属度是 1：带电发的那一点紫光会把整只怪染成紫红（穷奇吞雷后最明显）。烘焙前统一改成非金属，或带电改用边缘光。

**UI 与音效**
- 名字卡的书法字（现在是系统字体）、破防条、元素状态图标、反应字样。
- 音效全部还没做：每招前摇声（吼、蓄风、拍腹）、落雷 / 雷鸣、命中和弱点命中、反应爆炸、登场 / 转阶段 / 死亡的配乐提示点（镜头表里的时间点可以直接当提示点）。
