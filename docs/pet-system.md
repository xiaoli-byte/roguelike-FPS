# 灵宠系统（第一版，2026-10-18）

> 一句话：**灵兽跟着你打，帮你打得更爽**。大多数灵宠是锦上添花的帮手；极少数「神兽」数值爆炸，抽到就是这一局的狂欢。
> 用户要求（2026-10-18）：宠物协助、陪伴、辅助战斗；允许极稀有的超模宠物；Tripo 自助生成不超过 8 个，稀有的设计两个。
> 实现：Unity（`unity/Assets/Game/Scripts/Pets/`）。Three.js 版没有宠物，这是全新系统。

---

## 1. 设计原则

1. **帮手，不抢戏**（普通 / 稀有）：灵宠持续输出约为玩家武器 DPS（60–90）的 15–35%，主要价值在控制、元素、增益。
   玩家始终是主角——射得爽的是玩家，灵宠让「射」更爽（标记、元素起手、控场、续航）。
2. **神兽就是要超模**：两只神兽各自把一局变成另一种游戏——白泽让每一枪都是弱点暴击，应龙让全场一直打雷、反应不停。
   代价只有一个：**极稀有**（每个灵兽封印 3%）。不做"超模但有负面"的设计，抽到就该爽。
3. **接进元素反应**：灵宠的元素命中走玩家同一条伤害管线（深度 0），可以引发焚雷 / 熔金 / 封脉 / 归墟。
   精卫给火、重明鸟给雷、狻猊给蚀，配合英雄和武器凑反应是灵宠最主要的构筑价值。
4. **看得见的贡献**：灵宠攻击有自己的特效颜色和动作；灵技（G）有大招感；HUD 显示灵宠、灵契等级和灵技冷却。
5. **不添麻烦**：灵宠无敌（灵体），不需要喂、不需要复活、不会挡子弹（没有碰撞体），走远了自动瞬移回身边。

## 2. 获取与稀有度

| 品阶 | 颜色 | 封印权重 | 灵宠 |
|---|---|---|---|
| 凡灵（普通） | 灰白 `(.85,.85,.85)` | 72% | 当康、讙、精卫 |
| 灵兽（稀有） | 蓝 `(.4,.65,1)` | 25% | 重明鸟、狻猊、狰 |
| **神兽**（超模） | 赤金 `(1,.32,.3)` + 金色光柱 | **3%** | **白泽、应龙** |

- **灵兽封印**（`PetSeal`）：地上一团带品阶光柱的封印，里面浮着灵宠的身影。按 F 结契，灵宠出来跟你走。
  已有灵宠时再结契 = 换宠，旧灵宠变回封印留在原地（可以换回来，不会白丢）。
- 来源：
  - 1-1 场地 ② 清场宝箱改为「灵兽封印」奖励（按权重抽品阶，再在该品阶里抽一只）。
  - 精英怪死亡 6% 掉一个灵兽封印。
  - 试玩期间出生点旁有「灵兽台」（测试用，和武器架同理）：8 只全部摆出来，方便体验。
- 每局只带 **1 只**（FPS 视野里多只会乱，也让「换不换」成为选择）。
- 神兽出现时：全屏横幅「神兽现世」+ 金色光柱冲天 + 封印环绕金光，确保"抽到神兽"是这一局的高光时刻。

## 3. 灵契（局内成长）

- 灵宠跟随期间，**任何敌人被击杀**都给灵契经验：普通 1、精英 4。
- 等级 1–5，升级所需经验：6 / 10 / 16 / 24（1-1 一关约能升到 3–4 级）。
- 每级：灵宠伤害 +15%，灵技冷却 −6%。
- **3 级「觉醒」**：每只灵宠解锁一条强化（见第 4 节）。
- 升级时灵宠头顶浮字「灵契 Lv.N」，觉醒时横幅提示。

## 4. 八只灵宠

数值为灵契 1 级。伤害来源 `DamageSource.Pet`，吃新属性「灵宠伤害」`Stat.PetDamagePct`（秘卷以后可以加），
**不吃**玩家的武器伤害 / 技能伤害；默认不随机暴击（狰、白泽有自己的暴击规则）。

### 神兽（超模，3%）

**白泽（万鬼图鉴）**——"让玩家变神"
- 出处：黄帝巡狩遇白泽，能言，知天下鬼神万物之状。
- 形态：浮空地面（脚下踏云）；元素：无（金光）。
- 被动 **万鬼图**：你的每一次命中都算弱点（必定暴击），暴击伤害 +50%。
- 被动 **洞悉**：25 米内敌人受到你的伤害 +20%。
- 普攻：金光三连射，同时打 3 个目标，各 30 伤害（1 秒一次）。
- 灵技 **白泽图**（25 秒）：30 米内所有敌人眩晕 1.5 秒，8 秒内受伤 +60%；你的技能冷却立刻减半。
- 觉醒：自动吸取 25 米内全部掉落物；万鬼图暴击伤害改为 +80%。

**应龙（兴云布雨）**——"全场一直在打雷"
- 出处：《山海经·大荒北经》：应龙蓄水，杀蚩尤与夸父。
- 形态：飞行；元素：雷（布雨附蚀）。
- 被动 **布雨**：每 0.6 秒对 28 米内随机敌人降一道天雷，50 伤害 + 必定雷殛；每第 3 道是「蚀雨」，再附蚀化——封脉会接连不断地炸。
- 普攻：龙息雷光，每秒 5 × 20 伤害打它盯住的目标。
- 灵技 **杀蚩尤**（25 秒）：6 秒雷暴，每秒 12 道天雷落在 30 米内敌人身上，每道 70 伤害，元素按 火 → 雷 → 蚀 轮转（归墟遍地开花）；释放时你的护盾回满。
- 觉醒：布雨间隔 0.4 秒。

> 平衡说明：第一章普通敌人 26–170 生命，镇墓兽 640+160。两只神兽都能单独清场——这是有意的，3% 的稀有度就是它的代价。
> 以后有局外成长时再考虑「神兽保底」和「神兽在 Boss 战的数值上限」。

## 5. 操作与界面

| 输入 | 作用 |
|---|---|
| G | 灵技（有冷却，HUD 显示） |
| F | 对灵兽封印结契 / 换宠 |

- HUD 左下（生命框上方）：灵宠名（品阶色）、灵契等级与经验条、灵技图标（冷却遮罩 + 秒数，就绪时 G 键高亮）。
- 灵宠的攻击用自己的颜色：凡灵白金、灵兽元素色、神兽金红；伤害数字和玩家一样显示，但**不触发玩家的命中标记**。

## 6. AI 行为

- 状态：**跟随**（玩家身后 2.5–3.5 米，飞行宠物在肩后上方 2 米）→ **交战**（玩家 18 米内有敌人：去打离玩家最近 / 玩家正在打的那个）→ **归位**（离玩家超过 22 米或卡住 3 秒：灵火一闪瞬移回身边）。
- 地面宠物用 NavMeshAgent（1-1 已烘焙导航网格），找不到网格就跟飞行宠物一样贴地飘；飞行宠物直接插值飞行，遇墙抬高。
- 灵宠没有碰撞体：不挡玩家、不挡子弹、不被爆炸误伤。
- 嘲讽（讙）：`EnemyAI` 新增「临时目标」，被嘲讽的敌人瞄准、走位、近战都对着讙；打到讙身上无效（灵体），玩家这段时间不吃这些敌人的伤害。

## 7. 美术

- 8 只灵宠由本地 Codex 出四视图 → Tripo Studio（智能网格、多视图、P2.0、带贴图）→ `art/source/_tripo_inbox/`（不入库）→ `pet_export.py` 归档到 `art/source/pets/<ID>/03_model/`（入库）。
  概念脚本 `art/pipeline/pet_concepts.py`，导出脚本 `art/pipeline/blender/bl_pet_export.py`（GLB → 落地、朝向、缩放、FBX + 贴图）。
- 第一版是**静态网格 + 程序动画**：漂浮、呼吸、跑动时上下颠、转身倾斜、攻击前冲 / 缩放挤压。骨骼绑定（Tripo 自动绑骨 →
  `build_tripo_creature.py`）放到第二版。
- 模型缺失时自动用程序化占位体（同色系的简单几何），系统本身不依赖美术。

## 8. 代码结构（`unity/Assets/Game/Scripts/Pets/`）

| 文件 | 内容 |
|---|---|
| `PetDefs.cs` | 品阶表、八只灵宠的数据（名称、出处、元素、形态、数值）、按权重抽取 |
| `Pet.cs` | 灵宠本体：跟随 / 交战 / 归位、移动（NavMeshAgent 或飞行）、程序动画、灵契等级、通用攻击工具 |
| `PetBehaviours.cs` | 八只灵宠各自的普攻 / 被动 / 灵技 / 觉醒 |
| `PetOwner.cs` | 挂在玩家身上：当前灵宠、结契 / 换宠、G 键、经验、玩家属性加成的登记与撤销 |
| `PetSeal.cs` | 灵兽封印（可交互）、灵兽台（测试） |
| `PetHud.cs` | HUD 灵宠面板 |
| `PetVisuals.cs` | 模型加载（`Resources/Pets/<ID>`）与程序化占位体 |
| `PetBootstrap.cs` | 场景加载后自动挂上 PetOwner / PetHud / 灵兽台（不用重建场景） |

改动到的现有代码：`Damage.cs`（`DamageSource.Pet`）、`Stats.cs`（`Stat.PetDamagePct`）、`Combat.cs`（灵宠伤害倍率、不随机暴击）、
`Hud.cs`（灵宠伤害不触发命中标记）、`EnemyAI.cs`（嘲讽目标）、`LootDirector.cs` / `Chest.cs`（`pet` 奖励、精英掉封印）。
