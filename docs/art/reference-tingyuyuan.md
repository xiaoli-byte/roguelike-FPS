# 参考拆解：《听雨园》（细雨中的江南园林，全程序生成的 three.js 场景）

2026-11-25 用户：「你看看别人的场景是怎么做的，很精致很有氛围感！」
- 视频：<https://www.bilibili.com/video/BV1ZFsW6oEdJ/>（7:14 起是「怎么做的」）
- 仓库：<https://github.com/Wode44398/tingyuyuan>（MIT；three.js **0.186**，和我们同一版本）

一个 5 MB 的单页 HTML，没有任何贴图、模型、音频文件，全部由代码生成；作者用 Opus 5.5 做了 34 天（2026-10-08 — 11-11），约 174 亿 token。
目标机器是 RTX 5090（首次加载生成约 2 分钟），**不是游戏**：没有画质分级、没有自适应分辨率，7 个电影级特效全开。
所以这份拆解分两类：**做法和流程**（全部能学），**渲染技术**（按「每毫秒换来多少观感」挑着学，60 帧的射击游戏装不下它的全套）。

## 一、一句话：它为什么「精致、有氛围」

1. **光是软的**：太阳的阴影只压到 45–68%（`shadow.intensity`），环境光不用半球光，而是用程序天空渲出来的环境图；AO 只压间接光、不压太阳。
2. **颜色是「印」出来的**：AgX 色调映射 + 线性空间调色 + 程序生成的 3D LUT（高光去饱和、暗部一点乳白、阴影偏冷高光偏暖、暖色灯保住琥珀色、绿偏玉色），再加很轻的暗角、颗粒、边角色差。
3. **天气是一整套，不是几个特效**：一张俯视高度图（「遮挡图」）同时决定哪里淋得到雨、哪里湿、雨丝在哪停、雾贴哪、声音在不在檐下。
4. **细节密度够**：没有一张照片贴图，材质全靠算（一张高度图推出法线、颜色、遮蔽）；地面是颗粒状的泥土、碎石和积水；山坡铺满苔藓蕨草；树冠是 400 万片真叶子。
5. **构图像电影**：近处用回廊柱子、窗棂、屋檐压暗做框，中景亮，远处退进雨雾；灰绿的园子里放一棵红枫当点缀色；54 个固定机位逐轮复核。
6. **流程硬**：七轮迭代，零件先单独过关再拼园子，材质摆进「材质广场」在同一片天光下比，一帧拆成白模和一层层光来查，同机位截图逐轮挑刺，逐个开关查回归，用数据抓闪点。

## 二、做法与流程（视频 7:14 起，全部能学）

| 轮次 | 时间 | 做了什么 |
|---|---|---|
| 1 | 10-08 | 一片空地 → 13 个模块并行，不到 4 小时拼出整座园子 |
| 2 | 10-08—12 | 13 个模块各自细化，叠加 7 项电影级渲染特效（同一机位前后对比：多了倒影、雾、调色） |
| 3–5 | 10-12—18 | 加运镜、视频导出、环境声；13 个模块逐个返修（假山坡从「秃黄土」改成苔藓蕨草铺满） |
| 6 | 10-18—28 | 树冠从平面贴图换成一片片真叶子（约 400 万片叶子和小枝），影片改用光追 |
| 7 | 10-31—11-11 | 路径追踪；材质与地面真实感（地面从光滑一层壳变成颗粒泥土和积水，树皮重做），**54 个机位逐一复核** |

具体方法：
- **先造零件，再拼园子**：13 个模块各写各的，在同一块地形上一个个加进来；**每个零件先在空地上单独过关**（厅堂先格扇后屋顶，亭子落到山坡上，水池先看倒影、雨纹、锦鲤），过了才进园子。
- **湖石先做零件库**：峰石、湖石、黄石都是程序生成的，再挑来叠山。
- **材质全靠算**：没有一张照片。树皮对着真树皮照片一版版改，从「像橡皮泥」「像砖」到第 13 版才像梧桐。**只算一张高度图**：法线、颜色、遮蔽都从高度推出来，最后合成。
- **材质广场**：所有材质摆成一排排样板（球、方块、立板、名牌），放在同一片天光下比，白天、晚上八点半各看一遍（仓库里是 `src/modules/matboard.js`，`?matboard=1` 打开）。
- **拆开看一帧**：同一画面去掉材质只看形状（白模），再看每个像素的朝向；光一层层算出来：固有色、风化遮罩、直射光、反弹光（GI）、高光，叠起来才是成片。
- **每一轮都有人挑刺**：同一机位每轮审查都拍一张对着改（例：第二轮「湿了但太暗」）。
- **抓回归、找根因**：复审发现卧室书法被照白了 → 逐个关开关，锁定是室内补光，修好再复验。
- **用数据说话**：闪点检测——把树冠里过亮闪烁的像素全标红，再一个个压下去。仓库里还有 GPU 计时（`fx/camera/profiler.js`，`?camprof=1`）和一堆 URL 开关（`?fx=none`、`?post=0`、`?ao=0`）。

## 三、渲染技术拆解

> 下面的耗时是作者在 RTX 5090、1440p 下的注释；中端显卡 1080p 估计要乘 2.5–4。

### 3.1 后期（`src/core/post.js`、`fx/camera/*`）

一帧的顺序：法线预渲染（给 AO / SSR）→ 主画面渲到半浮点、4× MSAA 目标 → GTAO → 曝光测光 → SSR → 体积光 → TAA → 景深 → Bloom → 曝光 + 光晕 → 线性调色 → AgX + sRGB 输出 → 色差 + 3D LUT → 颗粒。没有画质分级，全开。

- **色调映射**：AgX；曝光按太阳高度给表（白天 1.0，夜里 1.85，黄昏再压 0.45 EV 让亮窗跳出来）。
- **自动曝光**（`exposure.js`）：1/4 分辨率测对数亮度平均，中心加权，过亮的灯不算进去；**只修正一部分**（变亮修 75%，变暗修 33%，封顶 ±1.5 EV）——暗处保持暗、有情绪。全在 GPU 上，不回读，< 0.1 ms。
- **线性调色**（`post.js:13-36`）：对数空间以 0.18 灰为轴的对比度；只抬暗部（夜里抬成冷蓝）；饱和度补回 AgX 吃掉的部分；暗角 0.2–0.32。几乎不花钱。
- **程序化 3D LUT**（`camera/lut.js`）：启动时在 CPU 上用 OkLab / OkLCh 算三张 33³（白天 / 黄昏 / 夜），GPU 上按权重混。内容：中灰附近轻 S 曲线、白点压到 0.985（像印片，白不顶到 1）、黑底抬 0.0006（雾和镜头眩光的乳白）、饱和色略加深、高光去饱和 14%、暗部去饱和 5%、琥珀色 +4–6% 并偏 2–3°、绿偏玉色、蓝收一点、阴影偏冷高光偏象牙暖（只作用在接近中性的颜色上，红灯笼不被拉灰）。**整体色度不变，只重新分配**。≈0.05 ms。
- **Bloom**：three 自带的 UnrealBloomPass，强度 0.16（有灯时 +0.5），阈值 0.95（有灯时降到 0.65），并把输入亮度夹在 8 以内——湿叶子上的小高光不会炸成星星。**光晕（halation）**：只取红通道里很亮的部分，两级模糊后染成橙红叠回去，灯笼外面一圈暖红边。
- **颗粒 0.018、边角色差 0.9 px、没有镜头脏迹**。
- **景深**只在第一人称漫游时开；**TAA、SSR、PCSS 接触阴影、全分辨率 GTAO** 都很贵。
- **预热**（`warmup.js`）：先空跑一帧把所有着色器变体记下来，分批并行编译、等 GPU 栅栏——第一次开枪 / 进新区域不会卡。

### 3.2 光照（`src/core/env.js`、`lights.js`、`fx/gi/*`）

- **一盏平行光**（日 / 月），阴影 8192²、固定盒子，**阴影强度只给 0.45–0.68**——没挡住的那一部分太阳就当天光补光，这是阴天柔光的核心。光不动就不重画阴影（隔帧）。
- **没有半球光 / 环境光**：环境光全部来自 `scene.environment`——把程序天空加一圈暗色的「周围剪影」（地平线上 6–17°）渲成 256 的环境图（PMREM），太阳高度或雨变了才重生成（≤ 每 0.2 s）。湿的表面因此反射「上亮下暗」的天。
- **天空**：自写着色器，层叠噪声云、藏在云后的太阳亮斑、雨幕；颜色按太阳高度查色板；**天空本身压暗 0.62 EV，环境图不压**。
- **灯**：最多 26 盏点光、4 张 1024 立方阴影，灯阴影是静态的（灯亮时画一次）；**从不切换光源可见性**（会让所有着色器重编译）。
- **全局光照**：加载时在 GPU 上烘（1–3 s）：体素化场景，16936 个探针、每个 256 条射线、3 次反弹，存一阶球谐 + 可见性（DDGI 式），**天空 / 地平线 / 日月 / 灯四部分分开存**，时间变化不用重烘，太阳动只重算太阳那份。室内看不到天的探针提亮到 6 倍（相当于剧组的反光板）。
- **为什么阴天的明暗这么软**：① 部分阴影；② **遮挡图**（俯视高度图）：头顶有遮盖的地方太阳阴影变完整、只剩 GI，边缘有软半影；③ GI 关掉时的后备：0.3 m 一格的天空可见度体积（沿高度图走 32 条射线）乘到天光上；④ **AO 只压间接光**，用多次反弹公式（亮表面少掉一点）。
- **材质**：基本都是 MeshStandardMaterial，金属度约 0；GPU 烘的程序化 PBR 贴图（AO / 粗糙 / 金属 / 高度挤在一张图里）。

### 3.3 雨、雾、水、湿（`src/core/fog.js`、`rainocc.js`、`modules/weather/*`、`modules/water.js`、`materials/patch.js`）

整套天气挂在**一张俯视高度图**上（`rainocc.js`：正交相机往下拍，写世界 y，2048 浮点，加载时拍一次，再拷一份到 CPU 给 `heightAt` 用）：雨丝、湿表面、雾、水花、水面雨纹遮罩、声音的「在不在檐下」全读它。

- **高度雾**：替换 three 的四个雾片段，沿视线对指数高度雾做精确积分（和我们 `Atmosphere.ts` 的低雾同一个式子）；雨大时变浓。雨幕、体积光用同一条衰减律，粒子和雾永远对得上。
- **池上雾团**：一个盒子网格，片元里 24 步抖动步进，停在场景深度和水面；密度 = CPU 烘的 128² 岸边距离遮罩 × 三层被风拉长的噪声 × 高度衰减；镜头高过 3 m 雾变淡。另有约 40 片顺风漂的雾片。
- **体积光**：半分辨率 64 步、两瓣相函数、灯用等角采样——**太贵，不学**。
- **雨丝**：实例化面片，两个跟着镜头、取模循环的体积（近 1.2 万滴 / 14 m，远 4.4 万滴 / 40 m），落到遮挡图以下就消失（檐下没雨）；长度 = 速度 × 1/48 s，宽度夹在 1.2–2 像素，透明度 ∝ 1/长度、封顶 0.22；颜色取它折射的环境（比天暗），加一点朝灯的闪光；阵风是顺风滚动的噪声调密度。**远处雨幕**：一个全屏三角形画 4 层圆柱「帘子」（13 / 21 / 34 / 56 m），一次绘制。
- **水花**：实例化的小皇冠，位置由实例号 + 周期号哈希、落在高度图上；近处 4000 个、只在看着的那片 6×6 m；平整湿地面上才有毛细环。檐口滴水和水面涟漪共用一个时钟。
- **湿表面**（MeshStandard 的补丁）：淋雨程度 = 遮挡图 + 檐下溅水带 + 风吹偏；变暗 `c *= 1 - 0.63·湿·孔隙率^0.8` 并略加饱和；粗糙度湿了降到 0.25–0.45；立面比地面干（贴地处除外）；墙上流水痕用噪声；**积水**：朝上的面用三层旋转噪声减去材质高度得到积水遮罩，积水里 albedo × 0.62、粗糙 0.03、雨纹法线、采地面平面反射。湿了以后自动曝光不能把地面提亮回去（`wetmeter.js`）。
- **水面**：一张 4 m 可平铺的雨纹 + 色散波的坡度贴图（1024² 半浮点，每帧画，带 mip；第二个输出存坡度²，远处的雨让倒影「起霜」而不是消失），采两次（第二次旋转缩放），再叠最多 96 个世界空间涟漪；平面反射**隔帧**重画、视锥裁到看得见的水面；反射查找沿 `wp + R·7m` 投影并用 `textureGrad`，灯的倒影竖向拉长；菲涅尔 F0 0.02；水体颜色按 Beer-Lambert（σ = 2.9, 2.05, 3.2 /m）。
- **风**：顶点补丁，权重 (y/h)²，三个正弦 + 抖动，深度材质同步（影子也摇）；全图一个阵风值，雨幕和声音共用。

### 3.4 声音（`src/core/audio/*`，没有任何录音）

- AudioWorklet 里按表面分「颗粒池」（瓦、叶、竹、池、石板、芭蕉叶）：短促的成形噪声颗粒按泊松随机到达，速率和大小随雨强、阵风变——永远不重复。风过树叶是粉噪声 × 交叠的 Hann 包络。
- 每秒 10 次在高度图上按圈采样：头顶有没有屋顶、屋顶中心在哪、树冠 / 竹林 / 水池 / 遮蔽有多少 → 每层的音量和声像。
- 空间化：一对虚拟心形话筒 + 耳间时差（不用 HRTF），距离反比 + 空气低通 `17k/(1+d/9)`；遮挡用 3 条射线对碰撞 BVH；室内把外面的声音低通到 3.5k 并加房间混响，檐下是半开放混响。滴水声和看得见的水滴用同一个时钟。

### 3.5 材质、地表、石头、植被、构图（`src/materials/*`、`lookdev/*`、`modules/*`、`layout.js`、`core/cinecam/shots.js`）

**贴图管线**
- 几乎全在加载时用 GPU 渲到贴图：配方着色器先出一张高度场，再推出法线（按每像素多少米缩放）、AO 和缝隙（一圈高度采样；缝隙暗直接烘进固有色）。每个材质三张：固有色、法线、打包图（AO / 粗糙 / 金属 / 高度），RGBA8、带 mip、各向异性拉满。
- 地面、树皮这些主角表面用另一套「物理」生成：底高度 → 由大到小撒真石子、碎屑、叶片、小枝 → 细土 → 几轮侵蚀让土沉到低处 → 推 AO 和最终颜色。地面一层 4096² 只铺 0.8 m。
- **粗糙度的 mip 会把被平均掉的法线细节算进去**（Toksvig / LEAN）：远处碎石不会变亮闪。
- 贴图密度：花岗岩 / 青石约 2700 px/m，灰泥 1024 px/m，湖石 2048 px / 2 m（三向投影），地面约 5100 px/m。
- **藏平铺**：世界空间三向值噪声（不采贴图）让固有色和粗糙度起伏 ±4–10%；地面层采两次（第二次 1.37 倍、旋转）按高度混；陡坡换侧向投影；石头三向投影 + whiteout 法线混合；每块石板 / 木板有自己的色调和粗糙度偏移。

**地表**
- 0.16 m 一格的地面网格，每个顶点存岸边 / 铺地 / 潮湿 / 外圈遮罩，还存「比周围低多少」——**积水只在真的洼地里**。
- 五层：土、苔、淤泥、碎石、落叶，按遮罩 + 噪声给权重，**按高度混**：`分 = 权重 + 高度 × k`，每层份额 = 分 − (最高分 − 0.14)。
- 铺地边上一条湿的、有砂的带；被踩的地从石板 → 细土 → 苔藓过渡；落叶堆在石边和积水边，有的沉进水里。
- **物件和地面的交界**：俯视渲染 + 距离变换得到「离石头 / 树干多远、离建筑多远、哪边是上坡、离檐口滴水线多远」，地面据此加潮湿带、上坡一侧的堆土、下坡的碎砂扇、一圈苔藓、卡住的落叶；再沿每块石头的地面线撒实例化的碎石、碎土块，加一圈真的「裙边」网格。
- **所有材质的脏旧**都从俯视高度图来：压顶下的流水痕、贴地的溅水带、缝里的脏和苔、遮蔽高处的积灰、贴墙的落叶。

**湖石**
- 每块石头是一个有向距离场，在 Worker 里用 Surface Nets 网格化；平滑后把顶点推回原场，棱保持锐。表面：脊状噪声做褶皱（每层按粗一层加权，脊会分叉）、竖向拉长的噪声做竖槽、胞状噪声做顺坡的凹坑。
- **每个顶点烘好缝隙 AO、凸度、水渍潜势**（沿面往上走一段算出来）；着色器里棱亮、缝暗、水渍 × 竖向条纹噪声、朝上的凹处长苔、路边的石头顶被磨干净；程序凹凸按屏幕上的像素大小淡出，不闪。
- 25 块库石实例化，20 m 切细节（有滞后）；小石头不投影。

**植被**
- 树骨架程序生长，避开路的净空、建筑、视线走廊。叶子用真几何：记录存在 RGBA32UI 贴图里，2.5 m 一块、64 个实例一页，三档模板；**远处按屏幕大小稀疏**：保留比例 f = (投影像素 / P0)²，按每片叶子固定的随机名次挑，留下的放大 1/√f 保住覆盖率，CPU 只画前缀。
- 树冠 AO：叶子密度体素 + 14 个锥追踪。风三级：阵风前锋顺风扫过园子、枝条绕根部刚体转、叶子各自抖。薄片次表面透光、叶背浅、弯曲法线让叶片像体积一样受光。
- 地被：苔藓毯是 3 层 alpha 测试壳；沿路边、墙脚的沿阶草是真叶片；芭蕉叶撕成几何条。

**构图和摆设**

脚本另有 `toggles`（同机位逐项关掉各出一张 + 测开销，拼成一张）、`fireflies`（所有机位找闪点、存标记图）、`warm`（不预热 / 预热各开一个全新浏览器，转一圈量每个方向第一帧）。

实跑查出来、当场改掉的：
- **4-4 转身卡一下**：转到 45° / 90° 第一帧 210–300 ms。根因有两个：草的实例化区块每次 `update` 最多建 4 块，进图时还没建到那边；`renderer.compileAsync` 按「画到屏幕、Neutral 色调映射」编，编出来的变体出图后期一个都用不上。修完以后最坏 15 ms；4-1、4-2 本来就不卡。
- **远处的野花在闪**：4-1 孤立闪点里草和花占了一半以上（比一个像素还小的白 / 黄点）。给 `patchMaterial` 加了 `shrink` 选项，野花离镜头 45–75 m 缩到没有。夔的擂台机位闪点从 0.088% 降到 0.066%。

查出来、没改的：
- **成线的闪烁**：4-1 每个机位 0.2–0.6%，主要是经幡布条、绳子（1 像素的 `LineSegments`）和山脊剪影。已经开了 4 倍多重采样，再压要换绳子的画法或加抗锯齿后期。
- **地表草层本身很饱和、很平**：样板页上一块纯绿。实际地图里被草叶盖住了。
- **4-4 晴天出生点各项开销**（2560×1440 测）：后期整套 0.57 ms、阴影 0.38 ms、雾 0.30 ms、泛光 0.15 ms，其余都在 ±0.11 ms 的噪声以内。

## 五、不学的（射击游戏装不下，或不适合）

- **TAA**：快速甩枪会拖影，还要给所有动的东西出运动矢量。
- **SSR、PCSS 软阴影 + 屏幕空间接触阴影、全分辨率 GTAO（还要多画一遍法线）**：每项都是毫秒级。要 AO 就用第 4 项的顶点烘焙，或半分辨率 SAO。
- **体积光步进**（半分辨率 64 步）：我们的解析高度雾 + 向阳散射已经拿到大部分；要光柱就用面片做。
- **1.7 万个 DDGI 探针、路径追踪、400 万片真叶子、0.8 m 一张 4096² 的地面**：目标是 RTX 5090 的离线级观感，我们按 60 帧中端显卡算。
- **景深**：伤可读性，最多给开镜用。
