## 0. 总纲

场景不对劲时，十有八九是两个问题：**层没拉开**（画面闷、平）和**焦点太多**（等于没有焦点）。
先去色数一遍层，再数画面里有几样东西在抢戏，做完这两件事，多数时候不用再套别的公式。

工作顺序不能反：**大块面 → 引导线 → 光影（先定曝光）→ 颜色面积 → 点缀小件**。
小件、垃圾、贴花大约只占关卡 5% 的工作量，却最容易吃掉一半时间；一上来就摆小件，画面永远「醒」不过来。

## 1. 好构成的八个特质

### 1.1 大型清晰
- 人眼读图从低频到高频：先抓剪影和大块面，再看细节。大中小三级就是人为规定阅读顺序。
- 大型一旦含糊，中型、小型做得再好也没人看得到。
- 三级之间的**面积差和明度差都要大**，缩到拇指大小仍然读得出。
- 最常见的失败：几块形体同一个等级、互不相让，或者左右对称平分，主次就消失了。

### 1.2 视觉锚点
- 锚点不是最大的东西，而是**对比最强**的东西：明度差、冷暖差、清晰度差、疏密差，哪里差得最剧烈，视线就落在哪里。
- 小东西也能当主角，前提是给它**留一圈干净背景**：要么它暗、背景亮，要么它实、周围虚。锚点附近的碎细节要主动削掉。
- 检查：把图缩小，看第一眼落在哪里。

### 1.3 空间明确
- 空间主要来自**遮挡**和**明度分层**，透视只是辅助：A 挡住 B，前后关系就成立了。
- 前、中、后景各占一条**不重叠的明度带**。常规做法：前景压暗，中景受光，远景抬亮并降低对比和饱和度。
- 层与层之间要有实体遮挡咬合，不要只是上下排开。
- 反例：整张图的明度都落在 40–70% 的中间调里，前中后挤成一张贴纸。

### 1.4 光影是第二次构图
- 几何定好以后，换个光位，主次和层次可以完全重排。所以灯光能救场，也能毁掉一个好场景。
- 先定光位和层次，再抠细节。
- 用**大块阴影**主动切掉不需要玩家看的区域；这些阴影要保持整块，别被零碎结构打断。
- 雾和大气透视是最省力的分层工具：一层雾就能把远景推远，把主体拎出来。

### 1.5 节奏感
- 节奏来自大小、疏密、亮暗、颜色的对比。公式是**有规律的重复 + 恰当的打破**：只重复会闷，只打破会乱。
- 完全等距、等大、等量的排列，大脑会直接把它当成一片材质，读不出信息。
- 疏密要**成组**，不要平均撒。按长短节拍想：长笔画是大结构和通长的线，短笔画是密集的小单元，两者交替咬合。
- 自查：画面里有没有一处最密、一处最疏？密度到处一样，就没有节奏。

### 1.6 留白
- 留白是信息密度的低点，让眼睛有地方落脚；同时它是对比的另一半，没有空，满就衬不出来。
- 留白要**成块**：碎成一片小空隙只会显脏。
- 把最空的区域放在主体旁边；留白正中再放一个小物件，它就成了第二焦点。

### 1.7 尺度对比
- 尺度是纯粹的相对量：人只认得「跟人比有多大」。宏大感靠的不是把模型放大，而是配一个**认得出的小参照物**（人、门、台阶、栏杆、箱子），并且放在看得见的位置。
- 进一步可以做两级参照：一个贴近玩家，一个在中景，尺度就有了递进。
- 参照物必须从周围杂物里跳出来（明度、细节等级不同）；和杂物混在一起，就起不到参照作用。

### 1.8 颜色控制
- 颜色乱的根源往往不是色相选错，而是**面积失控**。两种颜色面积一旦拉开就自动分出主次，一旦接近就互相抢。
- 主色统一环境，通常直接取环境光或雾的颜色；辅色区分区域和材质；点缀色只给最重要的信息点（锚点、可交互物、剧情道具），宁少勿多。
- **冷暖对比比明暗对比更抓眼**，所以点缀色天生适合做指向。

## 2. 631 法则：六个维度的主次配比

631 不是行业标准，只是一个好记的刻度：主要的占六成，次要的占三成，最跳的占一成。
真正要记住的是**三档之间要拉得足够开**，一眼就能排出先后（532 的麻烦是老二和老三分不清）。
631 是起手式，不是镣铐：成熟画面也会出现 811，或两块势均力敌的对峙，但前提是清楚自己在破什么规则。
说不清哪儿不对的时候，把下面六个维度按 631 排一遍，问题基本会浮出来：要么三档没拉开，要么顺序做反了。

| 维度 | 6 | 3 | 1 | 检查 |
|---|---|---|---|---|
| 构成 | 面：体块、立面、地面、天空、大块阴影，撑住画面 | 线：栏杆、管线、链、光柱、路的走向，拖着视线走 | 点：小而集中的高对比物件（一盏灯、一个人、一块牌），把视线钉住 | 缩成拇指大小或高斯模糊后，还看得出大块分割 = 面立住了；糊成一片 = 全是碎线碎点 |
| 灯光 | 主光：吃掉六成亮度和几乎全部阴影形状，决定时间、天气、情绪 | 环境：天光和反弹，撑住暗部；暗部不是黑，要有层次、色偏、信息 | 点光：只给眼睛一个落点，不负责照明；色温必须和主光**冷暖相反** | 去色后还看得出主光从哪来、视线往哪走；三份光一样亮 = 处处亮但很平 |
| 颜色 | 环境本身：石、土、地面，多半低饱和 | 建筑构件和大件道具的固有色 | 高饱和：警示色、发光、血红 | 饱和度和面积成反比：铺满画面的高饱和会让人疲劳，缩到 5% 才是让人眼前一亮的那一笔 |
| 地编 | 大块面：地形起伏、建筑体量、大件遮挡，决定玩家能不能瞬间读懂哪能走、哪是墙、路通向哪 | 线性物：人会不自觉地沿线走，想让玩家往哪走就往那拉一条线 | 点缀小件：箱、杂物、水渍，生活痕迹 | 顺序比比例更重要；小件最后摆 |
| 单个资产 | 主体量（一个盒子、一个圆柱） | 次级结构（屋顶、阳台、附属体块），打破主体的单调 | 细节（铆钉、把手、线脚） | 纯黑剪影还认得出、看着舒服，大型就过关；这也是精度预算的分配表 |
| 信息密度 | 安静：大片墙、地面、天空、雾，基本不给信息 | 中等密度 | 高密度：希望玩家看的那一块 | 留白不是偷懒，是给焦点腾地方；粗糙度同理，大部分粗糙、少数半光、极少镜面 |

**点缀色和玩法绑定**：可攀爬、可拾取、可交互的东西统一用同一种点缀色，玩家不用教程也知道往哪走。

## 3. 八种构图在游戏空间里怎么用

游戏和摄影、绘画的区别：摄影可以为一个机位把元素钉死，游戏是三维空间，玩家从哪来、往哪转头都控制不了。所以构图要做在**空间**里，而不是做在某一张图上。
实际做场景时，几种构图基本是叠着用的。

1. **三分**：核心不是把主体放在交点上，而是别放正中、别贴边，三分线附近是一段舒适区间。游戏里最实用的是**切地平线**，因为主体会动，地平线不会：
   - 地平线压到下三分，天空占三分之二，画面开阔、史诗，可以用天空讲叙事；
   - 地平线提到上三分，地面占三分之二，适合压迫感、废墟。
   - 黄金分割和三分差不了几个像素，不用纠结；关键是**不等分**，等分会呆板。
2. **引导线**：眼睛碰到一条清晰的线，会不自觉地滑到尽头。
   - **收敛点比线本身重要**：多条线汇到同一处，吸引力成倍放大。找机位时让灭点落在你想让人看的东西上。
   - **方向决定推还是拦**：纵深方向的线把视线往里推；横穿画面的线把视线拦住。想让玩家停下来看风景，就在前面横一道栏杆、台阶或倒下的柱子。
3. **框架**：用场景物件围出一个洞，主体放在洞里。框是三维的，玩家往门口走，框自然收紧，主体始终锁在里面。
   - 做的时候问一句：**玩家穿过这个洞的瞬间，洞里框住的是什么？** 最经典的用法是框住下一个目标：推开门，门框里正好是远处的地标。这一下同时给了方向、给了一张好看的画，还让玩家觉得是自己发现的。
   - 进阶：**套框**，大框里还有小框，视线被一路吸到最深处。
4. **对角线**：水平和垂直代表静止，斜线代表运动，这是最底层的视觉心理。
   - 落地：斜坡、斜插的岩层、倾倒的建筑，而不是平地加直墙；机位轻微俯或仰；斜打进来的光柱。
   - 两条方向相反的斜线交叉，冲突感最强，适合战斗场景、灾难、废墟。
   - 反过来用：想要安宁、庄严、停滞，就把斜线全部清掉，只留水平和垂直。
5. **中心**：大多数时候要避开正中，但神殿、王座、祭坛反过来必须正中、左右对称。对称传达秩序和权力，玩家会不自觉地放慢脚步。
   - 给对称**留一个破口**：完全镜像会假、会死，在对称框架里塞一个不对称的元素。
6. **三角**：把主要元素连成三角形，用形状定性格。
   - 正三角：稳、庄重；倒三角：不安、危险、随时坍塌；锐角斜三角：攻击性、指向性。
   - 它能反过来指导地形：想让一段路走得压迫，靠的不是把灯调暗调冷，而是**把两侧体量抬高**，形成上宽下窄的夹角。
   - 检查：转黑白只看剪影；剪影读不出情绪，后面加多少特效都只是补丁。
7. **曲线**：S 型或 C 型路径贯穿画面，曲线比直线更能留住视线。
   - 曲线会**自己制造遮挡**：路一拐，后面就被山体挡住，看不到尽头就想走过去看看，这是最朴素的探索动机。直路一眼望到头，走起来是在完成任务；弯路每转一个弯都有新画面。
   - 主路的粗略指标：每隔一段就转向一次，转到看不见前方为止。玩家的行进节奏就是这些拐点切出来的。
   - 反用：路径绕来绕去却回到同一处，会制造迷宫感和焦虑（恐怖游戏常用）。
8. **留白**：做减法，刻意空出大面积不放东西，让旁边的焦点显出来。
   - 最常犯的错不是不敢空，而是资产库里东西太多，看到空地就想填。
   - 留白是唯一一条不需要加任何东西的构图法，也最考验判断。

## 4. 自检

### 4.1 流程
每个关键视角（出生远眺、每个场地入口、地标、首领场地）按顺序过一遍。前面不过，就别往后改：

1. **缩略图**：缩到很小，还读得出大型、看得清锚点 = 骨架立住了；糊成一团 = 回去改大型，别在细节上耗。
2. **灰度**：只看明度，前中后三层分不分得开？锚点是不是还在最跳的地方？空间和光影的问题在灰度下藏不住。
3. **眯眼 / 模糊**：只剩大块明暗时，疏密和留白成不成组？有没有一处最密、一处最疏？
4. 三项都过了再改颜色：用 631 定面积比例。
5. **数焦点**：画面里有几样东西在抢戏？超过一个主焦点加一个次焦点，就要删、压暗或去饱和。
6. **水平翻转**：翻过来还平衡吗？翻转后看着别扭，说明原来的平衡靠的是习惯。

### 4.2 脚本
`python scripts/unity/composition_check.py <截图或目录> [--out 目录] [--md 汇总.md]`

每张图出一张六格自检图（原图 / 缩略 / 灰度 / 眯眼 / 翻转 / 细节密度热图），并打印 631 统计：

| 统计 | 怎么分 | 提示阈值（经验值） |
|---|---|---|
| 颜色三档 | 按色度（RGB 最大 − 最小）：低饱和 < 0.12 / 固有色 / 高饱和 ≥ 0.40 且最亮通道 ≥ 0.45；高饱和里再拆出暖（熔岩、血红）和冷（青金） | 高饱和 > 15% = 点缀超量；< 3% = 没有点缀；低饱和 < 45% = 主色不够安静 |
| 明度四档 | 暗 < 20% / 中暗 20–40% / 中间调 40–70% / 亮 ≥ 70%，另报平均亮度和 5%–95% 跨度 | 中间调 > 55%，或跨度 < 25% = 明度挤在一条带；平均 < 15% = 整体太暗 |
| 细节密度 | 亮度先按 2%–98% 拉满，梯度按格（16 列）分安静 < 0.015 / 中等 / 密集 ≥ 0.05 | 安静 < 40% = 留白不足；密集 > 25% = 太满；最密 / 最疏 < 3 = 疏密不分 |

阈值按用户给的 3-3 参考图（火神王座，`art/source/characters/_design/inferno/inferno_boss_warlord/user_ref_throne_of_fire_god.png`）校准：它正好是颜色 60 / 31 / 9、密度 64 / 33 / 2，全部不报提示。
用色度而不用 HSV 饱和度，是因为暗褐在 HSV 里饱和度很高，看起来却是安静的。阈值只是提示，最终还是看图判断。首领场地这类刻意破规则的视角（例如 3-3 王座照参考图偏暖偏亮），在汇报里写出实际比例和理由即可。

## 5. 资产生成与搭建流程（第六期）

视频的流程是：Tripo 出高精度主资产，AI 按参考图在 Blender 里搭场景，人只做灯光和构图。和本项目现行流程基本一致（Tripo 出件，代理按设计稿搭关卡），可以补进来的几条：

- **Tripo 贴图勾选「去光处理」**：贴图里烘进去的光影和 AO，放进引擎会和实时光打架，是画面发脏的来源之一。以后生成新件默认勾上。
- 主资产用多视图生成，结构比单张图稳；导出时轴心选**底部中心**（本项目管线也按底面中心对齐）。
- **先按参考图搭结构，再做灯光和构图**：每张图的关键视角先有一张关键概念图（Tripo 图片页出图不花积分），按它搭大块面；结构还原以后再打光。
- 灯光调优**先把曝光定死**，再按空间层次和主次一盏盏加：主光 → 环境 / 反弹 → 点光。不要拿局部曝光去补布光的问题。

## 6. 落到本项目

- **点缀色和玩法绑定**（2.1 末条）：可交互、可拾取、路线提示统一用一种点缀色。第三章已经这么做了：主路引导灯是青金色（S6），和熔岩橙冷暖相反，熔岩光吞不掉它。危险预警按 fx-style 2.1：熔岩地面上用品红，不和点缀色混用。
- **第三章 · 熔火的 631**：
  - 颜色：暗紫玄武岩约 60%，铜色金属和暖灰约 30%，熔岩橙约 10%。
  - 熔岩面积大，按「饱和度和面积成反比」处理：大面积熔岩湖用暗色结壳加少量亮缝，白热和高饱和只给主路沿线的熔流和焦点。满地半饱和的橙红就是「脏」。
  - 灯光：一盏主光决定阴影形状；熔岩自发光和天光属于环境层，撑住暗部（偏紫，不是死黑）；引导灯、火盆是点光，只做落点。
  - 远景靠紫褐烟雾分层抬亮，锯齿山峰一层层隐进雾里，不是平的黑片。
- **每张图的构图主法**（建议，具体由地图路定）：
  - 3-1 熔湖关隘：引导线（堤道收敛到宫门）+ 框架（宫门门洞框住宫院）；
