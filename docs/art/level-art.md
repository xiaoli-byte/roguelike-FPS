# 场景搭建 / 地编准则

2026-11-21 用户确认：场景搭建、地编按这份准则做；**氛围、打光、光影、构图、特效和几何同等重要**，验收时逐项看，不能只看模型摆得对不对。
相关：构图细则 [composition.md](composition.md)、特效风格 [fx-style.md](fx-style.md)。

## 一、原则

- **地编是给玩法搭台的，不是摆景。** 顺序：路线和遭遇 → 白盒 → 构成 → 光影雾 → 特效 → 细节。顺序反了必然返工。
- **一眼只让玩家看一件事。** 战斗时最显眼的是敌人，探索时是目标地标。场景再漂亮，盖过敌人就是失败。
- **可信比真实重要。** 每样东西要有「为什么在这儿」：水往低处流，植被长在背风有水处，碰熔岩的只能是石头和铸铁。
- **留白是内容。** 繁和简成对出现，眼睛有地方休息，重点才立得住。
- **用地形说话，不用空气墙。** 边界靠悬崖、深水、陡坡、风暴这些看得懂的东西。

## 二、技巧

**构成**
- 大中小三级体量约 6:3:1：少数大形定轮廓，中形过渡，小件只在焦点附近点缀。
- 远中近三层：近景压暗做框，中景是可玩区，远景只管剪影和气氛。
- 聚散有致：物件成簇摆，簇间留空，不均匀撒点。
- 截图缩小、去色看一遍：轮廓读得出、明度层次分得开，构成才算对。

**引导**
- 每个区域一个远处认得出的地标。
- 路、河、栏杆、旗绳、光带都指向想让玩家去的地方。
- 出口、奖励、下一个目标放在更亮、更暖或对比更强的位置。

**地形与散布**
- 先捏大起伏，再做中等形体，最后才是碎石杂草。
- 坡度表达可走性：能走的缓，不能走的明显陡，不留暧昧的坡。
- 地表材质按坡度和高度混合；植被按生态规律分布，交界做过渡带。
- 物件和地面的接缝用碎石、草、贴花、堆土盖住。

**模块化**
- 一套套件拼出大部分场景，靠旋转、缩放、镜像、贴花、破损件打破重复。
- 全场贴图密度一致。

**氛围、打光、光影**
- 先定主光方向和明暗大关系，再谈局部补光。每张图有一句话的氛围目标（时间、天气、情绪），光、雾、天空、特效都为它服务。
- 雾分层：远景一层层退进雾里，低处压一条雾带，拉出纵深。
- 逆光出剪影，天空通常是画面里最亮的部分。
- 光要有来源：补光挂在灯、火、天光开口上。
- 阴影是构图的一部分：用投影切分地面、框住焦点，不要整片平光。

**特效**
- 环境特效是场景的一部分，不是事后点缀：风里的沙 / 雪 / 落叶 / 火星、流动的雾带、水面和熔岩的动势、光柱、小活物，每张图都要有让画面「活着」的层。
- 特效同样服从「一眼只看一件事」：环境层低对比、低频；战斗特效高对比，且不遮敌人和弹道。
- 特效的光要和场景打光对得上（方向、色温、强度）。

**战斗场地**
- 先定度量并全场统一：玩家身高、跳跃高度和距离、掩体高度（半身 / 全身）、通道最小宽度。
- 掩体分级，间距让玩家「跑得到但有风险」；留侧翼路线和高低差。
- 敌人入场点、驻守点提前规划，用导航网格验证连通。
- 战斗区地面干净，碰撞体用简化形状，不卡脚。

## 三、注意事项

- 用玩家视角、玩家速度走一遍验收，不在自由相机里验收。
- 不过早做细节：白盒阶段的问题用细节盖不住。
- 比例最容易错：放一个玩家等高的参照物随时对比。
- 克制视觉噪声：高频纹理、花哨地面、过饱和道具会吃掉敌人和弹道的可读性。
- 检查穿插和浮空，尤其坡地上的建筑、石头、树根。
- 性能从一开始算：重复物件实例化，控制透明叠加（草、雾片、粒子）和实时阴影数量；看得见走不到的远景用便宜做法（程序化、绘景板）。
- 每局路线和布局会变：每个变体单独走一遍，确认构图、引导、连通没被破坏。

## 四、验收清单

每张图交付前逐项过（截图为证）：

1. 路线连通、遭遇和入场点可达（导航验）。
2. 构成：去色缩略图里轮廓和三层明度读得出。
3. 氛围：和这张图的一句话目标对得上。
4. 打光与光影：主光方向明确，有投影参与构图，焦点最亮或对比最强。
5. 雾与纵深：远景退进雾，有层次。
6. 特效：有环境动势层，且不抢敌人。
7. 战斗可读性：站在各遭遇点看，敌人从背景里跳得出来。
8. 玩家视角走一遍：没有穿插、浮空、卡脚、空气墙。
