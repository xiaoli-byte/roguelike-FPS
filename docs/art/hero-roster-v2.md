# 玩家英雄全新设定 v2（2026-10-07）

用户否决了 Tripo 版赤狐 / 岩熊 / 雷隼（`docs/hero-remodel.md`）：和《枪火重生》的建模差距太大，和本项目新怪物也不是一个画风。决定改做全新英雄，参照《枪火重生》的英雄画风。

## 画风

和怪物 v2 设定稿用同一套风格化规则（`art/pipeline/redesign_sheets.py` 的 STYLE），按英雄定位做了调整：

- 约 4.5 头身，头、手、靴子偏大，身体紧凑结实。
- 毛发做成几大簇，服装是厚实的简单褶，贴图是手绘渐变。
- 两三块主色，再加一处灵火发光点缀。
- 性格讨喜、自信，带点痞气。

物种、轮廓、配色都要避开怪物名单，包括冰雪章的白色九尾狐巫、青鸟、猿、玄龟，以及沙漠章的鼠类和狮形镇墓兽。

## 选人界面演出（2026-10-10 用户要求，由我设计）

每位英雄在选人界面有专属的**出场演出**和**循环待机**，并在待机中随机穿插**小动作**。动作要贴合英雄的性格和技能，不做三人共用的抬枪动作。

**节奏原则**：性格决定节奏。
- 燎：快，冲过头再弹回。
- 磐：慢，蓄力长、落点重。
- 鼯：轻，飘，小动作碎。

**三人的区分**：出场方式彼此不同。燎从光柱里蹦出来，磐从天上砸下来，鼯滑翔进场。待机的重心也不同：燎爱晃，磐不动，鼯一惊一乍。

### 燎：嘴硬手快的爆竹游侠

- **性格**：爱显摆，没耐心，喜欢恶作剧，玩火从不怕烫。
- **动作特点**：快、脆、冲过头再弹回，尾巴是他的情绪表。

**出场（2.2 秒）**

| 时间 | 动作 | 特效 / 声音 |
|---:|---|---|
| 0.00 | 从光柱里压低身子冒出来，尾巴盘在脚边 | — |
| 0.25 | 弹起，左手从斜挎带上抽出一枚爆竹，在腰间火折子灯上一擦点燃 | 引信火星；嗤的点火声 |
| 0.55 | 把爆竹高抛过头顶；右手让步枪绕扳机护圈甩转一圈 | 枪身拖出一道残影 |
| 1.05 | 爆竹在头顶炸开，抬眼看，咧嘴笑 | 橙金火花、碎红纸片飘落、一下暖光；啪的爆响 |
| 1.15 | 炸开的火星凝成三团火灵，绕到尾巴周围 | 火灵各拖一道短尾焰 |
| 1.35 | 步枪甩上右肩，左手叉腰，尾巴向上甩成 S 形，一只耳朵抖一下 | — |
| 1.8–2.2 | 冲过头的姿势回弹，落进待机 | — |

**待机（6 秒一循环）**
- 重心在两胯之间来回换，步枪随呼吸在肩上轻颠。
- 尾巴用弹簧骨骼慢慢左右摆，三团火灵沿尾巴绕圈。
- 耳朵每隔 2–4 秒随机抖一下。

**小动作（每 7–11 秒随机挑一个）**
1. 掏出一枚爆竹，不点火，抛起接住，冲镜头眨一下眼。
2. 对着火折子灯吹一口气，灯火呼地窜高，他满意地点头。
3. 一团火灵绕到脸前，他嫌烦地用尾巴把它扫开。

### 磐：慢吞吞、推不动的工匠武僧

- **性格**：稳，温和，不着急；对自己的手艺很自豪。他是队伍的山。
- **动作特点**：重、慢、蓄力长，落点狠。动完马上恢复温和的笑。

**出场（2.6 秒）**：唯一不从光柱升起的出场，从天而降。

| 时间 | 动作 | 特效 / 声音 |
|---:|---|---|
| 0.00 | 一颗团起来的鳞球从画面上方落下，鳞球是单独的模型 | 鳞缝透琥珀光；下坠的呼啸声 |
| 0.35 | 鳞球砸在祭台上，弹一下 | 一圈尘环、琥珀色裂纹在祭台顶面扩散、轻微震屏；咚的一声闷响 |
| 0.55 | 鳞球展开，换成本体的蜷缩姿势：双臂抱头，尾巴裹身 | 换模型的那一帧被尘雾盖住 |
| 0.55–1.1 | 慢慢站起，背鳞从颈到尾依次张开 | 每片鳞张开时鳞缝亮一下，咔咔声连成一串 |
| 1.30 | 右拳砸进祭台，对应「裂地重击」 | 裂纹再亮一次，碎石弹起 |
| 1.60 | 从背后把钻炮抡上右肩；背鳞从尾到颈依次合上 | 一串合拢的咔哒声 |
| 2.0–2.6 | 低头一点，露出温和的笑，落进待机 | — |

**待机（8 秒一循环，慢）**
- 双脚钉在地上，胯不晃，只有又深又慢的呼吸。
- 吸气时鳞缝的光变亮，呼气时变暗。
- 钻炮扛在肩上，尾巴像扫帚一样贴着地面慢慢扫。

**小动作（每 9–13 秒）**
1. 用指节敲敲钻炮炮管，侧耳听声，满意地点头。工匠在检查自己的活儿。
2. 提起铜线锤让它垂下，看一眼垂线，再看一眼祭台，点头：「正。」
3. 打一个大哈欠伸懒腰，背鳞顺着脊背波浪般抖一遍。

### 鼯：好奇、毛手毛脚的雷鼓机关师

- **性格**：好奇，机灵，有点神经质，手上的小玩意儿总在冒火花。
- **动作特点**：轻、飘、停顿碎。像松鼠一样一惊一乍，转头很快、停得很急。

**出场（2.4 秒）**：从画面左上方滑翔进场。

| 时间 | 动作 | 特效 / 声音 |
|---:|---|---|
| 0.00 | 从画面左上方滑进来，飞膜张开成 X 形，扁尾当舵，身子略侧倾 | 飞膜边缘一道风线；风声 |
| 0.60 | 拉起减速：飞膜兜住风，身体后仰 | 风声收住 |
| 0.80 | 单膝跪地缓冲落在祭台上，尾巴向前甩保持平衡，步枪压低 | 落地一小圈尘 |
| 1.10 | 弹起，左手把风镜拉下罩住眼睛；护腕线圈冒电火花 | 噼啪的电火花声 |
| 1.50 | 腰间雷鼓亮起，一圈青紫色电光扩散；护腕和枪身线圈之间跳过一道电弧 | 咚的一声鼓响加雷音 |
| 1.8–2.4 | 把风镜推回帽子上，好奇地歪头笑，落进待机 | — |

**待机（5 秒一循环，碎）**
- 站姿轻快，脚跟微抬。
- 头每隔 1–3 秒快速歪一下，停住，再换一边。
- 扁尾一抖一抖，快抖之后慢下来。
- 飞膜随呼吸微微鼓动。

**小动作（每 6–9 秒）**
1. 拧护腕上的线圈，电火花炸了一下，他甩手吹手指。
2. 拉下风镜盯着镜头看，再推回去。
3. 抽鼻子嗅一嗅空气，尾巴卷起来。

### 技术需求（Tripo 绑定之后，在构建阶段加）

- **骨骼**：Tripo 给的是 Mixamo 65 骨人形骨架，构建时在此基础上加骨骼。做法同 `build_tripo_creature.py` 的 `biped_tail`。

  | 英雄 | 尾巴链 | 耳朵 | 其他 |
  |---|---|---|---|
  | 燎 | 6 节 | 每侧 2 节 | — |
  | 磐 | 7 节 | — | 背鳞 5 排「鳞排骨」，绕横轴转出去就是张鳞；鳞缝发光遮罩用于呼吸 |
  | 鼯 | 6 节 | 每侧 1 节 | 每侧一根飞膜辅助骨（腕与踝之间），飞膜权重在手臂、辅助骨和腿之间渐变；风镜单独一根骨 |

  尾巴、耳朵、飞膜用弹簧骨骼做惯性，参照跳鼠刀兵尾巴的参数：从根到尖刚度递减，单节最多弯 26°。
- **挂点**：
  - 燎：左手（爆竹）、火折子灯、尾尖（火灵绕圈中心）。
  - 磐：背后枪挂点（出场时钻炮先挂在背上，1.6 秒再到右手）。
  - 鼯：左右护腕线圈、雷鼓、枪身线圈（电弧两端）。
- **单独模型**：磐的鳞球形态 `SM_HeroPart_PangolinBall`，单独用 Tripo 生成。爆竹、火灵、电弧用程序化特效。
- **动画实现**：
  - 关键帧姿势表：每根骨骼的旋转轨道，加三次插值和冲过头的缓动曲线。
  - 叠加弹簧骨骼和呼吸。
  - 小动作从待机里淡入淡出，过渡 0.25 秒。
  - 枪的位置在各段之间切换（右手、右肩、背后）。持枪手由现有的 IK 握枪处理。
- **舞台**：
  - `HeroPreview` 现在固定为「从光柱升起」，加 1.5 秒拉远。需要改成每位英雄自己声明：入场方式（光柱升起、空降、滑翔）、演出时长、相机拉远包络。
  - 取景测量从角色进入画面那一刻开始量，鼯在画外滑翔的那一段不计入。
  - 「减弱动态」设置下，出场只保留落地和亮相，小动作不播。

## 2026-10-11 绑定检查与演出实现

### 绑定检查（`art/tools/review_native_rig.py`）

工具做两件事：一是按顶点的主骨骼上色出权重分区图，二是摆 8 个压力姿势，统计「动了的部位」边长拉伸的 p99 并把超过 1.8 倍的面标成品红。8 个姿势是：持枪前伸、举手 120°、深蹲、扭身转头、尾巴上卷、尾巴侧甩、甩耳朵、握拳。审核图在 `art/reviews/hero-shows-20261011/rig_*.png`。

查出的问题和修法如下。修法都在 `build_tripo_creature.py` 的 `biped_tail`，用 `creature_rigs/SK_Hero_*.json` 里的选项打开。

| 问题 | 修法 |
|---|---|
| 燎、鼯的尾巴尖被 Tripo 分给了腿，一弯就撕开 | 尾巴是独立的网格块，用 `"island": true`，整块交给尾巴链 |
| 磐的尾巴和身体连成一体 | 加宽尾巴区域，用 `max_z` 避开背包 |
| 磐背后的卷轴背包跟着左臂变形 | `rigid_islands`：盒子里的网格块整块挂到 Spine2 |
| 鼯的飞膜按高度硬切成手臂和腿两半 | `membrane`：从前臂到小腿渐变，靠近躯干时保留原权重；手和手指不参与，因为手套和飞膜是同一块网格 |
| 耳根过渡太窄 | 耳朵过渡带加宽：`blend` 0.08，`x_blend` 0.04 |
| 手臂权重越过肩线 | 加了 `arm_clamp`，实测只挪动了 6–12 个顶点。看上去占着胸口的其实是锁骨，属于正常权重 |

修完后，演出用到的范围内（手臂不超过约 100°、尾巴单节不超过约 15°、耳朵不超过约 20°）没有撕裂。下面几种姿势仍会拉伸，演出时不用到这么大：
- 举手 120° 时腋下拉伸。
- 鼯手臂前伸 75° 时飞膜被拉开，这本来就是弹性皮膜。
- 磐深蹲到底、尾巴卷到 170° 时拉伸。

发布版本：燎 v004、磐 v003、鼯 v005。

### 演出实现

| 文件 | 作用 |
|---|---|
| `src/ui/heroPreview/heroes/heroShows.ts` | 三位英雄的出场、待机、小动作时间线：关键帧加缓动，每帧写出一份姿势 |
| `src/ui/heroPreview/heroes/nativeTripo.ts` | 姿势执行器 |
| `src/assets/SpringChain.ts` | 通用弹簧骨骼，算法同跳鼠的尾巴 |
| `src/ui/heroPreview/heroes/heroShowFx.ts` | 道具与特效 |
| `art/source/attachments/SM_HeroPart_PangolinBall` | 磐的鳞球形态，用 `build_hero_part.py` 构建，绑定 hero `bear` 的 `ball` 挂点 |

姿势执行器负责这些部分：
- **整体**：入场时的整体位移和转动，滑翔和空降都靠它。
- **下半身**：髋下沉，腿用 IK 钉住脚、保持脚掌水平。
- **躯干和头**：分给脊椎、脖子和头。
- **枪**：手持、扛肩、背后三个位置之间混合，再绕扳机护圈转动。Q 版英雄的手比较大，枪按 1.35–1.4 倍放大。
- **双手**：IK 在握枪点和空手目标之间插值，手指可张开或握拳。
- **尾巴和耳朵**：先摆意图姿势，再交给弹簧骨骼算惯性。

特效分三位：

## 2026-10-11 扛枪姿势改为枪口朝天

v2 首版的扛肩姿势是握把在腰、枪管朝后上方越过肩膀，用户看成「枪都拿反了」。现在改成枪口朝天：握把在胸前右侧，枪管贴着右肩前方竖直向上，略朝外以避开 Q 版大头，枪背朝向角色。代码在 `nativeTripo.ts` 的 `shoulderQ` 和 `GUN_LAYOUT[*].shoulder`。燎和磐的待机、出场结尾都用这个姿势；鼯一直是双手低位持枪，不受影响。

## 2026-10-11 手臂、手肘、甩枪修正（用户：出场动作诡异）

- **甩枪**：
  - 原来枪绕扳机护圈转一整圈时，右手被握点 IK 拖着一起转 360°，手腕和手肘都被拧坏。
  - 现在手按「不转的枪」求解、钉住不动，枪绕扳机护圈（`TRIGGER`，枪身坐标）转。
- **手肘**：空手时不再用每个姿势手写的肘向，统一按「向外、向下、略向后」自动计算；和握枪时的肘向接近，切换时不会翻面。
- **手腕**：
  - 空手时手腕保持绑定姿势相对前臂的自然角度；握枪时才对齐枪身，两者之间插值。
  - 绕前臂轴的扭转一半分给前臂骨。Mixamo 没有前臂旋转骨，不分的话手腕处会拧成糖纸。
- **平滑**：空手目标在角色坐标里加 0.05 秒的一阶平滑，吸收时间线跳变；握枪时手直接跟枪。
- **时间线跳变**：磐出场 1.6 秒时右手从腰间瞬移到头侧。现在改成砸地、收回、伸到右肩后方握住背上的钻炮（1.66–1.74 秒），1.75 秒起抡到胸前。
- **燎的火折子灯**：
  - 灯的网格有 183 个顶点，其中 4 个被 Tripo 分给了左手拇指，左手一抬就扯出一条细线。
  - 新增构建选项 `island_majority`：400 顶点以内、九成归同一骨骼的小挂件，如果有顶点挂在另一侧（手臂或身体），整块统一用多数骨骼的平均权重。
  - 只给燎开：在磐、鼯上试过，拉伸指标反而略差。
  - 燎的抛爆竹上举也从约 100° 压到约 90°，并略朝前。
