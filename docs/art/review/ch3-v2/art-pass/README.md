## 结论（composition_check）

- **颜色**：改前「低饱和」只有 1–59%，满屏是半饱和的红褐；改后是 61–98%。3-2、3-4 和 3-1 的交战视角落在 60–80 / 20–40 / 0–7，接近 631。
  3-3 的坑底大半在影子里，铜色路面暖不起来，低饱和到了 72–89%。
- **明度**：改前的平均亮度只有 7–13%，整体发黑；改后 16–25%。改前 5%–95% 的跨度是 11–26%，改后 3-4 是 26–29%，3-2 是 20–22%，3-3 是 10–18%。
  交战区的背景是有意压在窄明度带里的（composition.md 第 6 节「明度留给人」），所以「明度挤在一条带」的提示保留，不当问题处理。
- **点缀色**：改后大多报「没有点缀色」（高饱和 < 3%）。场景里的强调色只给熔岩和焦点，最高饱和留给怪、预警、引导灯；没拍到怪、也没拍到熔岩的视角就是这样。
- **3-3 王座**：神范台入口颜色 76/19/4、明度均值 20，参考图是 60/31/9、均值 20，改前是 1/87/12、均值 21。亮度和改前持平，主色从红褐换成了冷暗紫。
  暖意来自暖橙烟雾天、局部调色（色温 +12）和熔岩柱、圆环、熔渠。
- **怪的可读性**（composition.md 第 6 节自检，[3-3/check/enemy_readability.jpg](3-3/check/enemy_readability.jpg)）：近处的怪又亮又饱和，去色后也最跳。中距离的小怪去色后和灰紫背景只差一点，主要靠红色的色相读出来；
  同一画面里更抢眼的是爆炸烟团和大片亮熔岩。熔岩横在交战视线上是布局问题（③ 浇包吊坊的熔渠就在怪身后），要地图路把熔岩挪到侧面；中距离怪的轮廓光 / 描边属于角色美术。
  抬头时天上的太阳原来是一块 HDR 白盘，这一批改成了暗暖光晕。
