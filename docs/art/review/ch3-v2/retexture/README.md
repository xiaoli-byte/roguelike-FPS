## 结果

| 件 | 细节梯度均值 | 碎像素 | 高饱和 | 平均色 | 结论 |
|---|---|---|---|---|---|
| 火坛 FireAltar（v002） | 0.0189 → 0.0126（−33%） | 10.1% → 5.3% | 0.2% → 0% | 偏红褐 → 偏紫 | 白黄火苗没了，炭床暗紫黑；日纹板、铜鼎照原设计 |
| 圆殿墙段 RoundHallWall（v003） | 0.0142 → 0.0115（−19%） | 9.6% → 7.5% | 1.4% → 1.5% | 蓝灰 → 冷暗紫 | 砌块线、铆钉、砂浆缝基本收掉，大面安静；日纹饰带简化成平涂圆盘 |
| 岩肋 RockRib（v003） | 0.0144 → 0.0124（−14%） | 9.0% → 7.8% | 1.8% → 1.7% | 褐灰 → 冷暗紫 | 岩面安静；熔岩缝原位保留；朱漆日纹不再发光 |
| 玄武岩柱丛 BasaltColumns（v003） | 0.0049 → 0.0048（持平） | 2.0% → 2.0% | 1.6% → 1.6% | 暖褐灰 → 冷暗紫 | 原来就不碎，变的是颜色：从暖褐换到和地形同一套的冷暗紫 |

## 判断

- 本来就碎的件（圆殿墙段、岩肋、火坛）细节梯度降了 14–33%，碎像素少了 1–5 个百分点。
- 四件的主色都从暖褐 / 蓝灰换成了冷暗紫，和 ch3-look 的地形色板一致。
- 熔岩缝位置、自发光面积都没变。

结论是明显变好，可以铺开。关卡里中距离的同机位对比要等 Unity 侧导入（等 3-4 收尾提交）后补到这里。
