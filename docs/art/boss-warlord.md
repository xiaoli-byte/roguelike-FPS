## 1. 定位与设计（以用户选定的设定图为准）

**定位**：第三章领主，祝融火山铸坊里用地火和熔岩铸成的魔将，熔火深渊的统帅，重剑士。

- **设计依据**：用户 2026-11-01 选定的设定图 `art/source/characters/_design/inferno/inferno_boss_warlord/user_concept_molten_warlord.webp`（入库，1792 × 1024）。
  - 这张是 Tripo 图片 tab 第一轮出图（DS v001）里的一张，用户自己挑出来并下载；
  - 图上标了「4.2 m」，旁边画了 1.8 m 的人作比例；
  - 原话：「把刀和人物分开，用这个概念图的挺好」。
  - 我之前另出的 DS v003（墨色战裙、无红布）不再使用，见第 2 节。
- **四视图要忠实于这张图**：不自己改造型。只做三处建模需要的改动：
  - 人和剑分开；
  - 本体摆 A 字、空手；
  - 熔岩裂纹画成平涂暗橙（特效分离的底态）。

### 1.1 大形和比例

| 项 | 定稿 | 说明 |
|---|---|---|
| 身高 | **4.2 m**（角尖） | 玩家 1.8 m，约 2.3 倍。和旧模型（包围盒 4.14 m）、`WarlordDef.height = 3.6` 的胶囊同档，场地和碰撞不用重调 |

### 1.2 色块（设定图色板）

| 色块 | 用在哪 |
|---|---|
| **暗紫灰岩**（主色） | 全身岩质甲片：开裂的岩面，大块面 |
| **暗红** | 胸前到膝下的破旧战旗布：图腾纹，边缘撕裂；背后一块短一些的红布 |

- **和火麒麟拉开**：靠岩甲加裂缝熔岩的质感、直立重甲剑士的体型、方块岩甲和月牙角，不靠颜色。
  - 火麒麟是四足马鹿，玄铁鳞片、火焰鬃毛，母题是圆 / 环；
  - 魔将的红只在一块战旗布上。
  - 我之前定的「不要红布」作废，以用户的图为准。

### 1.3 熔岩纹的位置（之后烘发光遮罩用）

- **R 层 · 甲缝熔岩纹**：
  - 胸甲正中那道竖裂；
  - 肩甲、上臂、小臂、大腿、膝甲的裂缝；
  - 都是中尺度的粗裂缝。
- **G 层 · 最亮的芯**：眼睛，加上裂缝里最亮、最宽的那几段。狂怒时白热。
- **B 层 · 胸口地火之心（弱点）**：
  - 胸甲正中熔岩裂缝最宽的一段，就是地火之心，挂点 `socket_core`；
  - 平时微亮，破绽窗口里烧亮。弱点由 main 定为胸口（2026-11-01），角盔 `socket_helm` 只当普通部位。
- **规则沿用**（[vfx/warlord.md](vfx/warlord.md) §0、§狂怒）：平时一点余烬、每招前摇烧亮、狂怒（20%）白热。
  - 层色和强度在 `WarlordBrain` 里，这边只管「哪里亮」。

### 1.4 熔心大剑

- **独立挂件**：保留 `SM_BossWeapon_Greatsword`，**单独进 Tripo**（用户 2026-11-01）。
  - 双手握持的动作要剑是刚体、能挂在手上换握；并进本体的话，剑会和手熔在一起；
  - 现有代码（`WarlordBlade`、`EnemyCatalog` 的 `bind = boss_warlord / greatsword`）也是按挂件写的。
- **形制**（设定图的 GREAT SWORD / SWORD REAR）：
  - 总长约 3.2 m；
  - 剑身是很宽很厚的粗岩：暗紫灰，刃口不规则，剑尖是崩口的楔形，剑身上布满熔岩裂纹；
  - 剑格：直的十字铁格，两端铜帽，中心一个铜环；
  - 剑柄缠深色皮革，有铜箍；
  - 剑首是一个大铜环，挂一小撮暗红穗子。
- **发光遮罩分两层**：R = 剑身熔岩裂纹，G = 刃口。剑格、剑柄不亮。

**本体骨架**（`python art/pipeline/tools/build_warlord_rig.py` → `python art/pipeline/build_tripo_creature.py SK_Boss_Warlord --publish`）：

- 64 根骨（二轮加角根红缨两条短链后 68 根）：名字、人形层级和 11-01 版一样，`warlord_anims_humanoid.py` 的 33 段动作和 Unity 侧的招式 / 事件直接用。
- 坐标全部按新网格实测（发布到 4.2 m 后的米制，左侧量、右侧镜像）：
  - 躯干中线不在 y = 0：胸甲前凸、背后挂战旗，髋 / 脊 / 胸 / 头都放在 y ≈ -0.06 ~ -0.13；
  - 手臂是小幅 A 字：肩 (±0.70, 3.17) → 肘 (±0.93, 2.67) → 腕 (±1.175, 2.17)。手掌朝内，四指朝外下。
    四指被 Tripo 熔成一块，按指缝的 y 位置分骨（食 -0.31、中 -0.25、无名 -0.18、小 -0.11），拇指单独；
  - 腿外撇：髋 (±0.29, 1.90) → 膝 (±0.59, 1.08) → 踝 (±0.72, 0.38)，脚尖外撇约 17°；
  - 布料四块，各配一条弹簧链：
    - `skirt_F1..3`：前战旗，腰扣下 z 2.35 → 0.82；
    - `skirt_B1..3`：后战旗，z 2.36 → 0.76，往后张；
    - `skirt_L/R1..2`：两侧红披，从肩后的缨穗结垂到 z 0.8，往外后方张开；
    - `tassel_L/R1..2`：胸前两条缨穗，z 3.1 → 2.6。
  - 侧披和缨穗是从肩上垂下来的，链根从 hips 改挂 chest。挂 hips 的话上身一前倾，挂在肩上的布就和身体脱开。
