# 熔心魔将 · 招式动作与特效设计单（VFX 调优 W 路，2026-10-31）

熔心魔将是第三章 3-3 铸范大坊的领主（神范台：十字浅渠和中央熔池环着一座铸铁台）。他是熔火深渊的统帅：一身玄铁熔铜铠甲，胸口一颗地火之心，头戴角盔（弱点），手持一柄熔心大剑。
本单写他全部七个招式（冲锋留火、横扫、陨石雨、跃击、连斩、熔铜渠涨落、20% 狂怒），以及登场和倒下。

- **世界观母题**：
  - **熔铜铠甲**：铁甲的缝里流着熔铜；
  - **地火之心**：胸口的炉心；
  - **战阵与号令**：举剑号令天火、插剑引动熔铜渠；
  - **陨火**：自己从天上砸进场地、跃击像一颗陨火坠地。
- **形状语言：重、方、斩**：
  - **斩** = 月牙。刀光一律是「暗月牙托亮刃」：底下垫一层暗紫褐的月牙，中间是实色熔铜，外缘一道白热刃口；
  - **方** = 方块。碎屑是方铜渣、铁片，不用圆点和细碎颗粒；
  - **重** = 粗环、深蹲、顿帧。落地、劈地都有贴地的卡通粗环和局部顿帧，没有写实冲击波扭曲。
- **色阶**：火 + 第三章熔火，三阶。代码在 `WarlordPalette`（`Fx/Fx.Warlord.cs`）。

  | 层 | 常态 | 狂怒（20%，换挡） |
  |---|---|---|
  | 亮芯 | 白热铜 `#ffe6a6` | 近白 `#fff6dc` |
  | 主色 | 熔铜橙 `#ff8a2e` | 亮铜 `#ffb24a` |
  | 暗边 | 赭红 `#b8461a` | 赤 `#ff4a14` |
  | 烟 / 暗衬 | 紫褐烟 `#4e3442`、暗月牙 `rgb(0.13, 0.045, 0.06)`、铁渣 `#3a2a26` | 同左 |

  烟偏紫褐、余烬是铜橙，符合 fx-style §2.2 第三章底色。
- **和火麒麟（Q 路，3-4）区分**：
  - 魔将只用**铜和铁**、**方和月牙**；
  - 麒麟是玄鳞（青黑鳞光）和圣火（金白），母题是宝鼎的圆 / 环。
- **预警**：一律沿用 TelegraphTone。第三章关卡自动换品红，配色没改；只改了出现的时机，让预警从起手那一刻开始画、填满正好对上释放帧（原本就是这样，本次复核过）。

## 0. 先修的两件事：剑和动作

1. **熔心大剑原来没挂上**。
   - 部件骨架的 Hunyuan 网格按设定不带剑（registry 的 brief：剑是单独的挂件 `SM_BossWeapon_Greatsword`）。挂件早就生成了，但部件骨架没有 `socket_greatsword`，`Bosses.AttachParts` 挂不上。所以以前魔将一直是空手挥砍，刀光凭空出现。
   - 现在 `WarlordBlade.Attach` 在 `WarlordBrain.Spawn` 里把大剑挂到握点骨 `j_0_1_21_1_5` 上：
     - 用蒙皮的绑定姿势（bindpose）对齐。两份资产走的是同一套导出，资产空间一致：握点就是剑柄原点，剑尖朝下；
     - 再按剑尖骨 `j_0_1_21_1_5_11` 校一次剑身方向；
     - 剑长 2.70 m。
   - 这一步不改模型网格，只是把已经入库的挂件挂上去。
2. **招牌招式改用 Blender 手 K 关键帧**。
   - 以前用的是从 Three.js 程序动画采样出来的片段，幅度很小，看不出起手和释放。
   - 现在 20 段都是 Blender 脚本写的关键帧，同名覆盖采样片段（关键姿势总览 [warlord-keyposes.jpg](../review/boss-vfx/W/warlord-keyposes.jpg)）：
     - 横扫 4 段：`sweepReady` `sweep` `sweepReady2` `sweepBack`；
     - 连斩 3 段：`slashA` `slashB`，新增收尾刀 `slashC`；
     - 冲锋 4 段：`chargeReady` `charge` `crash`，新增刹停 `chargeStop`；
     - 跃击 3 段：`crouch` `leap` `land`；
     - `raise`、`plant`、`roar`；
     - 新增：登场下坠 `fall`、倒下 `death`、受击 `Hit`（框架在眩晕 / 硬直时按状态名播 `Hit`，以前部件骨架没有这个状态，会报「State could not be found」）。
   - 写法：
     - 底姿是采样待机的第 0 帧（嵌在脚本里），和仍用采样的待机 / 步态之间过渡不跳；
     - 四肢、大剑直接给方向（最短弧旋转），双手持剑用两骨 IK 把右拳放到两肩中点前方，左手 IK 握到剑柄上；
     - 腿用两骨 IK 把脚掌踩回地面（部件骨架没有 CreatureRig 的脚 IK）；
     - 披风单独 K，滞后跟随身体，做出 follow-through。
   - 审核：`warlord_anims.py --review <目录>` 每个关键姿势出正面（玩家视角）+ 俯视两张图。

## 1. 通用做法

### 1.1 释放帧对齐

- 片段按招式的实际前摇拉伸（`WarlordBrain.Act` 用 `ActScale`），刀到 / 落地 / 插剑那一帧落在招式判定时刻。
- 招式在判定那一刻调 WarlordBrain 的钩子登记，表现（顿帧 + 震屏 + 出手特效）等片段的 `hit` / `impact` / `cast` 事件再放：
  - 事件比判定先到，就立刻放；
  - 0.15 s 内没等到（代理模型、没有片段），按判定时刻兜底放。
- `LastHitSkew` 记事件和判定差多少。节拍条套件在不截图的对照段里逐招记下来，目标是 ≤ 1 帧（0.033 s），实测见第 11 节。

### 1.2 顿帧

- `WarlordBrain.Hold`：只冻魔将自己的 Animator（×0.04），全局时间不动，不顿玩家的手感。
- 时长按重量分档：
  - 0.045 s：连斩没砍中；
  - 0.06 s：横扫、连斩砍中；
  - 0.08 s：插剑、撞墙；
  - 0.09 s：竖劈、跃击落地；
  - 0.1 s：狂怒换挡、登场落地。
- 震屏走现有的 `CameraShake.Quake`（按距离衰减），强度同档递增。

### 1.3 主形：暗月牙托亮刃（`WarlordArc`）

- 两头尖、中间厚的月牙，厚度按 sin^0.7 收。
- 三层：
  1. 暗衬：普通混合，暗紫褐，比本体大一圈、略往外偏。在亮的熔岩上压得出轮廓，暗处也不会发黑。
  2. 本体：普通混合的实色块，内缘赭红、外缘熔铜，两阶软阶梯。不靠加法叠色，免得发白。
  3. 刃口：加法，只在最外 14% 的一道白热线，刀头那一段最亮。本体不用加法、也不提亮——加法铺满整弯会在泛光里冲成一片奶白（第一次实拍就是这样）。
- 颜色写顶点色，写之前过 `FxVertexColor.Linear`：工程是线性色彩空间，粒子材质把网格顶点色直接当线性值用；
  直接写调色板的 sRGB 值，铜橙 #ff8a2e 的绿 0.54 会显示成 0.76，整弯冲成淡桃 / 奶白（第二次实拍的问题）。
- 时间：
  - 第一帧刀头就扫到 40%，亮芯第一帧到峰值；
  - 前 40% 寿命刀头缓出扫到尽头；
  - 35% 寿命起刀尾从起点往刀头收掉，整体往外扩 8%；
  - 寿命 0.28–0.34 s。
- 池化：最多 10 道。

> 通用刀光 `SlashArc` 是等宽的加法光带，在 3-3 的暗红打光里会叠成一片发白的浅带（改前的拼图里看得到），所以魔将不用它。
> 它的顶点色也有同样的问题，已经一并改成按线性写（所有敌方刀光和玩家妖刀第三段的伸刃横扫都受影响），改前 / 改后见 `docs/art/review/boss-vfx/W/slash-linear-*.jpg`；
> 等宽加法光带这个形状问题还在，那是各章刀光自己的事。

### 1.4 次级：大剑拖影（`WarlordBlade`）

- 跟着真实的刀走：片段的 `smear` 事件开始记，`smearEnd` 停。
- 每帧记下剑身（握点 + 方向），相邻两帧之间按握点插 3 份弧线：转角用 slerp，大剑挥过的是弧，不是弦。
- 画成两层带子：
  - 暗衬，普通混合；
  - 亮刃，加法，剑尖那一半最亮。
- 0.2 s 内淡掉。
- 低画质不插值，段数减半。

### 1.5 焰刃（常驻）

- 剑身自发光走正式发光遮罩 `T_BossWeapon_Greatsword_E`（第二批收尾 C 路：R 剑脊熔铜纹、G 刃口，剑格剑柄不亮；狂怒时刃口白热，见 [glow-masks-crack-ch3.md](glow-masks-crack-ch3.md) §2）。原来借底色贴图当 `_EmissionMap`，材质没开 `_EMISSION`，那层一直没画出来。
- 亮度随前摇烧亮（`Heat` = WindupGlow），狂怒后常亮白热；边光同步转白热。
- 剑尖滴铜火星：平时每秒约 1 颗，烧亮时约 6 颗。
- 狂怒时剑身两片白热火舌。

### 1.6 点缀与预算

- 点缀：
  - 方铜渣：`InfernoBasalt` 预设染铜 + 7 颗拉丝火星；
  - 紫褐烟团：2–6 团，0.9 s；
  - 火星。
- 预算：
  - 粒子全部走 `Fx.Burst` / 预设，计入 `FxBudget`，按画质密度缩；
  - 月牙、拖影是固定顶点数的网格（月牙 3 × 132 顶点，拖影 2 × 160 顶点），不吃粒子预算；
  - 实测见第 11 节。

## 2. 烈焰冲锋（拖刀冲锋）

- **设定母题**：统帅压阵冲锋，大剑拖在身后犁地，剑尖犁过的地方燃起火（沿途留火是招式本身）。形状：一条直线，表示方向和切割。
- **读感目标**（前摇 0.9 s，二阶段 0.75 s，连冲第二次 0.65 s）：
  - **从哪来**：低身、左肩在前，大剑拖在右后。剪影是一张「拉满的弓」；
  - **打哪里**：直线预警（招式画），宽 3.4 m；
  - **多大**：预警长条，最长 26 m；
  - **什么时候**：预警填满 = 起跑，蓄力顶点那几帧身体压到最低，还在微微颤；
  - **元素**：火，剑身烧亮。
- **节拍表**：

  | 节拍 | 秒（一阶段） | 关键姿势 |
  |---|---|---|
  | 起手 | 0–0.27 | `chargeReady` 帧 0 → 8：key 后仰蓄力（上身后仰 12°、大剑往右后拖） |
  | 预警 | 0–0.9 | 直线预警从起手第一帧开始画，填满对上起跑 |
  | 蓄力顶点 | 0.67–0.9 | 帧 20 → 27：extreme 低身前压 28–31°、左肩在前、大剑剑尖贴地（moving hold） |
  | 释放帧 | 0.9 | 起跑：`charge` 帧 0；起步的紫褐尘、铜火星、震屏 |
  | 持续段 | 0.9 → 约 2.0 | `charge` 奔跑循环：每 6 帧一步，`step` 事件踏一团尘、轻震；剑尖犁地一路甩铜火星（每 0.045 s 一撮） |
  | 收招 | 0.5 s | 刹停 `chargeStop`：帧 3 extreme 后仰刹车、大剑插地，剑尖一扇火星 + 一道熔铜沟 + 紫褐烟。这段就是惩罚窗口 |
  |  | 1.0 s | 撞墙 `crash`：帧 0 撞击 → 帧 4 反弹后仰 → 帧 12 晕眩低头 → 帧 20 甩头。顿帧 0.08 s，熔铜炸开、方铜渣、紫褐烟 |
  | 余韵 | 0.6 s | 火尾体积（招式放）0.3 s 收掉，烟团散 |

- **特效层次**：

  | 层 | 内容 | 色阶 | 寿命 / 数量 |
  |---|---|---|---|
  | 主形 | 直线预警（招式）+ 身后火尾体积（`Surge.Trail`）：暗边赭红、芯熔铜，不再是白热的一团 | 赭红 / 熔铜 / 白热铜 | 跟跑程，0.3 s 收 |
  | 次级 | 剑尖犁地火星、刹停熔铜沟贴花 1 块 | 熔铜 / 白热铜 | 每 0.045 s 3 颗 |
  | 点缀 | 起步 / 刹停 / 踏步的紫褐烟团 | 紫褐 | 2–3 团，0.9 s |

- **动作配合**：
  - 起手 squash：下沉 0.38–0.42 m；
  - 起跑 stretch：`charge` 第 0 帧前倾 30°、步幅 1.1 m；
  - 刹停的 follow-through：披风前甩 26°，上身后仰；
  - 撞墙 overlapping：头先后甩，大剑晚 2 帧才甩开。
- **第一人称**：
  - 14 m：远处一个压低的剪影，剑尖的火星指着冲锋方向，直线预警是品红的；
  - 被冲中时：火尾体积不糊屏（锥尾是半透明的分层色块）。

## 3. 火焰横扫（重斩）

- **设定母题**：统帅横扫千军。大剑从右后绕过身前扫到左前，刀风卷起一道火浪（扇形冲击波由招式放）。形状：月牙（斩）+ 扇形（范围）。
- **读感目标**（前摇 0.85 s，二阶段 0.7 s）：
  - **从哪来**：拧腰、大剑高举在右后，正面看过去剑身横在右肩外，剪影大；
  - **打哪里**：扇形预警，半角 64.7°、14 m；
  - **多大**：扇形；
  - **什么时候**：顶点那几帧大剑还在往后再压一点，预警填满正好刀到；
  - **元素**：火，熔铜月牙。
- **节拍表**：

  | 节拍 | 秒 | 关键姿势 |
  |---|---|---|
  | 起手 | 0–0.23 | `sweepReady` 帧 0 → 7：breakdown 重心后移、大剑拖向右下（`SWEEP_LOAD`） |
  | 预警 | 0–0.85 | 扇形预警，起手第一帧开始画 |
  | 蓄力顶点 | 0.62–0.85 | 帧 19 → 26：extreme 拧腰 48–53°、下沉 0.3 m、大剑高举在右后上方（`SWEEP_COCK`），左臂前伸配重 |
  | 释放帧 | 0.85 | `sweep` 帧 0 smear（刀在右前、上身回正一半）→ 帧 1 `hit`（刀到身前）。同帧：顿帧 0.06 s、震屏 0.45、月牙 |
  | 持续段 | 0.85–1.65 | 火浪按 16 m/s 推到 13 m（招式） |
  | 收招 | 0.85–1.3 | 帧 5：extreme follow-through，拧到左边 58°；帧 14：大剑垂在左前低处、上身前倾 20°，这是惩罚窗口 |
  | 二阶段反手 | +0.2 起 | `sweepReady2` 0.55 s：从左下拧到左后高举，蓄反手；`sweepBack` 从左往右扫，镜像同上 |
  | 余韵 | 0.4 s | 方铜渣落地，紫褐烟团 |

- **特效层次**：

  | 层 | 内容 | 色阶 | 寿命 / 数量 |
  |---|---|---|---|
  | 主形 | 暗月牙托亮刃：中心 1.45 m、朝玩家那侧低头 14°（前缘约 0.4 m 高，第一人称看得到整弯的面）、半径 4.4 m、弧 = 扇形全角、最厚 1.7 m，方向跟刀走（反手 dir = −1） | 暗紫褐 / 赭红→熔铜 / 白热 | 0.34 s，1 道 |
  | 次级 | 大剑拖影（`smear` → `smearEnd`）、贴地火浪体积（招式，改成熔铜两色） | 同上 | 0.2 s / 0.8 s |
  | 点缀 | 沿弧切线甩出 3 组方铜渣、脚下紫褐烟 3 团 | 铁渣 + 熔铜 / 紫褐 | 0.35 s / 0.9 s |

- **动作配合**：
  - 蓄力：squash（下沉）+ 扭转，头反拧 38–40° 盯住玩家；
  - smear 帧：上身只回正一半、刀已到右前，拖影从这一帧开始画；
  - 释放帧之后 3 帧到 extreme follow-through；
  - 披风先往右甩 8°，扫过之后反甩 −14°；
  - 顿帧冻在刀到身前那一帧。
- **第一人称**：
  - 8 m 中距：起手时正面看到大剑横在他右肩外，剪影比以前宽一倍；
  - 释放帧：月牙从右往左横过视野，压低的那一侧朝着玩家，准星以下，不挡准星；
  - 暗衬在熔岩、亮砖上都托得出月牙。

## 4. 焰刃连斩（三斩 / 狂怒四斩）

- **设定母题**：近身三连斩，最后一刀双手竖劈入地。这是「斩」的本意：前几刀快、最后一刀重。
- **读感目标**（每斩 0.72 s：0.5 s 前摇 + 出刀）：

## 11. 实测

数字都来自 `bridge.sh playtest beats-warlord`。

### 11.1 释放帧对齐

对照段不截图。数值是片段的 hit / impact / cast 事件减去招式判定时刻，目标是不超过 1 帧（33 ms）：

| 招式 | 第 1 轮 | 第 2 轮 |
|---|---|---|
| 反手横扫 `sweepBack` | −23 ms | −21 ms |
| 竖劈 `slashC` | +17 ms | +11 ms |
| 跃击落地 `land` | +15 ms | +12 ms |

- 截图的那几帧很慢（一帧要渲染两三台相机、编码 jpg），事件会晚一帧到，节拍条里记的偏差只供参考。
- 兜底规则是至少等 0.15 s、4 帧，所以只有截图那几招会走兜底。

### 11.2 性能

- 同一会话里旧特效、新特效交替跑六轮，每轮横扫 / 连斩 / 跃击各一次，画质为高，在编辑器里测。
- 结果见汇报。
- 编辑器帧时间的波动有 ±10%，几次测量里新特效在 −3% 到 +14% 之间。
- 修整之后去掉了落地和插剑的熔铜火团、竖劈裂地线只留 3 节，方铜渣每圈只放一次铁片预设。
