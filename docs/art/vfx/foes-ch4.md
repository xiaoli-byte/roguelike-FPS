# 第四章雷魅 · 招式动作与特效设计单（第四章移植 E 路，2026-10-31）

第四章「雪域天路」的八只雷魅（+ 雷牦）和游猎精英穷奇，从网页可玩版（`src/world/plateau/play/`）移植进 Unity。
网页版是参考、不是照抄（[unity-ch4-port.md](../../unity-ch4-port.md) C4-7、「Critical, not copy」）：**招式表、时间轴、判定数值照搬**（[chuanzang-combat-v1.md](../../level-design/chuanzang-combat-v1.md) 第 3 节、[ch4-move-events.json](../ch4-move-events.json)），**动作、特效、手感按 Unity 现行标准重做**（首领与精英动作调优那一套：设计单 → 手 K → 特效按风格准则 → 顿帧 / 震屏 / 特效对齐到释放帧）。

## 0. 总则

### 0.1 设定母题：雷魅带电，燎点火就炸

黄帝以夔皮为鼓、雷兽之骨为槌；夔的雷魂沉在神山海子里，灵火失控后雷暴卷过高原，旱獭、野牦和西山经的异兽被雷火侵蚀成「雷魅」（[enemy-roster-v2.md](../enemy-roster-v2.md)「第四章」）。
所有招式都从这一个母题长出来：

- **雷是它们身上的病**：放电从毛尖、角、眼、弱点处冒出来，越要出手越亮——发光就是预警的一部分；
- **它们之间会连电**：啸獭电网、蛮蛮比翼、连鼓灵的鼓点电弧，都是「两点之间一道雷」，形状是**折线锯齿 + 少量分叉、粗细有对比**（fx-style §3「雷」）；
- **带电 = 身上有雷殛**：燎的火一碰就是焚雷；打爆带电的，电往同伴身上跳。所以「谁在带电」必须一眼读得出来——身上的噼啪、边缘光、连线。

**形状语言**（boss-vfx-rules 第二节）：

| 形状 | 用在 | 意思 |
|---|---|---|
| 折线锯齿（雷刃） | 落雷、电网、比翼电弧、鼓点电弧、吞雷 | 雷：两点之间、天上到地上 |
| 圆 / 环 | 尖啸声环、雷球砸地冲击环、惊雷、球雷、雷心、落点圈 | 范围、能量 |
| 符印圆（圈 + 四齿 + 三爻） | 天狗雷标、雷石电场 | 「这里要落雷 / 这里带电」：中尺度的东方纹样，线粗而少 |
| 尖角、月牙 | 扑咬爪痕、四角挑、穷奇翼刃 | 切割、危险 |
| 方块 | 举父的雷石、碎石、獓狠蹄下的土块、钻洞的土团 | 土石、重量 |
| 流线 | 蛮蛮的扫线、穷奇的滑翔气流、羽毛 | 风、掠过 |

### 0.2 色阶（fx-style §2.1 雷 + 第四章底色）

雷的元素色是「蓝白 / 白 / 靛紫」；第四章的**腐化雷光**按 C4-4 改成「邪火紫红雷光、白芯」，和第一章金白日火、第二章青紫霜火、第三章熔岩橙一眼分开。三阶：

| 阶 | 颜色 | 用在 |
|---|---|---|
| 亮芯 | 粉白 `#fff2fb` | 雷刃的芯、释放帧第一帧、白星 |
| 主色 | 紫红 `#ff4fd8` | 雷刃的身、电弧、符印、发光壳 |
| 暗边 | 靛紫 `#4a1a6e` | 雷刃底下垫的暗衬、冲击环的外缘、电场的暗底 |

辅助色：静电护盾淡紫 `#c79bff`（连鼓灵普通鼓）、加速珊瑚红 `#ff8f7a`（连鼓灵红鼓）。
环境色按第四章底色（F 路写进 fx-style §2.2）：高原尘 = 灰褐 `#9a8a6c`（不用沙黄）、雪粒冷白 `#e6edf4`、草屑青绿 `#6f8f3e`、石块 `#6e665e`。
蓑毛烧着走全局的火色（橙红 / 金黄 / 赭红烟），烧出来的雷筋是紫红——火和雷在同一只身上并存，正好讲「燎点火就炸」。

**预警的颜色**（C4-4，chuanzang-combat 1.5）：
- **会挨打的范围一律 `TelegraphTone.Danger`**（草甸、雪地上是正红，由 `TelegraphPalette` 按关卡给），不改配色体系；
- **紫红只出现在元素身份层**：雷标的符印圈、冲撞线上冒的电火花、电场的边、比翼电弧。身份层画在危险填充之上、细而亮，填充是红、符印是紫，两者分得开；
- **白星**（出手闪光）：只给「挨了会很疼」的招（踩踏、雷球砸地、球雷、掠空扑杀），出手前 0.25 s 在弱点上闪一下。

### 0.3 通用做法

1. **招式时间轴 = 网页 MoveDef**：每招「前摇 → 出手 → 收招」三段，时长照 ch4-move-events.json；状态名 = 招式 id；一招一个片段（三段连着录），`PlayTimed` 拉到招式总长，`ActScale` 正常为 1（连鼓灵红鼓加速时 1.4）。
   - 出手段可变长的招（獓狠踩踏、穷奇滑翔）：提前收招时 `CrossFadeInFixedTime(状态, 0.1, 0, 收招起点)` 跳到片段的收招段。
2. **出手跟动画事件走**（`Anim/<资产>.events.json`，照 ch4-move-events.json 的 clips 抄，加节拍点）：`warn` 起手画预警、`glint` 白星、`hit` / `release` / `land` 释放帧；
   AI 收到事件就出手，没收到（占位体、动画被裁）就按时间轴兜底（事件与时间先到者算，同 `BossMove.Cue`），两者相差 ≤ 1 帧（片段按招式总长拉伸，事件时刻 = 时间轴时刻）。
   **预警时长 = 前摇时长**，起手那一帧画、释放帧正好填满。
3. **释放帧四件套对在同一帧**：判定 + 亮芯第一帧到峰值的主形 + 局部顿帧（只顿自己的 Animator，0.04–0.08 s，精英由 EliteStrike 管）+ 按距离衰减的震屏（`CameraShake.Quake`）。音效第二期。
4. **受击四层**（chuanzang-combat 1.1）：闪白 + 数字（EnemyBody 原有）→ 方向小抖（CreatureRig.Hit）→ 硬直（2 s 内韧性伤害累计超过韧性：弱点 ×2、爆炸 ×3；打断非霸体招、撤预警，播 `stagger`）→ 眩晕（反制 / 封脉，`stun` 循环 + 头顶一圈紫白火花）。
   F 路落地后改成覆写通用入口，见第 11 节。
5. **四种死法**（Unity 用布娃娃，不做死亡片段——布娃娃在高原起伏地形上比固定倒地片段可信，和前三章一致）：
   - **普通**：布娃娃按最后一击方向倒；
   - **弱点**：弱点处一团白闪 + 头 / 弱点那根骨额外一甩（冲量），倒得更快；
   - **爆炸**：布娃娃被掀起、打转（上抛 + 水平速度 + 角速度），落地扬一团高原尘；
   - **带电**：倒下时身上一圈紫红噼啪，把电放给 8 m 内最多 2 个同伴（雷刃连过去，它们带电 6 s）。
   帝江都是炸（球雷 / 爆囊），连鼓灵是雷心裂开、鼓和骨槌叮当落地。
6. **带电的读感**（所有带电的怪统一）：边缘光（F 路的带电视觉，转接层先用覆盖色通道 `plateauCharge` 淡紫一层）+ 每 0.12–0.27 s 一道贴着身体的短雷刃（2–4 节折线）+ 状态图标。
   Tripo 模型金属度为 1 时带电会被染成一片紫（C4-5），F 路统一改非金属，带电走边缘光。
7. **手 K 覆盖采样**（C4-7）：招牌招式用 Blender 手 K（`art/source/characters/<资产>/anim/*.py` → `Anim/Keyframed/<招式>.fbx`，同名优先），其余用 `_plateau.mjs` 从网页程序化姿势采样打底。
   手 K 片段时长 = 招式总长、关键姿势落在节拍表的时刻上，事件不变。
8. **预算**：主形是固定顶点数的网格（雷刃池 48 道、符印池 16 个、月牙池 8 道）；次级 / 点缀走 `Fx.Burst` / 风格预设，计入 `FxBudget`、按画质密度缩。低画质下雷刃去掉分叉、暗衬，只留芯和身。

## 1. 啸獭（群怪·哨兵）

- **设定母题**：高原旱獭成窝，站岗的直立张望、尖叫报警（真实习性）；雷魅化之后毛里攒静电，挤在一起就连成一张网。
  形状：尖啸 = 一圈圈往外扩的**声环**（竖直的环，读作「声音」）；电网 = 獭与獭之间的**雷刃**；扑咬 = 小的**三道爪痕**；钻洞 = **方块土团**。
- 数值：血 40、移速 6.5、韧性 18、硬直 0.4 s、轻怪每挨一枪顿 0.12 s；弱点头 ×2、尾尖静电球 ×2.5（侧面、背后才打得到）。

### 1.1 `scream` 尖啸（哨兵，1.2 / 0.3 / 0.6）

- **读感目标**：0.4 s 内读出「它要叫人」——直立、仰头、两爪抱胸，嘴边紫光从暗到亮，头顶冒「！」；1.2 s 内打死或打出硬直就只叫醒自己这窝。不伤人，所以不画地面危险预警。
- **节拍表**（总 2.1 s）：

| 节拍 | 秒 | 关键姿势 | 特效 |
|---|---|---|---|
| 起手 | 0–0.3 | key：从四足跳成直立（hips −0.15、脊柱后仰），耳朵贴后 | 头顶「！」（紫红符号，0.25 s 弹出）；尾尖静电球亮起 |
| 预警 | 0.3–0.9 | extreme：仰头到顶（头 −0.45），两爪抱胸 | 嘴边紫光从 0 涨到 1（发光通道 0） |
| 蓄力顶点 | 0.9–1.2 | moving hold：整只往后挺、头颤（40 Hz 小抖） | 嘴边亮到发白；毛尖冒 3–4 颗细电火花 |
| **释放帧** | 1.2（`shout`） | 嘴张到最大，前爪一抖 | 三圈竖直声环（主形：粗环 1.2 → 18 m，0.6 s，紫红边、白芯，一圈比一圈晚 0.08 s）+ 贴地一圈尘环；顿帧 0.04 s；60 m 内的兽群醒 |
| 持续段 | 1.2–1.5 | 保持张嘴，抖 | 声环继续扩 |
| 收招 | 1.5–2.1 | 落回四足、抖毛 | 毛尖散几颗静电 |

- **特效层次**：主形 = 声环（3 个竖直的环带网格，各 0.6 s）；次级 = 「！」符号、嘴边光、贴地尘环；点缀 = 毛尖电火花 6 颗。
- **动作配合**：起手的直立是全章最好认的剪影（远处只看轮廓也知道是哨兵在叫）；仰头 → 释放帧张嘴前倾一点点（反向的 stretch）；收招抖毛是 follow-through（耳朵、尾巴滞后）。
- **第一人称**：远距离（30–48 m，哨兵站在巨石上）：直立剪影 + 「！」+ 嘴边紫光，三样都在剪影上方，准星对得上；声环扩到 18 m，玩家多半在环外，只看到环从远处扩开，不糊屏。

### 1.2 `bite` 扑咬（0.35 / 0.2 / 0.6）

- **读感目标**：0.35 s 的短前摇靠**姿势 + 声音**读：伏低、炸毛（毛尖火花），扑出 2.2 m；单只很脆，读不出也只挨 6。不画地面预警（太短、太小，画了只会刷屏）。
- **节拍表**（总 1.15 s）：

| 节拍 | 秒 | 关键姿势 | 特效 |
|---|---|---|---|
| 起手 / 预警 | 0–0.35 | key：伏低（hips 下沉 0.12、前倾）、耳朵贴后、尾巴压低 | 毛尖 4 颗紫红火花（炸毛） |
| **释放帧** | 0.35（`hit`） | extreme：往前扑直（前爪前伸、后腿蹬直），smear 1 帧 | 嘴前三道小爪痕（月牙 0.8 m，0.12 s）；带电时一小道雷刃 |
| 持续段 | 0.35–0.55 | 落地 | 落点一小团尘 |
| 收招 | 0.55–1.15 | 坐起来抖毛 0.6 s（破绽） | — |

- **第一人称**：贴脸时爪痕在准星下方偏左右，0.12 s 就退，不挡准星。

### 1.3 `burrow` 钻洞（0.25 / 1.2 / 0.4）

- **读感目标**：半秒内挨两枪或被贴到 3 m（且血不到一半）就一头扎进洞，土包沿地面移到 6–10 m 外另一个洞口，钻出来探头 0.4 s 不动（窗口）。
- **节拍表**（总 1.85 s）：

| 节拍 | 秒 | 关键姿势 | 特效 |
|---|---|---|---|
| 起手 | 0–0.25 | 一头往下扎（hips +1.7 前翻）、前爪刨 | 洞口一圈方块土团往外崩（8 块）+ 尘团 |
| 入地（`hide`） | 0.25 | 消失（无敌、不可选中） | 土团再崩一下 |
| 持续段 | 0.25–1.45 | — | 地面土包移动：每 0.1 s 一小团灰褐尘 + 两三块土块，紫红火花偶尔从土里冒（它还带电） |
| 出洞（`emerge`） | 1.45 | 从洞口探头 | 洞口土团崩开（12 块）+ 尘环 |
| 收招 | 1.45–1.85 | 探头左右看（破绽） | — |

### 1.4 电网（被动）

- **读感目标**：3 只以上相距 4.5 m 内，两两连一道**贴地的紫红雷刃**（离地 0.45 m）；碰到每 0.4 s 4 伤害挂雷殛；打掉中间那只断网。网里的都带电（身上噼啪）——**一眼看出「这一窝能连环炸」**。
- **特效层次**：主形 = 每条边一道持续雷刃（每 0.07 s 重抖一次折线，亮度 0.7–1 随机闪；粗 0.05 m，芯白、身紫、底下暗衬），两端在獭身上溅 1–2 颗火花；断网时那条雷刃 0.08 s 内啪地缩回两端。
- **第一人称**：雷刃在膝盖高度，从远处看是一张贴地的紫网，不挡视线；跳过去（单跳 1.42 m）或冲刺穿过。

### 1.5 受击 / 死亡

- 受击：耳朵贴后、头一缩（Hit）；硬直是往后滚一圈（`stagger`）。
- 死亡：普通——翻肚子倒（布娃娃）；爆头——原地转半圈倒下（头骨额外一甩）；爆炸——被抛成一道弧；带电——电跳给同伴（网里死一只，电往两只邻居跳，下一个焚雷就连上了）。

## 2. 天狗（群怪·包抄）

- **设定母题**：《西山经》阴山「其状如狸而白首」，御凶；雷魅化后白首额心长出雷纹，仰头一吠，雷就跟着吠声落下来。
  形状：雷标 = **符印圆**（圈 + 四个往里的齿 + 中间三爻，跟着人走、定格后收紧）；落雷 = **天上到地上的一道粗雷刃**；扑咬 = **三道爪痕月牙**。
- 数值：血 80、移速 9.5、韧性 30、硬直 0.45 s；弱点额心雷纹 ×2。一群里同时只有 1 只雷吠、1 只扑。

### 2.1 `howl` 雷吠（1.2 / 0.6 / 0.6）

- **读感目标**：
  - **从哪来**：停下、坐低、仰头长吠，额心雷纹从暗到亮——在 12–30 m 外也认得出的剪影；
  - **打哪里**：玩家脚下一个跟着走的雷标（半径 2.6 m）；
  - **什么时候**：1.2 s 时雷标**定格**（齿往里一收、颜色压实），再过 0.6 s 落雷（判定 3 m、15 伤害）。这 0.6 s 就是「横移出圈」的窗口；
  - 打出硬直或封脉：雷标取消；站到导体旁 2–5 m：雷被引走。
- **节拍表**（总 2.4 s）：

| 节拍 | 秒 | 关键姿势 | 特效 |
|---|---|---|---|
| 起手 | 0–0.3 | key：急停、屁股往下坐（后腿屈） | 雷标在玩家脚下浮现（符印圈从 0 长到 2.6 m，0.25 s）+ 危险填充开始 |
| 预警 | 0.3–1.2 | extreme：仰头到顶（脖子 −0.7、头 −0.5）、嘴张开，耳朵立起 | 额心雷纹从 0 涨到 1；雷标跟着玩家走（每帧挪，符印慢转），危险填充随前摇填 |
| 定格（`lock`） | 1.2 | 长吠：头颤（30 Hz） | 雷标定格：四齿往里一收、外圈加一圈细环；天上（落点正上方 12 m）开始聚一团紫光；危险填充改为 0.6 s 的「落雷」倒计时 |
| **释放帧** | 1.8（`strike`） | 吠声收尾、头往下点一下 | 落雷（主形：天上到地的粗雷刃 0.18 s，芯白第一帧峰值 + 两道分叉）+ 贴地冲击环 3 m + 一圈方块土块 + 焦痕贴花（3 s）；震屏 0.25（按距离）；3 m 内的天狗衔雷 |
| 收招 | 1.8–2.4 | 坐着不动（破绽：雷吠的那只站着 1.8 s） | 焦痕慢慢淡 |

- **特效层次**：主形 = 雷标符印（一张平铺网格：外圈 + 4 齿 + 三爻，紫红，离地 0.06 m，跟随时慢转 40°/s，定格后不转）+ 落雷雷刃；次级 = 危险填充（Telegraph 圆，赤红）、冲击环、焦痕、空中聚光；点缀 = 土块 8 颗、电火花 10 颗。
- **动作配合**：坐低（squash）→ 仰头（stretch 往上）→ 吠声顶点颤 → 释放帧往下点头（雷「被吠下来」）。耳朵、尾巴是滞后的 overlapping action。

### 2.3 衔雷（被动）

- 3 m 内落雷（自己的雷吠、雷暴、夔）：毛上闪电、带电 8 s。表现：一道从落点到它身上的短雷刃（0.15 s）+ 身上噼啪 + 边缘光。

## 3. 獓狠（坦克）+ 雷牦

- **设定母题**：《西山经》三危山「白身四角，其豪如披蓑」——巨型白牦，长毛像蓑衣；雷魅化后四角之间攒出一颗雷球，每踩踏一次攒一份电。
  形状：踩踏 = **直线 + 方块土块**（攻城锤）；四角挑 = **扇形月牙**；雷球 = **球**（越攒越亮、越大）；砸地 = **粗冲击环**（贴地、带一圈紫红雷刃）；蓑毛燃烧 = 卡通火舌，烧光后露出发光的**雷筋**（紫红折线纹）。
- 数值：獓狠 血 900、走 3.5 / 踩踏 13 m/s、韧性 220、不吃击退；弱点雷球 ×2.5（正面）、烧出来的雷筋 ×1.25；蓑毛 6 片（胸、背、臀、左右肩、左右后腿），没烧的只吃 20%，火落在那片上 1.5 s 烧光。
  雷牦 血 260、复用獓狠模型 ×0.72，没有雷球和蓑毛，毛色暗一些（覆盖色）。

### 3.4 蓑毛燃烧（被动）

### 3.5 雷牦（跟着踩踏）

- 獓狠刨地时，同一处遇敌里空着的雷牦在两侧平行排开（±4 m、±8 m），同一朝向、各自出线，一起冲；没有獓狠带队就自己冲。四角挑同獓狠（伤害 11），没有砸地。

- 受击：子弹只让毛抖一下（CreatureRig 小抖，振幅按伤害占比很小）；爆炸才晃。眩晕：前腿跪下、头垂到地上（stun）。

## 4. 举父（远程·炮击）

- **设定母题**：《西山经》崇吾山「其状如禺而文臂，豹虎而善投」——会投掷的猿；雷暴时手里的石头是雷石。
  形状：**方块**（石头、碎石）、**抛物线**（投掷轨迹）、落点**圈**；雷石落地留一个**符印电场**。
- 数值：血 240、移速 5（指节着地跑）、韧性 60；弱点：举石时手里的石头（打到就炸）、胸口掌印 ×2。

### 4.1 `climb` 抢高（0.5 / 1.0 / 0.5）

- 开战先跑向 25 m 内最近的高处一跃而上：蹲（0.5 s）→ 空中收腿举手（1.0 s，根节点抛物线 3 m 高）→ 四肢着地（`land` 1.5 s：落点尘团 + 土块）。跑的路上最好打。

### 4.2 `throw` 远投（1.0 / 0.1 / 0.8）——招牌，手 K（举石 / 投石）

- **读感目标**：
  - **从哪来**：弯腰抠起石头、双手举过头顶（全章最好认的投掷剪影，屋顶上也看得见）；
  - **打哪里**：落点 3 m 圈出现在「玩家正要去的地方」（预判 0.8 × 速度 × (前摇 + 飞行)），危险填充，填满 = 落地；
  - **什么时候**：1.0 s 出手，飞行 1.0–1.4 s；
  - **反制**：举石的 1 s 里石头是命中球，打中 40 → 石头在它手里炸开，自伤 60 + 眩晕 2 s（带电时是焚雷）；站在屋顶上被眩晕会摔下来。

| 节拍 | 秒 | 关键姿势（手 K） | 特效 |
|---|---|---|---|
| 起手 | 0–0.3 | key：弯腰、双手往下抠（hips 前倾、膝屈） | 落点预警（填 前摇 + 飞行）；手里石头出现（方块低多边形石，雷暴时带紫红裂纹） |
| 举石 | 0.3–0.7 | breakdown：直起来，石头沿身前往上举 | 雷石：裂纹一明一暗、往外溅细电火花 |
| 蓄力顶点 | 0.7–1.0 | extreme：石头举过头顶、整个身子往后弓（反向预备最狠），掌印亮 | 石头颤（30 Hz）；掌印发光 |

### 4.3 `shove` 推开（0.45 / 0.2 / 0.6）

- 被逼到 5 m 内：双臂张开（扇形预警 120° 5 m）→ 横扫（`hit` 0.45 s：12 + 击退 9；手臂扫过的弧一道灰褐月牙 + 尘）→ 推完跳去另一处高地。

### 4.4 `fall` 摔下高处（0 / 0.8 / 1.5）

- 站在屋顶 / 高处边上被打出硬直或眩晕：摔下去（四肢乱挥，`land` 0.8 s：落地尘 + 自伤 30 + 眩晕 1.5 s）。

### 4.5 受击 / 死亡

- 受击往后一仰；硬直踉跄退一步（在屋顶边会掉下去）。死亡：捂胸、往后倒；在高处的滑下来摔到地上（布娃娃）。

## 5. 蛮蛮（远程·扫线）

- **设定母题**：《西山经》崇吾山「其状如凫，而一翼一目，相得乃飞」——比翼鸟。雷魅化后，两只之间连的是一道电弧：电弧在，才飞得起来。
  形状：**两点之间的雷刃**（比翼电弧）+ **流线**（低空掠过的扫线、羽毛）。一对里左翼一只、右翼一只（右翼那只是同一模型 X 镜像）。
- 数值：每只血 70、飞行 9 m/s、韧性 25；弱点独眼 ×2.5。成对时一直带电，火打一只 = 焚雷，雷弧必定跳到另一只。

| 持续段 | 0.8–2.0 | 平飞掠过（离地 1 m），翅膀小幅扇 | 电弧每 0.05 s 重抖；扫过的地面留一串紫红火花（0.4 s 消）；碰到人 10 + 雷殛 + 击退 |
| 收招 | 2.0–3.0 | 慢慢爬升，大扇翅膀 | 掉几片羽毛 |

- **特效层次**：主形 = 比翼电弧（雷刃，两端连两只的胸口）；次级 = 走廊危险带、中线身份线、扫过的尘带；点缀 = 火花、羽毛。
- **动作配合**：两只的关键姿势同帧（成对），镜像；预警段的「翅膀高举」是全章最大的翼展剪影。
- **第一人称**：电弧在膝盖到腰之间、横跨视野，从远处扫来时是一条越来越近的亮线——跳起来那一下电弧从脚下过去，看得见。

### 5.2 `bolt` 电弹（0.4 / 0.1 / 0.3）

- 张嘴、独眼一亮 → 一颗慢速电弹（24 m/s、7 伤害）：主形 = 小球（白芯、紫身，0.35 m）+ 拖一道短雷刃尾；打中地面 / 人一团小闪。

### 5.3 比翼坠落（被动）

- 打死一只：电弧啪地断开（两段雷刃各往自己那只缩回，0.12 s）+ 断口一团白闪；另一只飞不起来，落到地上一蹦一蹦追着啄（`hop` 循环，4 m/s、6 伤害），落地的那只吃 ×1.5。

### 5.4 受击 / 死亡

- 受击：掉一蓬羽毛（4–6 片，灰白 / 墨褐，慢慢飘）、在空中晃一下；硬直是空中翻一圈、电弧闪烁。
- 死亡：空中被打死——打着旋掉下来（布娃娃 + 角速度），砸在地上羽毛炸开（16 片）。

## 6. 连鼓灵（辅助）

- **设定母题**：夔鼓的碎片——六面小鼓绕一颗雷心转，一根雷兽骨槌依次敲鼓，「其声如雷」。
  形状：**环**（鼓环、鼓面一闪的环）+ 鼓到同伴的**雷刃**；碎鼓是**方块木片和鼓皮**；雷心是**球**。
- 组装：`SM_EnemyPart_LianguCore`（雷心）+ 6 × `SM_EnemyPart_LianguDrum`（半径 1.15 m 一圈，第 0 面是红鼓）+ `SM_EnemyPart_LianguMallet`（骨槌，握柄在雷心上方，锤头朝外斜下）。悬浮离地 3 m、移速 4。
- 数值：六面鼓各 45（命中球在每面鼓上），雷心 220；3 面以上鼓在时雷心只吃 25%，少于 3 面吃 100%，鼓全碎后雷心落地吃 200%。雷心一直带电。

### 6.1 `beat` 鼓点（循环，0.25 / 0.1 / 0.85）——招牌，手 K（骨槌击鼓）

- **读感目标**：每 1.2 s 敲一面，鼓面一闪、一道电弧连到受益的同伴：普通鼓给 15 m 内一个同伴加一层静电护盾（最多 3 层，每层挡一次伤害），红鼓给 15 m 内同伴移速 / 出手速度 +40% 6 s。**一眼看出「是它在给别人加东西」——先打它**。
- **节拍表**（一拍 1.2 s）：

| 节拍 | 秒 | 关键姿势（手 K 骨槌曲线） | 特效 |
|---|---|---|---|
| 起手 | 0–0.15 | key：骨槌往后上方抬（反向预备），鼓环转到要敲的那面 | — |
| 蓄力顶点 | 0.15–0.25 | extreme：骨槌举到最高、锤头往后翘 | 那面鼓的鼓面亮一档 |
| **释放帧** | 0.25（`beat`） | 骨槌砸下（smear 1 帧），整个鼓环被砸得一沉（0.08 m） | 鼓面一闪（平面环从鼓心扩到鼓沿，紫白 / 红鼓珊瑚红）+ 一道雷刃连到受益的同伴（0.25 s）；同伴身上一层淡紫护盾壳（ShieldBubble）或珊瑚红的加速光环 |
| 收招 | 0.35–1.2 | 骨槌弹回（过冲一次）、鼓环回弹 | 鼓面余震（缩放 1.06 → 1） |

- **第一人称**：中距离（8–15 m，它在同伴后面）：每 1.2 s 一闪 + 一道连到同伴的电弧——电弧的起点就是它，顺着电弧找到它。

### 6.2 `clap` 惊雷（0.8 / 0.2 / 1.0）

- 被逼到 5 m 内：六面鼓全亮、鼓环转得飞快（前摇 0.8 s，危险圆 7 m）→ 7 m 冲击波推开、10 伤害（`hit` 0.8 s：贴地粗冲击环 + 六面鼓同时闪 + 雷心白闪；鼓环放大 1.25 一下；顿帧 0.04 s；震屏 0.25）→ 鼓环晃 1 s。

### 6.3 `orb` 雷心弹（0.4 / 0.1 / 1.3）与雷心落地

- 同伴死光或鼓全碎：自己出来，保持 12 m 打雷心弹（16 m/s、8 伤害；白芯紫身的球 0.4 m）。
- 六面鼓全碎：雷心掉到地上滚（核心发光 ×1.6），隔 1.8 s 打一发雷心弹；雷心 ×2、带电 → 火一碰焚雷。

### 6.4 碎鼓 / 死亡

- 每碎一面：那面鼓爆开（方块木片 + 鼓皮碎片 18 颗 + 一团闪；红鼓是珊瑚红闪）、隐藏；少一份护盾，红鼓碎了不再加速。
- 受击：被打的那面鼓凹一下（缩放 0.9 → 1）、震纹（平面环）；硬直时整个鼓环倾斜。
- 死亡：雷心裂开一道白光（竖直的光柱 0.2 s）+ 一团紫白爆闪，剩下的鼓和骨槌掉到地上（刚体，叮叮当当弹两下），3 s 后沉下去。

## 7. 帝江（近战·自爆）

- **设定母题**：《西山经》天山「其状如黄囊，赤如丹火，六足四翼，浑敦无面目，是识歌舞」——会跳舞的无面红皮囊。
  形状：歌舞的**鼓点圈**（每蹦一下落地一小圈）、胀大的**球**、炸开的**球状闪电**（球壳 + 放射雷刃）。
- 数值：血 50、移速 8、不硬直（太轻，被打退半步）；弱点四翼根部最亮处 ×2。两到四只一群。

### 7.1 `dance` 歌舞（移动）

- 一边转圈一边蹦着过来：15 m 外每 0.5 s 一蹦、8–15 m 每 0.33 s、8 m 内每 0.25 s——**鼓点越来越快**（声音第二期接，这里先用落地的小圈当节拍：每次落地一圈 1 m 的尘环 + 两颗紫红火花，频率就是鼓点）。前面有 1.2 m 以下的矮掩体或河：一大跳跃过去（2.2 m 高）。

### 7.2 `swell` 球雷（0.8 / 0.1 / —）

- **读感目标**：贴到 2.5 m：原地转圈、胀大 1.5 倍、白闪越来越快（0.8 s）→ 炸成 4 m 球状闪电（22 + 击退，自己死）。胀大时带电：火一碰在原地焚雷（炸的是它的同伴）。
- **节拍表**（总 0.9 s）：

| 节拍 | 秒 | 关键姿势 | 特效 |
|---|---|---|---|
| 起手 / 预警 | 0–0.55 | 原地转圈加速（6 → 20 rad/s），皮囊胀大（body 骨 ×1 → ×1.5），六足乱蹬、四翼张开 | 危险圆 4 m（0.8 s 填满）；白闪越来越快（10 → 40 Hz） |
| 白星 | 0.55（`glint`） | 胀到 ×1.4 | 白星 |
| **释放帧** | 0.8（`hit`） | 胀到最大、炸 | 主形：球状闪电（一个 4 m 的紫红球壳 0.25 s 从 0.5 扩到 4 m + 12 道放射雷刃）+ 中心白闪 + 冲击环；红皮碎片 + 紫红火花 40；震屏 0.3 |

### 7.3 爆囊（被打死）与连锁

- 被玩家打死时炸 4 m：对敌人 40、对 2.5 m 内的玩家 10；6 m 内的帝江 0.15 s 后一个接一个引爆（每一只都是同样的球状闪电，小一号 0.8）——在一群中间打爆一只能清一片。被火打死的是一团紫红火球（球壳换成火 + 紫红两层）。

## 8. 穷奇（游猎·精英）

- **设定母题**：《海内北经》「其状如虎，有翼」、《西山经》「猬毛」，四凶之一。雷魅化后背上的猬毛成了雷冠，会主动去接雷。
  形状：**影子**（滑翔时地上越来越大、越来越黑的影子）、**月牙**（翼刃、扑杀的爪风）、**竖直雷刃**（吞雷）。
  精英：走 `EliteStrike`（squash / stretch、局部顿帧、金光）+ 三章通用的金色点缀（`Fx.EliteCue / EliteRelease / EliteSlam`），再叠第四章自己的紫红点缀（金 = 精英，紫红 = 第四章雷魅）。
- 数值：血 1100、潜行 5.5 / 扑击 14、韧性 150、硬直 0.7 s；弱点背上猬毛雷冠 ×2.5、头 ×1.6、翼根 ×2（只在滑翔和旋斩时露出来）。每张图一只。
  Unity 里名册直接定为精英级（`rank = Elite`，金环 + 词缀），生命不再乘精英倍率（见第 10 节）。

### 8.1 `patrol` 游猎 / `ridge` 上脊

- 沿路线巡视（`PlateauRoute` 路点，M1 路给），雷暴时主动来找 70 m 内的玩家（领主战里不来搅局）；发现玩家先跑上 25 m 内最近、比现在高 4 m 以上的地方。

### 8.2 `glide` 掠空扑杀（0.7 / ≤1.6 / 0.8）——招牌，手 K（滑翔展翼 + 落地扑杀）

- **读感目标**：
  - **从哪来**：伏低、张翼、雷冠亮（0.7 s）；起飞后地上出现它的影子；
  - **打哪里**：落点 3.5 m 圈（危险填充，填 前摇 + 飞行），影子越接近落点越大越黑；
  - **什么时候**：影子和落点圈重合 = 落地扑杀（22，吞雷后 + 雷殛）；
  - **反制**：滑翔中打翼根 120 → 坠地眩晕 2 s。
- **节拍表**（总 2.3–3.1 s）：

| 节拍 | 秒 | 关键姿势（手 K） | 特效 |
|---|---|---|---|
| 起手 | 0–0.2 | key：前半身压低、双翼半张（反向预备：先往后缩） | 落点预警；起手金芒（精英） |
| 蓄力顶点 | 0.2–0.7（`glint` 0.45） | extreme：伏到最低、双翼全张往上举、雷冠亮到发白 | 白星（雷冠）；金光泛起；翼骨上细电火花 |
| **释放帧**（起飞） | 0.7（`hit`） | 后腿一蹬、双翼往下一扇（stretch），smear | 起飞处一圈尘环 + 草屑往外压（翼风）；金色爆闪（EliteRelease）；顿帧 0.05 s（EliteStrike） |
| 持续段（滑翔） | 0.7–≤2.3 | 双翼全展滑翔、前爪往前探、后腿收（翼根露出：命中区开） | 地上影子（暗紫褐椭圆，越接近落点越大越黑）；翼尖两道流线气流尾（白，0.3 s）；吞雷后拖一道紫红雷刃尾 |
| **落地扑杀**（`land`） | ≤2.3 | key：双前爪砸地、肩膀压下去、双翼往前一包（squash） | 主形：落点两道交叉的爪风月牙（3.5 m，紫红暗衬 + 白芯）+ 贴地冲击环 3.5 m + 金环（EliteSlam）+ 土块尘团；吞雷后多一圈 12 道放射雷刃；震屏 0.3 |
| 收招 | 落地后 0.8 | 低头 0.8 s（破绽）；双翼慢慢收拢（follow-through） | — |

- **坠地**：翼根被打穿：直直掉下去（14 m/s），落地一团尘 + 眩晕 2 s（翻倒在地、翅膀摊开扑腾）。
- **第一人称**：它从高处来，玩家先看到的是**地上的影子和落点圈**（这两样都在视线下方），抬头才看到展翼的剪影；落地爪风在准星前 0.15 s 就退。

### 8.3 `spin` 翼刃雷旋（0.5 / 0.4 / 0.8）

- 双翼一展、翼骨上电弧噼啪（0.5 s，危险圆 4 m）→ 原地旋斩一圈（`hit` 0.5 s：两道翼刃月牙 360° 0.25 s，紫红暗衬 + 白刃 + 金丝点缀；16 + 击退）→ 转完头晕似的晃 0.8 s。旋斩时翼根露出。

### 8.4 `claw` 爪击（0.35 / 0.5 / 0.6）

- 抬一只前爪（0.35 s）→ 两下（`hit1` 0.45、`hit2` 0.7 s，3 m 扇形，各 10）：每一下一道三爪月牙（1.6 m，0.12 s），第二下精英金丝。

### 8.5 `absorb` 吞雷（0.8 / 0.6 / 0.4）

- 12 m 内落雷：跑过去人立接雷，雷冠越来越亮（0.8 s）→ `eat`：一道从天上劈进雷冠的竖直雷刃（0.3 s）+ 雷冠一圈紫白闪 + 身上噼啪 → 带电 15 s，下一次扑杀带雷殛 + 拖出一道雷。
- **反制**：接雷时打雷冠 80 → 雷冠过载（一团爆闪），眩晕 1.5 s。

### 8.6 `flee` 撤退

- 血 < 30%：长啸一声展翼飞走（`flee` 循环），飞回巢穴回血（只一次）；可以追，在巢里的它没法滑翔。

### 8.7 受击 / 死亡

- 精英：只有弱点被打才缩一下；硬直时整只往后一坐。
- 死亡：滑翔中被打死——一头栽下来、在地上翻滚（布娃娃继承速度）；站着被打死——侧倒、双翼摊开，雷冠的电噼啪 1 s 后熄灭。
