# 第一章精英 · 出手动作与特效设计单（VFX 调优 H 路，2026-10-31）

本单的目标：第一章最常以精英出现的三种敌人，作为精英出手时**读起来更有分量**——起手更夸张、释放帧更狠，带精英专属的金色点缀，**招式的数值和时机一律不变**（前摇时长、伤害、范围、弹数、冷却都照旧）。
词缀的颜色和金环由 Q 路负责（`Fx.Elite.cs`、`EliteAura`），本单只管这三种敌人「精英版的出手」。

- 代码：
  - 姿态层 / 顿帧 / 金光：`unity/Assets/Game/Scripts/Enemies/EliteStrike.cs`；
  - 特效入口：`Fx/Fx.EliteCh1.cs`；
  - 接入：`Enemies/ScorpionArcherAI.cs`、`TombBeastAI.cs`、`MirageToadAI.cs`（只在 `elite` 时生效）。
- 对比拼图：[review/boss-vfx/H/](../review/boss-vfx/H/) 的 `elite1-*.jpg`，由 `bridge.sh playtest beats-elite1` 拍、`scripts/unity/beat_strips.py` 拼。

## 1. 哪三种最常以精英出现

统计口径：1-1 / 1-2 / 1-3 三张大图的遭遇编排（`Pipeline/Editor/Levels/Level_1_*.cs`）。

- **显式精英**：`E(…).Elite()`；
- **升格**：`EncounterSpec.Elites(n)`，按 `EncounterSpec.Promote` 的规则算期望——
  - 第 k 只落在倒数第 (k mod 2) + 1 波；
  - 候选是这一波里的非精英普通单位；
  - 按耐久加权抽：生命 + 护甲 + 护盾，冲锋型再 ×1.5。

1-4 是首领场，旱魃召出的沙魇、邪飞天都不是精英。

| 敌人 | 显式精英 | 升格的期望 | 合计（每局） |
|---|---|---|---|
| **蝎尾弩卫** scorpion_archer | 3：1-1「沙暴前锋」、1-2「供养窟守军」（迅捷）、1-3「沙王卫队」 | 1-2「守门小队」0.34 + 1-3「集市乱战」0.64 | **3.98** |
| **三彩镇墓兽** tomb_beast | 3：1-1「风沙压境」、1-2「塔前混编」（坚盾）、1-3「沙王卫队」 | 0 | **3.00** |
| **蜃楼蟾** mirage_toad | 0 | 1-2「守门小队」0.47 | **0.47** |
| 跳鼠刀兵 | 0 | 0.12 + 0.22 | 0.34 |
| 火浣鼠 | 0 | 0.07 + 0.14 | 0.21 |
| 沙魇、邪飞天 | 0 | 0 | 0 |

取前三：**蝎尾弩卫、三彩镇墓兽、蜃楼蟾**。

## 2. 通用做法

- **姿态层**（`EliteStrike`）：
  - 在动画之后，往模型节点（Animator 所在的子物体，原点在脚底）上叠 squash / stretch 和前后倾，幅度在 15% / 15° 以内，脚底不离地；
  - 蓄力：`Charge(t, 压扁量, 倾角)`，越到顶点压得越狠；
  - 释放帧：`Release(…)`，一下打到拉长 / 前冲，目标回到 0，靠欠阻尼弹簧（7.5 Hz、阻尼比 0.38）回弹，自带一次过冲，这就是 follow-through；
  - 连射的每一发再 `Kick` 一下；
  - 模型就是根节点时不叠姿态。
- **局部顿帧**：释放帧只把它自己的 Animator 压到 ×0.05、停 0.05–0.07 s，再以 ×1.6 追回。全局时间不动：敌人出招时不能顿住玩家的手感。
- **金光**：
  - `EnemyBody` 的覆盖色通道 `eliteStrike`：蓄力时淡淡泛金（0.12 → 0.42 × 0.42），释放帧一闪到满，0.3 s 内退掉；
  - 精英 = 金，见 fx-style §2.1 圣 / 金：亮芯暖白 `#fff3d0`、主色金 `#ffc233`、暗边赭金 `#a8742a`；
  - 不改招式本身的元素色：火珠还是火，沙还是暖砂。
- **节奏**（特效）：
  1. 起手一颗金芒「叮」（`EliteCue`：四芒星 + 柔光，告诉玩家「精英要出重手了」）；
  2. 蓄力时金点往出手的部位收（`EliteCharge`）；
  3. 释放帧：金色爆闪星 + 「啪」环 + 顺着出手方向喷的一束金丝 + 金色闪光灯（`EliteRelease`）；
  4. 重击落地：多一圈贴地金环、崩起的石块（方块）、往上溅的金丝（`EliteSlam`），震屏加重一点。
- **预算**：每层过 `FxBudget`。亮芯（爆闪、环）是 essential，金点、金丝按画质密度缩。
- **预警**：一律照旧，配色沿用 TelegraphTone，时长不变。精英版只多一个起手金芒（声音还是原来的 telegraph）。

## 3. 蝎尾弩卫 · 精英齐射

- **设定母题**：沙寺的弩卫，蝎尾上架着重弩。精英一次上五支弦，扇形齐射。形状：五道直线（切割、方向），扇形（范围）。
- **读感目标**（上弦 0.6 s）：
  - **从哪来**：弩口。起手金芒，上弦最后 0.15 s 弩尖金光一闪（原有）；
  - **打哪里**：后半段弩口沿五支的扇形甩出金色弦光，相邻两支夹角 0.09 rad，和出手一致，读得出五支扇形；
  - **什么时候**：金光一闪、弦光最密，就是第一发。

| 节拍 | 时刻 | 动作（姿态层叠在 aim / fire 片段上） | 特效 |
|---|---|---|---|
| 起手 | 0 s | 压低、后仰开始拉弦 | 弩口金芒；上弦音（原有） |
| 预警 | 0.27–0.6 s | 压低 8%、后仰 9°（越到顶点越狠） | 五道金色弦光沿扇形往外甩（每秒 20 → 60 道）；身上泛金 |
| 蓄力顶点 | 0.45–0.6 s | 同上（顶点） | 弩尖金光一闪（原有） |
| **释放帧** | 0.6 s | 一下拉长 10%、前冲 7°；顿帧 0.05 s | 弩口金色爆闪 + 「啪」环 + 顺着弩矢方向的金丝；身上金光闪满；第一支弩矢 |
| 持续段 | 0.6–1.24 s | 每一发后坐踢一下（后仰 3°、拉长 3%） | 每一发弩口金星；金色弩矢（原有） |
| 收招 | 1.24–1.64 s | 弹簧回弹、过冲后回正 | 金光退掉 |

- **钳击**（1.8 m 内，精英版同样处理）：
  - 前摇压低 10%、后仰 10°，起手金芒在钳子上；
  - 释放帧拉长前冲 11°，加顿帧，钳前金色爆闪。
- **第一人称**：五道弦光是细亮线，从弩口往玩家这边甩，准星中央只有很短的一截，不挡准星。中远距离（12–22 m）看得出扇形的张开。

## 4. 三彩镇墓兽 · 精英冲锋 / 踏地

- **设定母题**：墓门前的三彩陶兽。冲锋像攻城锤，踏地是人立而起再砸下。形状：冲锋是直线加三角的角，踏地是一圈一圈的环，再加崩起的方块陶石。

**冲锋**（刨地蓄力 1.0 s，精英一次冲两趟）：

| 节拍 | 时刻 | 动作 | 特效 |
|---|---|---|---|
| 起手 | 0 s | 长吼（原有）；压低、低头顶角 | 角上金芒 |
| 预警 | 0–0.6 s | 压低到 12%、前倾 7°（顶角）；前 60% 还在瞄（原有） | 冲锋线预警（原有，红）；金点往角上收（每秒 8 → 30） |
| 蓄力顶点 | 0.6–1.0 s | 刨地（原有，每 0.3 s 扬沙轻震） | 金点最密；身上泛金 |
| **释放帧** | 1.0 s | 一下拉长 12%、前冲 9°；顿帧 0.06 s | 角前金色爆闪 + 「啪」环 + 一束往前喷的金丝；加重震屏 0.25（叠在原来的 0.3 上） |
| 持续段 | ≤ 1.33 s | 15 m/s 直冲 | 蹄下往后甩的金屑（每秒 36）+ 日火裂痕（原有） |
| 收招 | 刹车 0.9 s | 往后一坐、后仰 9°（惯性过冲），再回正 | 犁起的沙（原有） |
| 撞墙 | — | 整只压扁 15%、往后弹 10° | 碎陶、日火柱（原有）；金光闪满 |

**踏地**（蓄力 0.7 s）：

| 节拍 | 时刻 | 动作 | 特效 |
|---|---|---|---|
| 起手 | 0 s | 人立而起：后仰、拉高 | 前爪上金芒 |
| 预警 | 0–0.7 s | 后仰到 13°、拉高 8% | 9 m 圈预警（原有）；金点往前爪收 |
| **释放帧** | 0.7 s | 砸下：压扁 14%、前冲 10°；顿帧 0.07 s | 原有的砸地（尘、碎陶、火柱、焦痕、火环、冲击波）加一圈贴地金环、金色爆闪、8 块崩起的石块、往上溅的金丝；加重震屏 0.35 |
| 收招 | 0.2–0.55 s | 弹簧回弹 | 金光退掉 |

- **第一人称**：
  - 冲锋的金芒和金点在兽头上，正好是玩家该看的地方（正面格挡、绕背）；
  - 踏地的金环贴地，和红色预警圈、冲击波环带分得开：金色、更细、先扩。

## 5. 蜃楼蟾 · 精英连吐

- **设定母题**：驮着半座佛塔的巨蟾，喉囊里攒火，抛出蜃火珠；精英连吐两颗。形状：圆（喉囊、火珠、落点环）。
- **读感目标**（鼓囊 1.0 s）：
  - **从哪来**：喉囊鼓起（原有，×1.32），起手金芒；
  - **打哪里**：落点金色预警圈（原有，每颗一个）；
  - **什么时候**：整只蹲到最低、金点收满，就是第一颗。

| 节拍 | 时刻 | 动作 | 特效 |
|---|---|---|---|
| 起手 | 0 s | 往下蹲、后仰吸气；喉囊开始鼓（原有） | 嘴前金芒 |
| 预警 | 0.3–1.0 s | 蹲低 12%、后仰 7° | 金点往喉囊收；喉囊冒火星（原有） |
| **释放帧** | 1.0 s | 一下拉长 12%、前探 8°；顿帧 0.05 s；喉囊一缩（原有） | 嘴前金色爆闪 + 「啪」环 + 顺着抛射方向的金丝 |
| 持续段 | 1.32 s | 第二颗：再踢一下（拉长 6%、前探 5°） | 小一号的嘴前爆闪 |
| 命中 | 落地 | — | 原有的爆炸、火环、余火、焦痕，加一圈金环、崩起的石块、金丝；震屏加 0.3 |
| 收招 | 0.7 s | 弹簧回弹 | 金光退掉 |

分身（幻影）没有这一层：真身才有金色，这本身也是分辨真假的线索。

## 6. 验收

- **数值不变**：
  - `EliteStrike` 只写模型节点的缩放、旋转，以及覆盖色和 Animator.speed；
  - AI 的状态机时长、伤害、弹数一行没动；
  - 精英的「两趟冲锋 / 五支扇形 / 两颗火珠」本来就有。
- **套件**：`desert`（第一章敌人冒烟）、`fx`、`fx-style`、`telegraph-look`。
- **对比拼图**：`elite1-scorpion_volley.jpg`、`elite1-tomb_charge.jpg`、`elite1-tomb_stomp.jpg`、`elite1-toad_spit.jpg`。
