# 第二章精英 · 出手动作与特效设计单（VFX 调优 K 路，2026-10-31）

第二章（霜山）精英的出手调优：**招式数值和时机一律不变**（前摇时长、伤害、范围、判定、冷却都照旧，精英原有的 ×1.15 / ×1.2 / ×1.25 也不动），
只让「同一招由精英打出来」时起手更夸张、释放帧更狠，并带精英的金色点缀。

- **分量层**：复用 H 路的 `EliteStrike`（`Enemies/EliteStrike.cs`，三章精英共用）：前摇里压低 / 后仰 / 前倾（`Charge`），释放帧拉长或压扁 + 前冲 / 后顶 + 只顿它自己的 Animator（`Release`），
  弹簧回弹带过冲（follow-through），金光覆盖色。
- **点缀**：H 路的通用金色点缀（`Fx.EliteCue` 起手金芒、`Fx.EliteCharge` 蓄力金点、`Fx.EliteRelease` 释放帧爆闪 + 「啪」环 + 金丝、`Fx.EliteTrail` 金屑），
  再叠第二章自己的 `Fx/Fx.EliteCh2.cs`：
  - 配色按第二章冷色调：主形还是冰（亮芯 `#f0fbff` / 冰蓝 `#7fd8ff`），金 `#ffc233` 只做**外圈描边**和亮芯里的一线——读作「同一招、更重」，不改元素语义；
  - 形状：冰的**块面**（崩起的冰块）+ 金的**圆环**（精英印）；钳击是一对合拢的月牙（尖角 = 切割）；
  - 预警照旧走 TelegraphTone（第二章的电光蓝预警不动）。
- **节拍条**：`bridge.sh playtest beats-frost-elite`（`Testing/Suites/FrostEliteBeatsSuite.cs`），测试场里逐种刷一只精英，按起手 / 预警 / 释放帧 / 收招 / 第一人称拍；

## 0. 选哪三种：遭遇数据统计

统计 `Level_2_1/2/3.cs` 的遭遇编排（`EncounterSpec`，2-4 是首领关、没有精英）：

| 来源 | 2-1 | 2-2 | 2-3 | 每局期望 |
|---|---|---|---|---|
| 写死的精英小队 `.Elite(...)` | 玄冰巨蟹（坚盾）、夫诸（迅捷） | 冰甲旋龟（坚盾）、夫诸（迅捷） | 冰甲旋龟（坚盾）、夫诸（迅捷） | 夫诸 3、旋龟 2、巨蟹 1 |
| 升格 `.Elites(1, "frenzied")`（最后一波按耐久加权抽一只） | 冰河豚群：夫诸 52% / 豪彘 30% / 河豚 19% | 兽庭合围：狐巫 41% / 青鸟 25% / 狌狌 17% / 豪彘 17% | 灯塔下：水母 42% / 青鸟 30% / 鲛人 15% / 河豚 13% | 夫诸 +0.52、其余都 < 0.6 |

（权重 = `EncounterSpec.Heft`：生命 + 护甲 + 护盾，冲锋型 ×1.5；按条目抽，不按只数。）

**最常以精英出现的三种：夫诸（约 3.5 只 / 局）、冰甲旋龟（2）、玄冰巨蟹（1）**。之后是三青鸟 0.55、豪彘 0.47、水母 0.42、狐巫 0.41，都不到一只。

## 1. 夫诸 · 冰光（`FuzhuAI`，精英约 3.5 只 / 局）

- **设定母题**：冻成冰的四角白鹿，角间聚一团冰光射出去。精英的这一下是「神鹿发怒」：角间的光更满、射出去时整只被反冲顶一下。主形是**角间的光团 → 一条直线光束**。
- **读感目标**（前摇 1.2 s，不变）：从哪来 = 角间光团；打哪里 = 地面瞄准线（前 70% 跟着玩家、之后锁定）；什么时候 = 光团最亮、瞄准线填满。精英多一个读点：蓄力时整只压低前倾、金点往角间收。

| 节拍 | 时刻 | 动作 | 特效（精英多出来的） |
|---|---|---|---|
| 起手 | 0 s | 前蹄一跺（原有） | **起手金芒**（角间四芒星 + 柔光）+ 蹄下**精英印**（金环套冰环，贴地） |
| 预警 / 蓄力 | 0–1.2 s | `Charge(t, 压低 12%, 前倾 9°)`：越蓄越低、头越压越低 | 金点往角间收（每秒 8 → 30 颗 × 密度）；原有冰晶星、冰屑照旧 |
| **释放帧** | 1.2 s | `Release(拉长 10%, 后顶 −9°, 顿帧 0.06 s)`：被冰光往后一顶 | 金色爆闪 + 「啪」环 + 顺光束的金丝；冰光里再穿**一线金芯**（细光束 0.3 s）+ 终点金星；离玩家近（18 m 内）轻震屏 0.25 |
| 收招 | +0.7 s | 弹簧回弹带过冲，收招结束 `Relax` | 沿光束几颗金点慢慢飘（余韵） |

- **层次**：主形 = 冰光（原有，精英 ×1.25 宽）+ 金芯；次级 = 起手金芒、精英印、金点；点缀 = 金丝、余韵金点。
- **第一人称**：中远距离（13–24 m，它的常驻距离）读得出「角间更亮、金点往里收」，释放帧金芯在冰白光束里是一条细亮线，不糊准星。

## 2. 冰甲旋龟 · 缩壳旋转 / 冰喙猛啄（`XuanGuiAI`，精英 2 只 / 局）

- **设定母题**：负冰甲的玄龟，缩壳化作锯片贴地滑行。精英的旋转是「更重的一颗磨盘」：起转那一下砸得出一圈冰刺、旋转中甩金屑。主形是**脚下一圈（壳的大小）→ 一道滑行的直线**。

| 节拍 | 时刻 | 动作 | 特效（精英多出来的） |
|---|---|---|---|
| 起手 | 缩壳开始 | 原有 retract 片段 | 起手金芒（壳心）+ 精英印 |
| 预警 / 蓄力 | 0–0.8 s | `Charge(t, 压扁 14%, 前倾 4°)`：整只往下压 | 绕身的冰晶星**隔一颗换成金**；金点往壳心收 |
| **释放帧（起转）** | 0.8 s | `Release(拉长 8%, 0°, 顿帧 0.05 s)`：一下弹开 | 贴地**大金环** + **冰刺环** + 冰白爆闪 + 冷光；金色爆闪；震屏 0.45 |
| 持续段 | 旋转 ≤ 3.6 s | 原有 | 身后甩**金屑**（`EliteTrail`）；撞墙反弹 `Kick(压扁 10%, 后仰 8°)` |
| 收招 | 过热翻倒 | `Relax` | 原有霜斑、散热孔紫霜 |

- **冰喙猛啄**：缩颈 0.45 s 时 `Charge(t, 8%, 后仰 10°)`（往后缩）+ 起手金芒；啄下去 `Release(拉长 10%, 前冲 12°, 顿帧 0.05 s)` + 金色爆闪 + 啄点**冰崩**（金环 + 崩起的冰块 + 冰屑）。
- **第一人称**：旋转起手时脚下的金环 + 冰刺环在冰面上用暗衬的金描边读得出；贴脸啄的时候冰崩在准星下方。

## 3. 玄冰巨蟹 · 夹击 + 横扫（`FrostCrabAI`，精英 1 只 / 局）

- **设定母题**：冰壳巨蟹，巨钳像一把冰剪。精英夹完立刻补一记横扫（原有设定）。主形是**扇形（钳够得着的范围）→ 一对合拢的剪刀**，接**一圈往外推的地波**。

| 节拍 | 时刻 | 动作 | 特效（精英多出来的） |
|---|---|---|---|
| 起手 | 0 s | 原有 grabWindup 片段 | 起手金芒（钳尖）+ 精英印 |
| 预警 / 蓄力 | 0–0.6 s | `Charge(t, 压低 10%, 后仰 10°)`：抬钳时整只往后坐 | 金点往钳尖收 |
| **释放帧（夹）** | 0.6 s | `Release(压扁 12%, 前冲 12°, 顿帧 0.07 s)`：往前砸 | 金色爆闪 + **剪刀月牙合拢**（冰白一道从上往下、描金一道从下往上）+ 钳下**冰崩** |
| 接招横扫 · 蓄力 | grabRecover 后 0.5 s | `Charge(t, 8%, 前倾 6°)` | 起手金芒（小钳） |
| **释放帧（扫）** | | `Release(拉长 8%, 0°, 顿帧 0.05 s)` | 金色爆闪 + 地波外多一圈**金环**往外扩 + 一圈冰环 |
| 收招 | | `Relax` | — |

## 4. 预算与验收

- 每一下精英点缀约 20–40 颗粒子（金点按前摇时长 × 每秒 8–30 颗），全部 × 画质密度、过 `FxBudget`；大形（爆闪、金环、月牙）各 1 个，essential。
- 回归：`frost`、`gallery-frost`、`fx`、`fx-style`、`telegraph-look`；节拍条 `beats-frost-elite`。实测见文末（实现完回填）。
