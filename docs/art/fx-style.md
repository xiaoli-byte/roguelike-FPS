# 特效风格准则

特效属于游戏美术的一部分，要和模型、场景、界面用同一套语言。本文的依据有三处：

- [`art/README.md`](../../art/README.md) 的「当前美术目标」
- `art/pipeline/pipeline.toml` 里的 `[concept].style`
- [`docs/unity-art-pipeline.md`](../unity-art-pipeline.md) §4 风格化着色

新做或改动的特效，都要按本文末尾的清单自查。

## 一、总原则：和模型、场景同一种手绘风格化

美术目标的原话是：以《枪火重生》级别的风格化游戏效果为参考，做到**轮廓清楚、比例协调、手绘材质统一、正常游玩视角下耐看**。场景和角色用的是「厚实大形、简化切面、两三个主色块、柔和的手绘渐变、克制的边缘点缀」。**拒绝写实、细碎颗粒、密集裂纹、繁复小雕饰和刺眼高光。**

落到特效上：

1. **形状先于细节**。每个特效先用一两个大形读出来（火团、冲击环、刀光弧、法阵），细节只是点缀。不要靠成百上千的小粒子堆出体积，也不要用噪声颗粒做质感。
2. **色块，而不是色彩渐晕**。每个特效只用 **2–3 个色阶**：亮芯 / 主色 / 暗边或烟，阶与阶之间是硬一点的「软阶梯」，对应 StylizedLit 的 `smoothstep` 明暗阶梯。避免纯加法叠成大片白、灰雾状过渡，也避免照片质感的烟火序列。
3. **中尺度的东方纹样**。法阵、刀光、火焰、云烟都可以借东方奇幻的母题，但要像场景里那样**简化成认得出的中尺度形状**：
   - 回纹、云纹、火焰纹、符箓、八卦、印章、卦象；
   - 烟和尘画成团块状的祥云，不做写实烟雾；
   - 刀光可以带一点墨笔的起收锋。
   不要细密刻花和小字。
4. **克制的光**。自发光和泛光只用来突出「这里是能量 / 危险 / 弱点」，不能让画面整体发白。高光要小、要硬，和 StylizedLit 的阶梯高光同一类。暗部偏冷而不发黑，特效的暗边、烟色也偏冷或偏紫，不用纯灰黑。
5. **读感优先、不糊屏**（项目手感原则：「射得爽」）。第一人称里，敌人轮廓、准星、预警在任何特效之上都必须读得出来。大特效要有明确的时间结构——**蓄 → 爆 → 余韵**，在 0.3–0.6 s 内把信息交代完，余韵很快退场。

## 二、色彩

### 2.1 元素色

全局固定，整个游戏一致：

| 元素 / 语义 | 主色 | 亮芯 | 暗边 / 烟 |
|---|---|---|---|
| 火 · 灵火 | 橙红 | 金黄 → 近白 | 赭红、暖褐烟 |
| 雷 | 蓝白 | 白 | 靛紫 |
| 蚀 | 鲜绿 | 黄绿 | 墨绿 |
| 冰 / 霜 | 冰蓝 | 白 | 蓝灰 |
| 圣 / 金（暴击、精英、鎏金） | 金 | 暖白 | 赭金 |
| 危险预警 | 正红；第三章熔岩地面上用品红 | — | 暗衬边 |

### 2.2 章节底色

特效的「环境色」（烟、尘、碎屑、余烬），要和章节调色一致：

- **第一章 · 沙寺**：暖砂岩、赭石，点缀克制的靛青和赤陶。尘是暖沙色，不用灰色。
- **第二章 · 霜山**：蓝灰的石和木，配积雪，少量暖色。雪雾偏冷白，不要纯白糊屏。
- **第三章 · 熔火**：暗紫玄武岩，配铜色和橙色。烟偏紫褐，余烬是铜橙色。完整的调色板、631 配比（暗紫玄武岩 60% / 铜色金属与暖灰 30% / 熔岩橙 10%）和自检见 [ch3-look.md](ch3-look.md)。
- **第四章 · 雪域**（雪域天路，docs/unity-ch4-port.md C4-4）：青绿草甸、白雪、深蓝天、白墙赭红（碉楼、白塔）、五色经幡（蓝白红绿黄，只作点缀，不进特效主色）。
  - 环境色：高原尘灰褐 `#9a8a6c`（不用沙黄）、雪粒冷白 `#e6edf4`、草屑青绿 `#6f8f3e`、石块暗灰 `#6e665e`。代码里 `FxTone.Ground(…, 4)` 把沙寺色按明暗换成「石块暗灰 → 灰褐尘」。
  - **腐化色：邪火紫红雷光**，三阶 = 亮芯粉白 `#fff2fb` / 主色紫红 `#ff4fd8` / 暗边靛紫 `#4a1a6e`。雷魅带电（边缘光的噼啪）、电弧、雷标、出生法阵「雷纹」、领主的雷都用它。
    这一章「雷」的元素色按它走（替代 2.1 的蓝白雷，只限第四章的怪和场地；玩家自己的雷殛仍是蓝白），和第一章金白日火、第二章青紫霜火、第三章熔岩橙一眼分开。
  - **和危险预警分开**：会挨打的范围一律是危险填充（`TelegraphTone.Danger`，草甸、雪地上是正红）；紫红只做「这是雷」的身份层（`TelegraphTone.Thunder`：细而亮的雷标 / 符印 / 电场的边，叠在红填充上，不算危险、不铺填充）。
    紫红（色相约 318°）比正红（358°）亮一档、拉开 40°，两者同屏也分得清；落雷 = 正红危险圆 + 外沿 0.35 m 紫红雷标环，同时填满即劈。

### 2.3 界面与法阵

界面的主题色是**墨色、朱红、鎏金**。出生法阵、印记、名字卡这类「仪式感」特效，优先用这一组颜色，再叠上章节的符文色。

## 三、形态与动作

- **火**：卡通火纹。S 形往上翻，顶端分成两三条舌头，会断出小火团往上飘。色阶分明，带一圈赭红暗边。
- **爆炸**：团簇状火团翻滚膨胀，边缘硬边消散，颜色按「白热 / 黄 / 主色 / 深色 / 烟」五段递进。烟是浅色实心的祥云团块。冲击环用卡通的粗环，不用写实的冲击波扭曲。
- **刀光 / 斩击**：一道月牙主形，带墨笔起收锋。敌方刀光底下垫暗月牙托出亮刃，玩家刀光偏金、偏灵火。
- **法阵 / 印记**：同心圆加简化符文，线条粗而少。旋转、收缩只用来表现倒计时。
- **冰**：块面清楚的冰晶多面体（低多边形的切面感），亮面白、暗面冰蓝，不追求写实的透明折射。
- **雷**：折线锯齿加少量分叉，粗细有对比，闪烁节奏短促。
- **水**：风格化的涟漪圈、白沫块和水花团，不追求写实流体。
- **环境粒子**（浮尘、雪、余烬）：数量少、形状大一点、运动慢。它们只是氛围，不能和战斗特效抢读感。
- **节奏**：出手要干脆，亮芯第一帧就到峰值；余韵快速衰减；循环类特效（状态、火盆）要有呼吸感，避免机械均匀的闪烁。

## 四、自查清单

做完一个特效，在第一人称和第三人称各截一张图，逐条检查：

1. 缩小到 25% 还能认出它是什么吗？大形读得出来吗？
2. 主要色阶是不是在 3 个以内？有没有大片纯白、灰雾或写实烟火？
3. 颜色符合元素色和章节底色吗？
4. 有没有细碎颗粒、噪点纹理、密集裂纹、细小刻花？有的话就删掉，或者换成中尺度的形状。
5. 在亮沙、雪、熔岩三种地面上，敌人轮廓和准星还看得清吗？
6. 时间结构是不是「蓄 → 爆 → 余韵」，0.6 s 内交代完？余韵会不会拖太久？
7. 和旁边的模型、场景放在一起，看起来像同一个游戏吗？手绘感、饱和度、亮度一致吗？
8. 有没有接 FxBudget？低画质档下退化得是否体面？
9. 五段（蓄 / 出手 / 飞行 / 命中 / 余韵）里该有的段都有吗？每段至少两层、寿命差一倍以上吗？（第五节）
10. 有没有至少一项世界回应（照亮周围、推动空气和地面、留下痕迹、方向、归属）？
11. 余韵层有没有盖住敌人剪影或准星？把余韵层全关掉，玩家还看得懂发生了什么吗？（必须看得懂：余韵只能是装饰）

## 五、分层、节奏与世界回应

前四节管「长什么样」，这一节管「一个特效由哪几层组成、每层什么时候出来、世界怎么回应它」。不分引擎。

依据：2026-11-15 拆读 small-magic（patch.gg/games/blendi/small-magic，MIT，Three.js 纯代码绘制的施法小游戏）的 `spells.js` / `fx.js` / `fire.js` / `flames.js` / `sigil.js` / `blast.js` / `page.js`。学的是手法；外观、配色、纹样一律按本文前四节。

**不能越过的线**：元素色、章节底色、危险预警配色（第二节）照旧；[composition.md](composition.md) 第 6 节的铁律照旧——**敌人必须是画面里视觉权重最高的东西**，特效再丰富也不能盖住敌人剪影。所以本节加的层都是「少、小、短、暗于主体」：亮的层 ≤ 0.1 s，活得久的层必须暗或小，烟尘每次 1–5 团，并且全部限流。第一节第 5 条的「0.3–0.6 s 内把信息交代完」指的是主体；余韵可以再留 0.6–2 s，但它不承载信息。

### 5.1 它为什么好看

1. **一个法术不是一个特效，是五段**：蓄 → 出手 → 飞行 → 命中 → 余韵。每段都有东西看，互不重复。
2. **每段是好几层寿命错开的东西**：火球命中 = 火舌（0.35–0.9 s）+ 带重力的火星（0.8–2 s）+ 烟（2.6–4.6 s）+ 一闪（0.28 s）+ 一团慢慢暗下去的暖光（1.3 s）+ 一盏照亮周围的灯 + 草被压倒 + 地面起火。没有哪一层是主角。
3. **飞行物本身几乎不画**，画的是它一路掉下来的东西：火舌带走飞行速度的 12% 再往上窜，火星偶尔甩出去，烟留在原地。所以读得出速度和走向。
4. **世界有回应**：火顺风蔓延、霜能灭火、风把草压倒把叶子扯下来、爆炸把地烧秃并烙下符阵。特效不是贴在世界上面的一层。
5. **符阵是「写」出来的**：从外圈往里一圈一圈画，每圈由一个亮点领着转一周；各层反向旋转。一出现就完整的符阵是贴纸。
6. **形状不重复**：火舌的轮廓由噪声按「每颗粒子自己的种子 + 年龄」啃出来，越老啃得越深；烟的边缘往里蚀。同一种粒子没有两颗长一样。
7. **大招有顿挫**：蓄力时四周的光点被吸向一点；落下的一瞬时间几乎停住；然后才是火。

### 5.2 五段各该有哪几层

做新特效按这张表过一遍，缺的补上；不需要的段（命中扫描的枪没有「飞行」）明确跳过。

| 段 | 该有的层 | 时长 |
|---|---|---|
| 蓄（预兆） | 法印写出；四周光点向出手点收拢；出手点由暗到亮 | 0.08–0.35 s（大招 ≤ 2.8 s） |
| 出手 | 一闪（≤ 0.1 s）；一束沿出手方向的拉丝火星；后坐 / 镜头一顿；对空气和地面的推力（气浪丝、扬尘） | 0.05–0.3 s |
| 飞行 | 亮芯（小）；身后落下的主体粒子；偶尔的火星；隔一段一团烟；一盏跟着走的灯 | 飞多久出多久 |
| 命中 | 一闪 + 灯；甩出去的大形（火舌 / 冰块 / 电弧）；带重力、落地会弹的小颗粒；方向（顺着来的方向带出去） | 0.1–0.6 s |
| 余韵 | 慢半拍的第二响（0.08–0.12 s 后）；余烬往上飘；烟；地上的痕迹（焦痕 / 烙印 / 余火）；被吸走的光点 | 0.6–2 s，痕迹 ≤ 8 s |

### 5.3 层的数值范围

| 层 | 颗数 | 大小（米） | 寿命（秒） | 运动 |
|---|---|---|---|---|
| 闪光 | 1 | 0.35–0.9 | 0.06–0.1 | 不动 |
| 大形（火舌等） | 3–14 | 0.3–0.8 | 0.35–0.7 | 2.5–7 m/s 甩出，往上偏；靠轮廓被啃掉消失，不靠淡出 |
| 拉丝火星 | 5–18 | 宽 0.018–0.045 | 0.12–0.45 | 6–16 m/s，受重力 |
| 会弹的颗粒 | 1–22 | 0.05–0.13 | 0.5–1.6 | 3–12 m/s，重力 13–16，落地弹 |
| 余烬 | 3–12 | 0.05–0.1 | 0.6–1.5 | 1–5 m/s，往上飘、带闪 |
| 符点 | 2–6 | 0.2–0.34 | 0.8–1.3 | 0.4–2.5 m/s 散开往上 |
| 烟 / 尘 | 1–5 | 0.3–1.0 | 0.8–1.8 | ≤ 1.4 m/s，延迟 0.05–0.15 s 出 |
| 气浪丝 | 2–9 | 宽 0.012–0.018 | 0.12–0.22 | 20–32 m/s，没有重力；从枪口前 0.9 m 起，不挡视野 |
| 光屑 | 1–4 / 发 | 0.07–0.11（远处放大） | 0.16–0.3 | 几乎不动 |
| 灯 | 1 | 范围 3–5 m | 0.09–0.16 | 全场共三盏，0.06 s 内不重复点 |
| 法印 | 1 | 半径 0.2（手边）/ 1.5–3（地面） | 写 0.08–0.5，停 ≥ 0.06，散 0.2–1.9 | 各层反向慢转 |

规律：**越亮的越短，越暗的越长**；相邻两层的寿命至少差一倍；颗数宁少勿多，靠寿命错开而不是数量让画面「有东西」（和第一节第 1 条「不靠小粒子堆体积」一致）。

### 5.4 世界回应

每个特效至少要有一项，按便宜到贵：

- **照亮周围**：命中、出手、击杀各一盏短灯，颜色 = 元素色 / 敌人色。
- **推动空气和地面**：开枪往前推开气浪丝；枪口前下方 2.6 m 内有地面就掀起一片尘（尘用章节环境色，2.2 节）。
- **留下痕迹**：弹孔、焦痕、技能落点烙下的法印（比火色暗、偏红，是烧过的痕不是光源；2 s 慢慢暗下去）、余火。
- **元素各有各的后果**：火弹落点起几条火舌和余烬；雷弹落点电弧贴着表面爬两拍；蚀弹落点蚀液往下滴、冒泡。
- **方向**：打中敌人，沿子弹来的方向从背后带出去一束，而不是原地一个球。
- **归属**：击杀后魂火先迸开 0.24 s，再盘旋着飞回玩家胸口（不往脸上飞）。技能蓄力时四周的火星向人收拢。

### 5.5 法印

纯程序绘制，纹样都是第一节第 3 条允许的母题。由外到内：粗细双环 + 七十二刻度（每六格一长）；一圈回纹；一道断环；先天八卦（三爻，阳爻整、阴爻断）；双细环；两重相错的多边形（方胜）；中心太极。

- **必须写出来**：写出时长给 0.08–0.5 s，不给 0。写的时候转得快一点，写完慢下来；领笔的亮点沿外圈甩几颗光屑。
- **边数区分技能**：内层多边形边数 3–9，每个技能固定用一个（燃爆雷 6、尾焰火灵 9）。
- **三种用法**：手边的小印（半径 0.2，法线朝镜头，一笔写完就散）；脚下的持续印（跟着人走，技能结束才散）；落点的烙印。
- 颜色按 2.3：仪式感特效优先墨、朱红、鎏金，再叠元素色。玩家的法印不用正红（正红是危险预警）。
- 不用西式符文字母、五芒星、六芒星。

### 5.6 节奏与限流

- **亮芯第一帧到峰值**，不淡入。
- **第二响**：击杀、技能命中在 0.08–0.12 s 后再来一下小的（符点、余烬、一下小闪）。一下是「啪」，两下是「啪—嗒」，后者才有分量。
- **烟和尘永远晚出**：延迟 0.05–0.15 s，等闪光过去再升起来，否则被闪光盖掉、还糊屏。
- **连射要限流**：每帧落点余韵 ≤ 3 处、光屑 ≤ 12 颗、击穿 ≤ 4 束、死亡余韵 ≤ 3 个；轻枪气浪隔发、扬尘每 5 发。
- 顿帧、镜头一顿已有，新特效接它们，不另造。

### 5.7 反例

- 一个发光球 + 一圈环：只有「命中」一段、只有一层。
- 把同一层调大调亮来「加强」：该加的是另一段或另一层。调亮还会盖住敌人。
- 六层同时出、同时灭：寿命没错开，等于一层。
- 特效播完世界毫无变化：没有灯、没有痕迹、没有被推动的东西。
- 符阵整枚淡入淡出。
- 飞行物是一个带拖尾线的球，身后什么都不留。
- 烟和闪光同一帧出。
- 余韵层参与玩法判定，或者被限流后玩家看不懂发生了什么。
- 余韵层用和危险预警、精英金边同一档的亮度和饱和度。
