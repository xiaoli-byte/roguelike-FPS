# 特效风格准则

特效属于游戏美术的一部分，要和模型、场景、界面用同一套语言。本文的依据有三处：

- [`art/README.md`](../../art/README.md) 的「当前美术目标」
- `art/pipeline/pipeline.toml` 里的 `[concept].style`
- [`docs/unity-art-pipeline.md`](../unity-art-pipeline.md) §4 风格化着色

新做或改动的特效，都要按本文末尾的清单自查。

## 一、总原则：和模型、场景同一种手绘风格化

美术目标的原话是：以《枪火重生》级别的风格化游戏效果为参考，做到**轮廓清楚、比例协调、手绘材质统一、正常游玩视角下耐看**。场景和角色用的是「厚实大形、简化切面、两三个主色块、柔和的手绘渐变、克制的边缘点缀」。**拒绝写实、细碎颗粒、密集裂纹、繁复小雕饰和刺眼高光。**

落到特效上：

1. **形状先于细节**。每个特效先用一两个大形读出来（火团、冲击环、刀光弧、法阵），细节只是点缀。不要靠成百上千的小粒子堆出体积，也不要用噪声颗粒做质感。
2. **色块，而不是色彩渐晕**。每个特效只用 **2–3 个色阶**：亮芯 / 主色 / 暗边或烟，阶与阶之间是硬一点的「软阶梯」，对应 StylizedLit 的 `smoothstep` 明暗阶梯。避免纯加法叠成大片白、灰雾状过渡，也避免照片质感的烟火序列。
3. **中尺度的东方纹样**。法阵、刀光、火焰、云烟都可以借东方奇幻的母题，但要像场景里那样**简化成认得出的中尺度形状**：
   - 回纹、云纹、火焰纹、符箓、八卦、印章、卦象；
   - 烟和尘画成团块状的祥云，不做写实烟雾；
   - 刀光可以带一点墨笔的起收锋。
   不要细密刻花和小字。
4. **克制的光**。自发光和泛光只用来突出「这里是能量 / 危险 / 弱点」，不能让画面整体发白。高光要小、要硬，和 StylizedLit 的阶梯高光同一类。暗部偏冷而不发黑，特效的暗边、烟色也偏冷或偏紫，不用纯灰黑。
5. **读感优先、不糊屏**（项目手感原则：「射得爽」）。第一人称里，敌人轮廓、准星、预警在任何特效之上都必须读得出来。大特效要有明确的时间结构——**蓄 → 爆 → 余韵**，在 0.3–0.6 s 内把信息交代完，余韵很快退场。

## 二、色彩

### 2.1 元素色

全局固定，整个游戏一致：

| 元素 / 语义 | 主色 | 亮芯 | 暗边 / 烟 |
|---|---|---|---|
| 火 · 灵火 | 橙红 | 金黄 → 近白 | 赭红、暖褐烟 |
| 雷 | 蓝白 | 白 | 靛紫 |
| 蚀 | 鲜绿 | 黄绿 | 墨绿 |
| 冰 / 霜 | 冰蓝 | 白 | 蓝灰 |
| 圣 / 金（暴击、精英、鎏金） | 金 | 暖白 | 赭金 |
| 危险预警 | 正红；第三章熔岩地面上用品红 | — | 暗衬边 |

### 2.2 章节底色

特效的「环境色」（烟、尘、碎屑、余烬），要和章节调色一致：

- **第一章 · 沙寺**：暖砂岩、赭石，点缀克制的靛青和赤陶。尘是暖沙色，不用灰色。
- **第二章 · 霜山**：蓝灰的石和木，配积雪，少量暖色。雪雾偏冷白，不要纯白糊屏。
- **第三章 · 熔火**：暗紫玄武岩，配铜色和橙色。烟偏紫褐，余烬是铜橙色。
- **第四章 · 雪域**（雪域天路，docs/unity-ch4-port.md C4-4）：青绿草甸、白雪、深蓝天、白墙赭红（碉楼、白塔）、五色经幡（蓝白红绿黄，只作点缀，不进特效主色）。
  - 环境色：高原尘灰褐 `#9a8a6c`（不用沙黄）、雪粒冷白 `#e6edf4`、草屑青绿 `#6f8f3e`、石块暗灰 `#6e665e`。代码里 `FxTone.Ground(…, 4)` 把沙寺色按明暗换成「石块暗灰 → 灰褐尘」。
  - **腐化色：邪火紫红雷光**，三阶 = 亮芯粉白 `#fff2fb` / 主色紫红 `#ff4fd8` / 暗边靛紫 `#4a1a6e`。雷魅带电（边缘光的噼啪）、电弧、雷标、出生法阵「雷纹」、领主的雷都用它。
    这一章「雷」的元素色按它走（替代 2.1 的蓝白雷，只限第四章的怪和场地；玩家自己的雷殛仍是蓝白），和第一章金白日火、第二章青紫霜火、第三章熔岩橙一眼分开。
  - **和危险预警分开**：会挨打的范围一律是危险填充（`TelegraphTone.Danger`，草甸、雪地上是正红）；紫红只做「这是雷」的身份层（`TelegraphTone.Thunder`：细而亮的雷标 / 符印 / 电场的边，叠在红填充上，不算危险、不铺填充）。
    紫红（色相约 318°）比正红（358°）亮一档、拉开 40°，两者同屏也分得清；落雷 = 正红危险圆 + 外沿 0.35 m 紫红雷标环，同时填满即劈。

### 2.3 界面与法阵

界面的主题色是**墨色、朱红、鎏金**。出生法阵、印记、名字卡这类「仪式感」特效，优先用这一组颜色，再叠上章节的符文色。

## 三、形态与动作

- **火**：卡通火纹。S 形往上翻，顶端分成两三条舌头，会断出小火团往上飘。色阶分明，带一圈赭红暗边。
- **爆炸**：团簇状火团翻滚膨胀，边缘硬边消散，颜色按「白热 / 黄 / 主色 / 深色 / 烟」五段递进。烟是浅色实心的祥云团块。冲击环用卡通的粗环，不用写实的冲击波扭曲。
- **刀光 / 斩击**：一道月牙主形，带墨笔起收锋。敌方刀光底下垫暗月牙托出亮刃，玩家刀光偏金、偏灵火。
- **法阵 / 印记**：同心圆加简化符文，线条粗而少。旋转、收缩只用来表现倒计时。
- **冰**：块面清楚的冰晶多面体（低多边形的切面感），亮面白、暗面冰蓝，不追求写实的透明折射。
- **雷**：折线锯齿加少量分叉，粗细有对比，闪烁节奏短促。
- **水**：风格化的涟漪圈、白沫块和水花团，不追求写实流体。
- **环境粒子**（浮尘、雪、余烬）：数量少、形状大一点、运动慢。它们只是氛围，不能和战斗特效抢读感。
- **节奏**：出手要干脆，亮芯第一帧就到峰值；余韵快速衰减；循环类特效（状态、火盆）要有呼吸感，避免机械均匀的闪烁。

## 四、自查清单

做完一个特效，在第一人称和第三人称各截一张图，逐条检查：

1. 缩小到 25% 还能认出它是什么吗？大形读得出来吗？
2. 主要色阶是不是在 3 个以内？有没有大片纯白、灰雾或写实烟火？
3. 颜色符合元素色和章节底色吗？
4. 有没有细碎颗粒、噪点纹理、密集裂纹、细小刻花？有的话就删掉，或者换成中尺度的形状。
5. 在亮沙、雪、熔岩三种地面上，敌人轮廓和准星还看得清吗？
6. 时间结构是不是「蓄 → 爆 → 余韵」，0.6 s 内交代完？余韵会不会拖太久？
7. 和旁边的模型、场景放在一起，看起来像同一个游戏吗？手绘感、饱和度、亮度一致吗？
8. 有没有接 FxBudget？低画质档下退化得是否体面？
