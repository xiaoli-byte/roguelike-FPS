## 1. 怎么做的

顺序照 composition.md 第 0 节：**先路线和场地 → 大块面 → 引导线 → 光 → 颜色面积 → 小件最后**。

1. 先定每张图的出生点、据点、上下层和过河 / 上山的路（4-2、4-4 照现有 spec，4-A 新设计），再定概念机位——三张的机位都是**出生点第一眼**。
2. 提示词按 6 / 3 / 1 三段写：六成是哪些大块面，三成是哪些线，一成是哪一个点。不写商业游戏名，要求厚实大形、平涂色块、没有细裂纹和雕花、中景没有细高杆（假人形）。
3. 第一版出来自己挑毛病，再把第一版当底图、列「必须改」的清单出下一版（只减不加）：
   - 4-2 v1 → v2：岩面全是细竖纹 → 大切面平涂；急流白沫太亮（比碉楼还抢）→ 乳白灰绿的平水；看不出 Y 形汇口 → 补上第二条河；前景石墙太高太碎 → 压低压暗。
   - 4-4 v1 → v2 → v3：右近景一根柱子顶天立地 → 退到中景；柱顶雷晶在发光（抢了山尖的戏，也不合特效分离）→ 不发光的灰石；岸上碎石太多 → 平滩 + 两块巨石；v2 湖面太蓝，自检高饱和 21% → v3 降到乳白青灰。
   - 4-A v1 → v2 → v3 → v4：看不出上山的路 → 加两道之字坡道；山嘴全是尖岩 → 大切面 + 雪；前景大石头和草丛 → 清掉；v3 雪的暗部偏紫、路边矮墙一块块戴雪帽 → v4 中性冷灰、平滑路牙，村寨五座减成三座。
4. 套件图：把定稿的场景图当风格参考，另出一张「件件分开、同一视角、灰底、中性白光、固有色」的套件表；不画火、烟、光、雪（雪交给着色器按朝上的面刷）。
5. 路线、据点、驻守点、入场点标到概念图和俯视图上，配怪写进表里。

出图用的是仓库里的 OpenAI 客户端（`art/pipeline/lib/openai_image.py`，`gpt-image-2.5-sunburst`，2048 × 1152，high）：场景 3 张初稿 + 6 次改稿，套件 3 张。

## 2. 631 自检

`python scripts/unity/composition_check.py`，定稿三张：

| 图 | 颜色 低饱和 / 固有色 / 高饱和 | 明度 暗 / 中暗 / 中间调 / 亮（平均 · 跨度） | 密度 安静 / 中等 / 密集 | 脚本提示 |
|---|---|---|---|---|
| 4-2 v2 | 71 / 29 / 1 | 13 / 44 / 34 / 9（40 · 64） | 39 / 55 / 6 | 没有点缀色；安静 39%（差 1 点到 40） |
| 4-4 v3 | 71 / 29 / 0 | 0 / 9 / 43 / 48（65 · 58） | 31 / 60 / 9 | 没有点缀色；安静 31% |
| 4-A v4 | 66 / 33 / 1 | 0 / 7 / 34 / 59（70 · 52） | 28 / 47 / 24 | 没有点缀色；安静 28% |

改稿前后：4-4 的高饱和 21% → 0%、低饱和 15% → 71%；4-A 的密集 46% → 24%、低饱和 40% → 66%。

怎么读这些数：
- **点缀色只有 0–1% 是故意的。** 场景自己只留一个小焦点（碉楼顶的暖光、山尖的金、红殿金顶），那「一成」的面积留给玩法：怪的紫红雷光、青金色灵火坛、危险预警的正红（composition.md 第 6 节「高饱和是配额」）。
- **安静区不到 40%**：4-4 是碎石滩被画出了一粒粒石子，4-A 是宫堡的窗和墙线。搭图时碎石滩用平涂地表材质、不撒石子模型；宫堡是主体，密度本来就该集中在它身上，路面和草甸保持平。
- 明度：4-2 是中暗调（平均 40），4-4 / 4-A 是高调（65 / 70）。三张的背景明度都在一条不宽的带里，怪进画面是唯一的强对比。

### 我自己挑的毛病（搭图时改，不再改图）

- **4-2**：前景出生台还是偏大，占了左下四分之一——实景里出生台的矮墙做到 0.7 m（可翻越），别挡下坡的视线。河面偏亮偏青，实景按 `#7fd1c6` 再往灰里收。概念图为了一张图里放下寨坡、碉楼、铁索桥、栈道，把碉楼和桥摆得比地图上近（地图上从出生点看，碉楼在北偏东 35°、桥在 72°）：**位置以 `gorge/spec.ts` 为准，概念图定的是层次、配色和件的样子**。
- **4-4**：整体偏亮偏平，是有意的（首领场地背景要安静），但白身的怪贴在雪上会淡——雷神本体是深色龙身 + 紫红雷光，没问题；转阶段的小怪用深色的天狗、帝江、蛮蛮，不放白毛的獓狠。三根石柱等高等形，是玩法要求（四根一样的导雷柱），不对称交给冰舌和垭口。
- **4-A**：白墙压白雪，靠岩面和赭红墙带分开——实景里岩面要比概念图再暗半档，墙脚留一圈露岩。概念图里中台不够宽，实景按设计稿做成 28 × 12 m 的大平台。套件图里坡道画成了平的，建模按升 4 m 做。

## 3. 路线与配怪

三类怪点照 run-variety 的规矩：**驻守点**（路遇埋伏，开局就站在场上）、**据点**（守灵火坛，多波）、**入场点**（游荡怪群和增援只从这里进，合情合理地「来」）。
第四章的怪都有领地和来处：啸獭从洞里钻出来，天狗从林线和崖顶下来，蛮蛮从河面、湖面上空飞来，牦群从山道走来。

## 4. 拆件

### 4.0 通则

- **三层分开做**（far-layer 规矩）：看得见、走不到的一律程序生成（多棱硬边、平涂、三四个色阶），不花 Tripo；玩家走得到、看得清的才出四视图走 Tripo；要严丝合缝对接的直段 / 角件用 Blender 程序件（`art/pipeline/blender/`，像栈道木件那样）。
- **网格**：所有件吸附 0.5 m；墙块、坡道、女墙的长度是 4 m 的倍数。轴心在底面中心。
- **特效分离**：件上不带火、烟、光、雷、水、雪。会发光的（雷晶、雷桩铁笼）单独材质槽或走发光遮罩 `T_*_E`；会动、会坏的（门扇、滑轮、雷晶、栈道断口）单独成件；件上留 `FX_` 空挂点。
- **贴图**：固有色、中性白光下画（不带场景色光），雪的暗部和石头都不带紫。金顶、铜幢、铁箍、铁环建议按非金属做（平涂 + 阶梯高光）：第四章的生物已经因为带电染色改成非金属（unity-ch4-port C4-5），场景件和它们一致。石缝低对比，别在中景闪。
- **掩体分级**（高度是角色控制器的数：胶囊 1.8 m、眼高 1.62、帝江能跃 1.2 m）：

| 级 | 高 | 认法 | 件 |
|---|---|---|---|
| 全掩体 | ≥ 2.2 m | 房块、墙块、巨石、门墩：大而实 | 民居块、墙块、桥楼、链锚墩、石柱、巨石、冰块 |
| 半掩体 | 1.1 m | 一条带压顶的矮墙 | 梯田墙、女墙条、玛尼墙、冰碛垄；玛尼堆 1.4–2.2 m 介于两级之间，按 spec 的缩放 |
| 可翻越 | 0.7 m | 没有压顶的矮件 | 柴垛、矮石簇、栈道外栏、出生台矮墙 |
| 不可通行 | — | 深水、陡于 40° 的崖、墙块立面 | — |

半掩体挡不住帝江（它会跃过来），这是有意的；同一级不混形状。
