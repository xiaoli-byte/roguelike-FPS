## 和现在的图比，版面改了什么

玩法内容照旧（据点名、波次编制、藏宝、机关、走法变体都取自 `docs/level-design/maps/1-*.md` 和现有场景数据），重做的是**空间版面**：

- **1-1**：「古道 + 圆盘」的香肠形可玩区 → 整片能走的戈壁盆地，边界全靠地形；长城横贯、三处能过；干河床是下沉侧翼路；烽燧在全场最高处。
- **1-2**：三条平直河道 → 分分合合的辫状河道 + 风口垭口（迷宫不是走廊）；佛塔加高当指北针；外圈崖壁留豁口。
- **1-3**：方盒子城 → 不规则圆角城，巨型沙丘压住西北三分之一灌进城；出生在城外丘顶先俯瞰全城；墙头 / 屋顶 / 街面三层并行。
- **1-4**：保持露天月牙泉（用户 10 月定的方向），遮荫点按远近分散在绕泉环线上，泉随三阶段干下去。
- **1-A**：直崖 → 河湾外侧的月牙形长崖，出生在对岸一眼看全；据点按登高顺序重新编号（① 河洲驼队 → ② 大佛窟前 → ③ 西崖窟檐 → ④ 崖顶塔院），九层楼是贯通三层的竖向通道。

## 怎么出的

- 出图：`tools/gen_route_concepts.py`（OpenAI 图像接口 `gpt-image-2.6-sunburst`，1536×1024、high，每张 35–55 s）。提示词 = `prompts/_style.txt`（画法 + 标注规范；1-4 用 `1-4_style.txt`）+ `prompts/<图>.txt`（版面）。
- 改稿：把上一版当参考图 + `prompts/<图>_v<n>_changes.txt` 的编号「MANDATORY CHANGES」清单走 `images/edits`。
- 定稿版本：1-1 v4、1-2 v3、1-3 v2、1-4 v3、1-A v3（`raw/`，记录在 `raw/records.json`；被替换的旧稿在 `raw/_drafts/`，不入库）。
- 排版：`tools/make_sheets.py` 加中文说明、拼总览。

## 复核记录（2026-11-24）

第一轮改稿（主线按顺序穿过四个据点、1-4 换首领场标注）之后我没有逐段核对线路就发给了用户。用户圈出 1-A 的一段问：「这条线路确定能走吗？你做完图也需要 review 一下」——那段金线竖直爬上九层楼、穿过大佛一直到崖顶，走不通。
于是把五张图沿每条线放大逐段核对，规则是：**线只能落在可走的地面、坡道、台阶、栈道上，不爬墙 / 崖面 / 建筑立面，不翻岩脊，不越沿**。查出并改掉的：

| 图 | 查出的问题 | 改法 |
|---|---|---|
| 1-A | 金线竖直爬九层楼立面、穿过大佛直到崖顶；设计本身也不对（「楼内上窟檐层」= 九层楼梯间，又窄又没法打，佛龛还被大佛占着） | 九层楼只当地标（只有底层敞厅能进）；楼左侧加一座贴崖木栈梯（两跑一平台）从崖脚广场上窟檐层 |
| 1-1 | 长城主缺口画成一道门缝；北豁口的角楼是实心墩；金线上下烽燧台时越过 6 m 台壁，没走坡道；白线 C 箭头反了 | 主缺口画成三车宽的豁口；角楼旁画出塌开的豁口；金线改走东西两条夯土坡道 |
| 1-2 | ② 的平顶屋整栋露着，看不出怎么上屋顶；② → ③ 的金线横穿一道岩脊 | 屋子埋到屋檐、沙堆接上屋顶；岩脊上开出沙垭口 |
| 1-3 | 金线越过塌坑沿直接进坑；四个入场点对着实墙；③ → ④ 贴着厢房山墙 | 走到坑口沿螺旋坡道下去；入场点只放在沙丘漫墙处、南门、东墙豁口、墙头、屋顶；③ → ④ 穿一座门楼 |
| 1-4 | 环线南段钻进月泉阁二层，白杨林里看不出路 | 环线从底层敞厅（只有柱子）和回廊下穿过，林边画出沙路 |

改完又按同一规则复核了一遍，画面层面没有再发现爬墙 / 翻脊 / 越沿的线。

## 哪些验过、哪些只是示意

- **只做了画面层面的复核**：线落在什么上面是看图核对的；**坡度、通道宽度、跳不跳得过还没有实测**——要等白盒地形出来跑可达性探针。说明里的长度（约 400–450 m）、各层高度是设计目标，不是实测。
- **有依据的**：据点波次、藏宝奖励、机关（1-1 沙暴、1-2 流沙、1-3 补给营、1-4 日晒）抄自现有场景数据和设计稿。
- 仍有的小出入：1-3 金线绕寺塔那一小段被塔身挡住看不到；1-4 品红三角画了 6 个（设计是 4 个）；1-1 ② → ③ 之间的橙菱形偏离了金线一点；部分岩石偏饱和，搭图时要压。
