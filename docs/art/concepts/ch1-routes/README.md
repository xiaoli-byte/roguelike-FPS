## 和现在的图比，版面改了什么

玩法内容照旧（据点名、波次编制、藏宝、机关、走法变体都取自 `docs/level-design/maps/1-*.md` 和现有场景数据），重做的是**空间版面**：

## 哪些验过、哪些只是示意

- **只做了画面层面的复核**：线落在什么上面是看图核对的；**坡度、通道宽度、跳不跳得过还没有实测**——要等白盒地形出来跑可达性探针。说明里的长度（约 400–450 m）、各层高度是设计目标，不是实测。
- **有依据的**：据点波次、藏宝奖励、机关（1-1 沙暴、1-2 流沙、1-3 补给营、1-4 日晒）抄自现有场景数据和设计稿。
- 仍有的小出入：1-3 金线绕寺塔那一小段被塔身挡住看不到；1-4 品红三角画了 6 个（设计是 4 个）；1-1 ② → ③ 之间的橙菱形偏离了金线一点；部分岩石偏饱和，搭图时要压。
