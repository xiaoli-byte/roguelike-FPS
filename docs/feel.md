# 手感终调（I7）

手感参数集中在 `unity/Assets/Game/Scripts/Core/FeelProfile.cs`。按决定 D16「代码默认值优先」，字段默认值就是定稿值。要在编辑器里调，就在 `Resources/Feel/FeelProfile.asset` 建一份覆盖（菜单 Create ▸ Spiritfire ▸ Feel Profile），代码不用改。

原则沿用 [unity-parity.md](unity-parity.md) 1.2 的「手感优先」：要射得爽，反馈要强，但不能把战斗打成幻灯片，也不能糊屏。

## 一、定稿值

### 顿帧（`HitStop`）

| 来源 | 时长（真实秒） | 说明 |
|---|---|---|
| 普通击杀 | 0.035 | 一帧半左右，只「咬」一下 |
| 精英击杀 | 0.07 | 明显一顿，可以插队打断冷却 |
| 首领击杀 | 0.18 | 之后接首领溃散的慢动作 |
| 重暴击（一下打掉总量 18% 以上） | 0.025 | 冲锋枪的暴击不算 |
| 元素反应（直接命中引发） | 0.045 | |
| 缩放 | ×0.05 | 不用 0：deltaTime 为 0 时有些系统会跳过结算 |

频率上限不在表里，写死在 `HitStop`：
- 两次之间至少隔 0.12 s，单次最长 0.2 s。
- 预算桶 0.15 s，每秒回 0.075 s，连续作战时顿帧最多占真实时间的 7.5%。

这些数值从 F3 落地起一直在用（10-20 起的全部试玩），I7 没有改，只是搬进总表。

### 清场慢动作（`ClearSlowMo`，I7 新增）

- **触发**：打死一处场地的最后一只，且这处场地至少打过 4 只。
- **效果**：时间 ×0.3，持续 0.4 s 真实时间。
- **优先级**：比顿帧低一档，最后一击先顿一下，接着慢放。
- **让位**：首领溃散慢动作、暂停和场景过渡都压得过它。
- **为什么**：开放大图里每处据点打完，原来没有收束感。慢放 0.4 s 给出「这一仗打完了」的落点；2–3 只的小场地不放，以免频繁打断节奏。
- **关掉**：缩放设成 1。

### 屏效（`GameplayVolumes`）

| 屏效 | 色差强度 |
|---|---|
| 受击 | 0.4 |
| 冲刺 | 0.25 |
| 慢动作 | 0.15 |

低血量的去饱和从 35% 血开始，到 10% 时最强，数值留在 `GameplayVolumes`。

### 震屏曲线（`CameraFeel`）

- **画面幅度**：上限 × trauma ^ 指数 × 设置里的「震屏强度」。
- **定稿值**：指数 2，即 trauma²，开头猛、收尾柔；幅度上限 1.8。
- **多个震源**：最强的那个加上其余之和 × 0.35，见 `CameraShake`。
- **调法**：指数调小，余震就拖得更长、更软；调大，就只剩开头那一下。

### 手柄瞄准辅助（`AimAssist`，I7 新增）

只对右摇杆生效，鼠标完全不受影响。设置里的「手柄瞄准辅助」默认开启。

| 参数 | 值 | 作用 |
|---|---|---|
| 范围 | 45 m | 只看得见的、可选中的敌人 |
| 生效角 | 身体角半径 + 4° | 准星压在敌人身上才介入 |
| 减速 | ×0.5（越靠中心越明显） | 摇杆扫过敌人时「黏」一下，不容易甩过头 |
| 吸附 | 每帧拉近剩余角差的 12% × 摇杆幅度 | 摇杆不动就不拉，不替玩家瞄；不会拉过头 |

## 二、技能出手动作（HC3，相关）

放技能时，枪模按动作类型叠一段 0.4–0.6 s 的时间线：投掷、召唤、砸地、举手、点名，见 `Skills/CastPose.cs`。这段叠加只动枪模，不锁武器，开火节奏不受影响。

## 三、自动翻越：评估结论是不做

对齐计划把「自动翻越」留到 I7 评估（D28）。结论：**不做**。

1. **会改写关卡的可达规则**。[unity-maps-v1.md](level-design/unity-maps-v1.md) 第 0 节规定：
   - 掩体 / 台阶层 1.2–2.6 m，俯射层 2.5–4 m。
   - 主线只靠坡道和单跳（1.42 m）。
   - 二段跳（约 2.7 m）只是捷径。

   L5 的自动验收也是按这条算可达的。加了翻越，1.5–2.2 m 的边沿都能直接爬上去，12 张图的高差设计和验收规则都要重算，那些「绕到敌人背后的高路」也就失去了意义。
2. **和现有移动重叠**。原地冲刺接跳 5.95 m，助跑跳 5.0 m，土狼时间 0.1 s，跳跃缓冲 0.12 s，台阶 0.45 m 自动跨过。正常游玩中，「差一点跳不上」的情况主要出现在 1.2 m 的低掩体上，单跳已经够得着。
3. **参考作品也没有**。《枪火重生》本身没有攀爬 / 翻越，它的机动感来自冲刺和多段跳。我们已经有冲刺，鼯有二段跳，还有「额外跳跃」卷轴。

以后要重新评估，只在这种情况下：试玩数据里出现大量「对着 1.4–1.8 m 边沿连跳」的卡点。那时优先改关卡（加台阶或坡道），而不是加翻越。
