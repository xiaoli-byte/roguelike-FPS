# 场景模型画风调整（2026-10-04）

按用户指定的《枪火重生》级别品质，实际调整三章主要场景资产：沙寺残垣与砂岩、霜山祭亭与雪松、熔火铸造炉与玄武岩。保留主要轮廓、立体厚度和玩法占地，简化细碎写实纹理，改用清楚的大形、宽切面、手绘色块和少量中尺度纹饰。

## 生成与版本

使用 **Codex 内置 image_gen** 编辑原概念四视图，完成六件新参考图；原生输出复制到资产的 `01_concept`，以 concept v002 登记。完整实际提示词、生成器、参考原图与原生输出路径在 `art/pipeline/stylized_landmark_concepts_v002.json`、`art/pipeline/stylized_nature_concepts_v002.json`。各资产的 `asset.json` 继续记录输入与文件哈希及实际审核者 **Codex AI visual review**。

三维艺术形体由本机 ComfyUI / Hunyuan3D 重生成，Blender 做减面、UV、投影、烘焙与 LOD 技术处理。尺寸参考只有数值与相机，没有新增程序化艺术模型。雪亭和雪松沿用四视图 Hunyuan2mv，其余使用 Hunyuan3D 2.1 单图；seed 依次为沙寺残垣 202610050、雪亭 051、铸造炉 052、砂岩 053、雪松 054、玄武岩 055（均为 202610xxx）。保留 50 步、CFG 5、octree 384 的现有生成档。

成品沿用每件 5000 / 1600 / 500 三角预算、1024² BaseColor / Normal / ORM、单材质和 900 KiB 上限；真实实际数值以发布清单和校验报告为准。原概念、成品和失败版本仍可在源资产阶段目录追溯，新版通过检查后再替换游戏发布物。

雪亭 concept v002 的 MV 高模在 build v002 中未能达到远景预算：LOD2 初始 1742 面，按已有最多 1.5% 高度的焊接清理后仍为 1448 面，因此拒绝导出并保留失败记录。没有放宽预算，也没有用程序化方式补建形体。随后用内置 image_gen 编辑同一参考，将侧墙封闭、柱与屋顶/基座融合，去掉细檐、绳结及浮离的小结构；完整重试提示词和原生输出在 `art/pipeline/stylized_frost_retry_concept_v003.json`，以 concept v003 / seed 202610056 继续由本机 Hunyuan2mv 重建。

## 场景材质

`SceneSurfaceMaterial` 只调整六件环境资产的场景/检视材质副本：粗糙度 `.9`、法线强度 `.22`，解除原粗糙度纹理的乘法影响，使大色块在灯光中更稳定。所有 LOD 复用材质副本；释放副本时保留原库材质与共享贴图。旧道具、人物与枪械不套用该环境材质参数。

降低结构石材和地面凹凸，道路用六成章节铺地色、四成已有石纹混合，保持原顶点明暗与一次道路蒙版采样。路外仍为积沙、积雪或灰烬。远景岩石降低去饱和程度，保留较清楚的暖冷色块。原章节光照、场景布局与实体碰撞不变。

修复地标异步补入时重复生成整圈墙边风化层的问题；第一次构造正常生成墙边层，补入时只增加新地标接触层。道具检视显示正/侧/背面镜头控件，镜头方位考虑当前模型旋转，播放后暂停仍能查看真正的正面。
