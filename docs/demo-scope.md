### 2.2 英雄：燎 + 鼯

燎是火、鼯是雷（雷鼓机关师），两个英雄各自天然通向不同的反应流派。鼯的二段跳也让地图里的"高路"有人用（[unity-maps-v1.md](level-design/unity-maps-v1.md) 尺度表：二段跳只有鼯和「额外跳跃」秘卷）。

### 2.3 武器：8 把，每种元素至少 2 个来源

| 武器 | 元素 | 为什么留 |
|---|---|---|
| 蜂鸣冲锋枪 `smg` | 物理（精良起可能带随机元素） | 已移植，燎的初始武器 |
| 赤铜左轮 `revolver` | 物理 | 已移植，爆头流核心 |
| 碎岩霰弹 `shotgun` | 物理 | 已移植，贴脸爽感 |
| 焚城榴弹 `launcher` | 火 | 范围灼烧，焚雷 / 熔金的起手 |
| 雷弧发射器 `beam` | 雷 | 持续雷殛 + 弹射，封脉 / 焚雷的起手 |
| 青冥雷蛊 `stormpod` | 蚀 + 固有雷 | 封脉引擎，撞墙反弹好玩 |
| 赤蛟霰铳 `magmashot` | 火 + 固有蚀 | 熔金破甲，霰弹手感的元素版 |
| 三才转轮 `trinity` | 火 → 雷 → 蚀轮转 | 归墟引擎，最能展示"三元素坍缩" |

元素来源：火 = 榴弹、霰铳、转轮、燎的技能；雷 = 雷弧、雷蛊、转轮、鼯的技能；蚀 = 雷蛊、霰铳、转轮。

**碎刃（原魔刀千刃）**：不进试玩版，原因是工作量。它有独立的控制器（128 片碎刃、刃群、屏障），Unity 里要单独做一套。

- ✅ 2026-10-18：Three.js 版已改名，武器描述去掉了原作人物和地名，改成原创设定（见 DESIGN.md 14.4）。
- 按决定只改名：技能名（千刃出窍、碎刃屏障、杀气爆发 / 人刀合一、噬灵鬼眼）、玩法和刀柄贴图不变。它们的原作出处记在 [demon-blade-v2.md 第 1 节](demon-blade-v2.md)，以后做 Unity 版碎刃时可以再评估。

### 2.4 秘卷：约 40 张，3 个流派

保留现有 16 张基础秘卷，再补约 24 张。流派举例（最终名单第 2 周定）：

| 流派 | 核心 | 代表来源（`progression/scrolls/`） |
|---|---|---|
| 焚雷爆炸 | 火 + 雷，爆炸范围、连锁 | 反应秘卷里的焚雷系、爆焰、焚天雷狱 |
| 熔金破甲 | 火 + 蚀，打精英和护甲 | 熔金系、熔铸、金乌坠 |
| 暴击爆头 | 物理，不靠元素 | 现有暴击 / 爆头秘卷 + 战术秘卷 |

选哪 40 张，参考第 5 节网页版试玩里玩家最常拿、拿了最兴奋的那些。

### 2.5 旱魃

设计见 [unity-maps-v1.md 第 3 节](level-design/unity-maps-v1.md)。试玩版的做法：

- **第 4 周先做一、二阶段**（烈日、焦土），可以用占位模型。二阶段的"飞天之殇"复用已经做好的邪飞天。
- **第 6 周补三阶段**（赤地千里 / 日蚀）和正式模型。
- 制作注意：
  - 骨架是语义人形，手臂类施法动作可以拿 Mixamo 片段做底。
  - 但她是**悬浮**的，走跑类动作用不上。悬浮、日轮、残衣和长发的弹簧骨都要自己做。
  - "影子安全区"靠阴影贴图 + 射线判定，第 4 周先在白盒里验证这个机制好不好玩，再投入美术。

## 6. 试玩安排

### 第 1～3 周：先用网页版试玩

Three.js 版是浏览器游戏，部署到 itch.io 或 GitHub Pages 就能发链接。Unity 移植的同时，先让朋友玩网页版（只开第一章），收集：

- 最常拿哪些武器、秘卷；
- 哪种反应打出来最兴奋，哪种看不懂；
- 死在哪里、一局打多久。

方式：录屏或一份简短问卷。第 2 周定秘卷名单时用这些数据，不凭感觉挑。（碎刃改名已完成，网页版可以直接发。）

### 第 4 周：Unity 内部可玩版，5～10 人

重点问四个问题：

1. 射得爽不爽？后坐、命中反馈、击杀反馈哪里不够？
2. 有没有打出过"这套组合太爽了"的时刻？是哪套？
3. 地图会不会迷路？场地之间的跑图会不会无聊？
4. 旱魃的影子机制看得懂吗？

### 第 8 周：第二轮外部试玩

用 Steam 测试分支上的版本，重点看第 4 周的问题有没有改善。
